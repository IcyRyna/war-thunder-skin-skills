# 炭灰工业独立素材包 0.2.0

本目录是素材包，不是Skill。32项制作素材可以直接取用，也可以按车型重排、改字、改变图案密度或调整材质。原生尺寸、PNG像素、Alpha和N数据通道保持原样。

## 目录

| 目录 | 内容 |
|---|---|
| `azur-v29-children/` | 0.2.0新增14项：按AZUR v29运行贴图实测颜色与比例绘制的人字警示（竖/横）、BLOW-OUT字层、车尾斜条板、身份铭牌组件、首下»箭头、微色标、缺口标、刻度尺、三角符、数码满铺与渐散块、侧裙亮格蜂窝平铺块；PNG＋SVG（像素图仅PNG） |
| `target-children/` | AZUR子版：NO STEP、蜂窝焦点板、旧版电路线（仅用户点名时用） |
| `production/` | 干净图形母版：色标、技术折线角标 |
| `armour-labels/`、`native-surface-children/` | 其他车型的铭牌、警示、拖车点、网布子版，可参考改制 |
| `hd-antislip/` | 三套高清防滑四图材质 |
| `references/azur-current-v29/` | AZUR三张构成范本图 |

各项的用途和对应装饰词汇见Skill的`references/style/decoration-playbook.md`。

`catalog.json`列出素材路径、适用条件、文字语义、图形来源和文件摘要。三套`hd-antislip`各有完整的color、coverage、normal-rgb和packed-n图片，直接可用；N.A是法线Y数据，不是透明度。不要因为有TOWING POINTS、D-TECHNOLOGIE或BLOW-OUT字样就直接贴到不对应的设备。

与`wt-style-charcoal-industrial`目录并排解压可自动识别。若素材放在其他位置，将`WT_CHARCOAL_ASSETS`设为本目录，或运行Skill的`asset_pack.py locate --assets 本目录`检查位置。仅解压Skill不会把素材塞进Skill安装目录。

`references/azur-current-v29`的三张图是必要范本，不是待复制到其他车辆的整车纹理。历史原车裁片、未核实AI元素和研发案例图库未随包分发。

来源沿用每项素材的记录和原SHA256；自行编写的规则/代码与第三方原作、游戏资源的使用范围分别判断。素材技术可用不代表任何目标车已获美术认可。
