## 三、更换机型与核对重点

- **真实模型与原生 UV 起步**：先用包内脚本识别可涂蒙皮、机械遮挡区、活动面与镜像/共享纹素，不按猜想画图形。
- **先构图后人物与文字**：先落实炭灰底、签名色、锐角白形与马赛克，再用 `design_lint.py` / `surface_map.py` 排查重叠、细线与净距，随后安放人物、字标与徽记。
- **外置字体与项目素材**：`v1.21` 不随包内嵌第三方贴花包，字体与角色/标志素材按具体制作任务从本机或项目目录提供，可在环境或参数中指定 `WT_SKIN_FONT`。
- **同尺度复查与实机交付**：配合 `scene_preview.py`、`detail_sheet.py` 与导出的最终 DDS 1:1 裁图复检眼部及文字清晰度，导出独立 `UserSkins` 游戏包后以游戏实机效果为准。
