# 终末地工业涂装 v0.2.0 · 发布候选

以 A7V 原作为第一视觉范本，结合 A7HU、EMBT 的迁移经验及本轮选中的 WT Live 铠甲／社区 EMBT 观察，重建适用于地面载具的黑白灰、黄色方向与工业身份制作流程。

- **按真实承载面构图。** 分配主识别、次识别、方向和安静机械面。宽主侧面把完整徽记、黄带与设备／三色微标安排到不同区域，保留连续底色；紧凑设备面保持成组层级。
- **方向与尺度。** 炮塔侧面采用可随真实上缘倾斜的单一直线；允许等宽黄带组。主标有足够的阅读尺度，辅助信息不会全挤在同一段黄带下方。
- **完整身份与材料精度。** 保留徽记母版和比例，两侧文字分别正向排布；核对实际 UV、共享使用者、窄板缝、遮挡与材质槽。颜色 Alpha、透明覆盖与 packed N／AO 按各自语义处理。
- **内置透明素材。** 23 张真实透明 RGBA PNG、22 份可编辑 SVG，含工业徽记、路线、标签、刻度与纹样；另保留6张必要参考图及来源许可。
- **独立运行包。** 内置固定版本工程脚本和显式真实面映射工具；不依赖旧 Skill 或退役运行时。生产默认无做旧、无颗粒，素材按本车重新排版。

## 已验证范围

完成 A7V／A7HU／EMBT 来源与实际槽位核对、多轮原生表面局部效果研究、DDS裁区读回、分层来源重建及独立包工程检查。EMBT 顶盖 A、肩部 C、正面 B 已取得对应局部选择；99A 侧面按反馈和委托完成分区重排。工程检查与这些视觉结论分别记录。

**同 brief 的新会话独立复现尚未回传，游戏实测为 `not_run`。** 当前为发布候选，不声称整车效果已独立重复验证、所有地面车型已适配，或比旧版有已证实的长期成功率提升。冻结测试输入另行提供，未混入安装包。

## 旧版与使用

0.1.0／0.1.1 及旧1.0–1.4继续永久封存，不恢复为当前依赖。[旧版封存说明](https://github.com/IcyRyna/war-thunder-skin-skills/blob/main/docs/history/endfield-archived.md)。

解压安装包后保留完整 `wt-style-endfield` 文件夹；制作时提供目标车的真实模型、原生UV和必要贴图。包内工具辅助定位、合成与检查，构图仍需依据该车表面和用户要求完成。
