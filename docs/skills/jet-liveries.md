## 能做什么

- 处理角色素材，安排机身、机翼和尾面的人物位置与裁切。
- 在原生 UV 上绘制色块、线条、字标和其他图形，检查共享纹素与接缝。
- 修改颜色和材质通道，用模型与原尺寸局部检查实际效果。
- 保存分层设计源，整理 DDS / TGA、BLK 引用和预览。

## 包含的工具

安装包自带 UV 岛分析、设计绘制、材质生成、纹理检查、模型预览和 Composa 连接脚本。运行环境见[安装说明](../installation.md#运行环境)。

机型模型、原始纹理与角色素材按项目准备。这个 Skill 的范围是二次元固定翼喷气机；指定 Akamywek 画风时，可直接使用[对应风格包](akamywek.md)。
