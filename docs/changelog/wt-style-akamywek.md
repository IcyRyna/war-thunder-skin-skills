# wt-style-akamywek 更新记录

## 0.2.0 · 2026-10-26

按新的「研究证据 → 风格关系 → 载具语义映射 → 实做检查」工作流整理，发布为独立的 `wt-style-akamywek` 版本线。旧 1.14 标签与包保留。

- 研究 F2A、F16 惠惠、Su27、F15 四套原作，增加阵风鸭翼专项；来源、纹理身份与 33 条有作用域的规则可追溯。
- 单发常规尾翼、单发鸭式三角翼、双发融合翼身、双脊和双发鸭式分别建立布局。主线、伴形独立端点、负形、渐变序列与人物动作／标题／留白关系分开处理。
- 包含原生 UV 检查、分层编辑器生命周期、Blender 场景适配、布局损失检查、输入图与字体身份冻结，以及按表面和动作锚点生成独立素材的流程。
- 独立安装包自带所需脚本、参考、示例和许可证；不内置作者立绘、原作贴图、游戏模型或编辑器／Blender 程序。

验证记录：30 项绘制、UV 与布局检查回归通过；仓库工具 43 项测试完成（41 通过，2 项因 Windows 符号链接权限跳过）；实际 Composa 8192 分层保存／重开、Blender 原 UV 检查和内置生图素材链路已验证。原生 Adobe Photoshop 在审计环境不可用，PSD 操作未实测。J10C 已验证局部鸭翼迁移，单发鸭式整机布局仍待完整作品验证；尚未完成新整机作品的用户美术验收、独立重复或游戏动态验证。发布不将这些项目改为通过。

下载附件 `.skill.zip`，完整解压后把 `wt-style-akamywek` 文件夹放入助手的 Skills 目录。Python 3.11+；依赖见包内 `requirements.txt`。编辑器、Blender、字体、游戏与所需原始素材按实际任务准备。
