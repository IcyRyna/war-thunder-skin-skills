# 在线 3D 涂装预览

**[打开涂装工作台](https://IcyRyna.github.io/war-thunder-skin-skills/)**

这是实时三维查看器。拖动旋转、滚轮缩放、点击部件、切换视角和显示网格；模型显示可选 512 / 1K / 2K / 4K。默认演示车由程序生成，并非战雷游戏模型。

点击“打开模型”，选择自包含 GLB，或同时选择已装配的 OBJ、MTL 和颜色图，查看自己的载具与原生 UV。颜色贴图可替换；可添加透明图案、文字、色块，选区调色、画笔修补，保存独立图层工程和最高 4K 长边的颜色图。页面中选择的模型和素材在浏览器中处理。

## 导入涂装 ZIP 或文件夹

网页不能自行扫描电脑中的战雷安装目录。自动识别涂装对应车型、读取游戏资源和处理原生模型时，需要运行仓库中的本地提取工具：

1. 下载本仓库工具源码，保留 `toolkits/web-preview/` 完整目录。
2. 在 Windows x64 上进入该目录，运行 `./extractor/setup.ps1` 安装固定版本的解码依赖。
3. 运行 `python -B preview.py serve`，打开输出的本机网页，选择“打开涂装 ZIP”或“打开涂装文件夹”。工具会只读查找战雷文件夹、按 BLK 和实际模型索引识别车型，提取并绑定模型与颜色；带配套模型的包优先使用包内匹配模型。
4. 也可运行 `python -B preview.py init --vehicle ztz_99a --out ./work/99a --serve`。生成的 `scene/model.glb` 可以直接在在线工作台打开。

找不到安装目录时加 `--game-dir 'D:/Games/War Thunder'`。有多套配置或子型号时，需要从真实候选中确认。源涂装与游戏安装文件保留。详细格式、输入限制和命令行选项见[工具说明](../toolkits/web-preview/README.md)。

## 支持范围

- 模型显示清晰度与贴图导出画布分开设置；显示档位不会改变模型面数，也不会把 4K 输出降成预览尺寸。
- 新加装饰和 AI 保留的图层可单独选中、移动、旋转、显隐、锁定和修改；已经合进游戏贴图的旧装饰无法可靠自动拆层。
- 部件中文分类按名字推测，允许人工改名、归类和确认。共享 UV 会联动对应表面，需要三维核对。
- 当前编辑 RGB 颜色，未接入游戏反射、法线、AO 与完整 Dagor shader。导出的 PNG/贴图 ZIP 不是直接可安装的游戏包。

此工具的网页部署与正式 Skill 发版独立。既有正式版本、标签与 Release 附件不因网页更新而改变。
