# 在线预览与本地涂装编辑

**[打开涂装作品集](https://icyryna.github.io/war-thunder-liveries/)** · [本地工具源码与说明](../toolkits/web-preview/README.md)

## 在线版：只展示与调预览

进入每套作品介绍即可查看对应车型和涂装。内嵌窗口与“展开查看”都提供：

- 拖动旋转、滚轮缩放，以及斜前、左右侧、顶视和恢复全车。
- 512 / 1K / 2K / 4K 模型显示清晰度；默认 1K，按需渲染。
- 反射层开关、反射强度、接缝凹凸开关；读取配套 N 贴图中的材质数据。
- 展开页面可保存当前预览 PNG。

在线发布目录不包含编辑器模块。加装饰、改色、图层、贴图替换、部件分类修正、模型或工程导入、工程或贴图导出均只在本地版提供。旧编辑脚本地址返回 404，网址参数不能切换为编辑器。预览设置只影响当前页面，刷新重新载入网站预设。

## 本地版：导入与编辑涂装

1. 下载工具源码并保留 `toolkits/web-preview/` 完整目录。
2. 在 Windows x64 上进入该目录，首次运行 `./extractor/setup.ps1` 准备固定版本解码依赖。
3. 运行 `python -B preview.py serve`，打开终端输出的本机网址。
4. 选择“打开涂装 ZIP”或“打开涂装文件夹”。工具只读查找战雷安装文件夹，按 BLK 与实际模型索引识别车型、提取资源、绑定颜色与反射材质；带配套模型的包优先使用包内匹配模型。

本地也支持直接打开 GLB，或同时打开已装配的 OBJ、MTL 和颜色图。可加装饰、文字与色块，框选或圈选改色、画笔修补，修正中文部件分类，保存图层工程并导出颜色贴图。原始输入文件保持只读。

找不到游戏目录时加 `--game-dir 'D:/Games/War Thunder'`。有多套配置或子型号时，从真实候选中确认。输入限制、自动初始化与命令行方法见[工具说明](../toolkits/web-preview/README.md)。

## 显示与编辑范围

- 模型显示清晰度与本地贴图画布分别设置，显示档位不改变模型面数。实际贴图不足 4K 时保持原尺寸。
- 新加装饰与 AI 保留的图层可独立调整；合进底图的旧装饰不能可靠自动拆层。共享 UV 会联动对应表面。
- 反射、金属度和凹凸采用 PBR 近似预览，AO 与完整 Dagor 特殊着色器以游戏内为准。
- 本地编辑 RGB 颜色，暂不回写 N/AO；颜色 PNG 与贴图 ZIP 不能直接当作完整游戏安装包。

网页部署与正式 Skill 发版独立。本次只分开在线展示和本地编辑，正式 Skill 版本、标签和安装包保持原样。
