# 涂装制作中文术语

## 贴图与模型

| 名称 | 中文解读 | 为什么需要关注 |
| --- | --- | --- |
| UV | 三维表面在二维贴图中的展开位置 | 决定图形画在哪里、另一侧是否镜像、接缝能否衔接 |
| UV 岛 | 展开图中连续的一块表面 | 单块能连续绘制，跨岛需要检查方向与边界 |
| Atlas | 多个部件共用的一整张贴图 | 修改前要确认像素属于哪个部件 |
| Texel | 贴图中的一个像素 | 同一像素可能被多个表面共用 |
| DDS／TGA | 游戏读取的纹理格式 | 交付时保留正确格式、尺寸与通道 |
| Mipmap | 逐级缩小的纹理层 | 影响远处显示、闪烁与图形清晰度 |

## 颜色与材质

| 名称 | 中文解读 |
| --- | --- |
| Color／Albedo | 表面颜色图，保存图形、人物和配色 |
| Normal | 法线，描述表面微小朝向变化，影响受光 |
| AO | 环境遮蔽，表达局部遮挡关系 |
| Roughness／Smoothness | 粗糙度／光滑度，影响高光宽度与清晰程度 |
| Packed channels | 把不同材质信息分别存入一张图的颜色通道 |

不同车型和游戏材质对通道的解释可能不同，按目标资源和具体工具说明核对。

## 工程与发布

| 名称 | 中文解读 |
| --- | --- |
| Skill | 助手可调用的工作流，包含说明、工具和必要资料 |
| Profile | 描述目标载具资源和表面约束的配置 |
| CMPS | Composa 分层工程文件 |
| Candidate | 用于检查与审查的候选，还没有作为正式版本发布 |
| Release／Assets | GitHub 发布页及可下载的附件 |
| SHA-256 | 文件内容的指纹，用来核对包和素材是否一致 |
| Regression | 回归检查，确认一次修改有没有破坏原有行为 |
