# 中文快速上手

## 1. 选择制作方向

| 目标 | 选择 |
| --- | --- |
| 坦克等地面载具，终末地黑白黄工业风格 | `wt-style-endfield` |
| 固定翼喷气机，人物主题与机体图形 | `war-thunder-user-skins` |
| 固定翼喷气机，Akamywek 风格 | `war-thunder-style-akamywek` |

[下载中心](../releases/README.md)列出各条正式版本线，旧兼容包单独放在历史档案。

## 2. 下载完整安装包

进入对应 Release，打开 **Assets（附件）**，下载名称以 `.skill.zip` 结尾的文件。解压后保留 `SKILL.md`、脚本、参考资料和素材的相对位置。

| 文件 | 用途 |
| --- | --- |
| `.skill.zip` | 正式独立安装包 |
| `.source.zip` | 开发与重新装配所需源码 |
| `.legacy-assets.zip` | 单独保留的历史素材，按具体说明使用 |
| GitHub 自动生成的 Source code | 仓库源码快照 |

然后按[安装指南](installation.md)配置对应助手的技能目录和所需运行环境。

## 3. 准备制作输入

| 输入 | 提供什么 |
| --- | --- |
| 目标载具 | 游戏内名称、国家或版本，必要时提供对应模型 |
| 原始纹理 | 模板或 DDS／TGA，保留颜色与材质通道 |
| 主题素材 | 人物立绘、标识及来源，说明想保留的元素 |
| 风格参考 | 参考作品、配色方向，以及明确不希望出现的处理 |
| 输出 | 游戏包、可编辑工程、预览图，或其中几项 |

可以这样提出请求：

```text
使用 wt-style-endfield，为指定载具制作终末地风格涂装。
按该车原生 UV 构图，保留可编辑图层，交付游戏包和整车预览。
参考图和原始贴图随请求提供。
```

## 4. 看结果，再决定修订

先看整车构图，再看原尺寸细节和接缝。检查游戏文件与实际显示，明确认可的是整套还是具体部位。后续修改从保存的分层工程继续。

需要理解 UV、法线和材质通道时，查[中文术语表](terminology.md)。每个工作流的具体工具与边界见对应中文介绍。
