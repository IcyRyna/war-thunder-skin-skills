# 素材与参考

## 制作工具

本仓库的工作流、辅助脚本与设计资料用于 War Thunder 用户涂装制作。目标载具的游戏模型、原始纹理与实际项目素材分别按来源记录。

## Akamywek 风格

风格研究以 Akamywek 的公开飞机涂装为参考，包括深色与签名色分区、几何焦点、三角马赛克、字标和漆面处理。具体分析与构造方法随该 Skill 的参考资料提供。

F-15C「莱万汀」案例使用《明日方舟：终末地》官方举剑立绘与上市感谢插画的处理图。右翼眼脸修复取自同姿势的官方角色影片近景，左翼细节由已有回身插画超分得到。包内配图为翼面构图和最终贴图的对照。[终末地官网](https://endfield.gryphline.com/en-us) · [官方角色影片](https://x.com/AKEndfield/status/1873202280838905959)
