# 素材与参考

## 制作工具

本仓库的工作流、辅助脚本与设计资料用于 War Thunder 用户涂装制作。目标载具的游戏模型、原始纹理与实际项目素材分别按来源记录。

## Akamywek 风格

风格研究以 Akamywek 的公开飞机涂装为参考，包括深色与签名色分区、几何焦点、三角马赛克、字标和漆面处理。具体分析与构造方法随该 Skill 的参考资料提供。
