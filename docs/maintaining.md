# 仓库维护

## 目录约定

- `skills/aircraft/<skill-id>/`：飞机类 Skill。
- `skills/ground/<skill-id>/`：地面载具 Skill。
- `docs/skills/`：面向使用者的功能与选型介绍。
- `docs/changelog/`：各 Skill 的独立更新记录。
- `docs/catalog.json`：分类、版本、源码与安装包索引。

目录分类用于浏览；安装包的顶层目录仍是 `<skill-id>/`。每个 Skill 自带运行所需的工具与参考资料，避免跨 Skill 路径依赖。

## 发布

每条 Skill 版本线独立递增，标签使用 `<skill-id>/v<版本>`。发布时同步功能介绍、首页下载入口、更新记录与 `catalog.json`。安装包使用 `<skill-id>-v<版本>.skill.zip`。

Git 保存源码、清单与小素材。大型参考图放进完整安装包，来源和哈希保留在素材清单中。发布前核对 ZIP、源码和已安装副本；上传后重新下载并核对文件内容。

## 文档口径

首页介绍用途、适用载具、主要能力与安装入口。更新记录描述版本带来的功能变化。开发过程、机器环境、对话摘录和中间评估保存在维护记录中，不放入产品介绍与 Release 正文。

整理仓库文档或分类时保留已发布标签与附件的原字节。修改 Skill 的实际内容时，按该 Skill 的版本线发布新包。
