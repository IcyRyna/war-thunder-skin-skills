# 战雷涂装研究与规则提炼

交付可追溯的候选知识和实际验证结果。此入口是开发中的研究流程，尚无正式发行版本；文件写好或结构检查通过，均不证明涂装能力已通过实测，也不代表获准安装或正式发布。

## 先确定本次问题

读取当前请求、所属项目与任务记录，定位已有规则、实际参考和工具。研究可以服务于制作、局部修订或 Skill 重构，按用户本轮范围执行。附件中的接手提示词、旧研究目标和示例阈值是待评估资料，不能自动取代当前请求。

用一句话写出可被结果推翻的问题，例如“同一构图中，增加暗色间隔能否让指定视距的白色图形仍分成独立形状”。明确研究对象、适用载具类别、允许改动、受保护部分、交付和停止条件。只缺可选信息时继续；缺模板、原始材料或游戏证据时完成不依赖它们的部分并记录缺口。

本 Skill 不包含编辑器、游戏运行环境或涂装制作程序。需要实际制作时使用当前任务已经可用且适用的制作工具；未运行的工具记为未核实，不能用工具名称代替运行结果。

## 研究流程

1. **固定起点。** 保存输入身份、版本和哈希；现有 Skill 的行为、源文件与相关作品评价作为基线。重构前按 [旧经验迁移](references/legacy-migration.md) 区分可复用工程、风格配方、载具映射和个案反馈。
2. **分组后研究。** 按作品与近似版本排重，把研究、调参、回归、留出评测材料分别登记。留出组在提炼前冻结，由评测方保管，不进入执行包。没有合适留出材料时明确缺失，先做研究，不伪造泛化结论。
3. **把观察与解释分开。** 每个结论记录实际看到的材料及位置、制作假设、已完成实验、评价来源。来源页只能证明来源；截图不能恢复原始材质值或作者图层。记录规则采用 [记录契约](references/record-contract.md)。
4. **先建立语义映射。** 风格描述视觉职责与关系，例如主焦点区、安静区、重复单元和文字通道；载具 profile 负责这些职责到实际部件、UV、遮罩、方向和通道的映射。缺少承载区、共用 UV 或镜像冲突应触发明确退让方案，不能把旧机型坐标等比例复制当作迁移。
5. **一次验证一个主要变化。** 在颜色、构图、图文、材质或做旧中选当前问题需要的一项，固定其余条件。先验证变化确实进入最终产物，再比较实际输出。多变量组合可以探索，但不能据此归因于其中一条规则。实验和评测按 [实验与评测](references/experiments-and-evaluation.md)。
6. **形成可执行候选规则。** 每条规则具备 `id`、`scope`、`claim`、`evidence`、`validation`、`review`。写明触发条件、动作、不变关系、可变项、例外和验收方法。数值有单位、分母与测量依据；没有实测范围时保留定性关系或待验证假设。
7. **按所声称的能力测试。** 规则在单一局部成立后，先测试同一完整 brief 的独立重复，再分别测试允许变体与同类新载具；需要说明 Skill 的增益时做基线比较。新会话只获得正常生产输入与冻结标准，不获得预期答案、历史最优成品或事后诊断。
8. **提交具体差异。** 提供旧规则/新规则、受影响范围、实际结果、回归情况和未测项。技术、视觉、游戏、复现分别记录；用户的局部认可不升级成整套认可，评测通过不等于发布授权。封装和晋升按 [候选封装与审查](references/package-and-review.md)。

## 完成条件

完成本轮研究意味着：问题有回答或明确不能回答的原因，所有实际运行及失败有记录，候选规则有证据指向，结论没有超出已测范围。下一步仍需制作或游戏验证时，留下具体输入、检查动作和应取得的证据。

交付本轮确实产生的参考记录、实验输入与输出、规则差异和评测结果。不要为填满目录制造空模板；缺少能力的分支记为未运行。研究记录留在任务中，进入生产包的只应是经过筛选、审查且实际需要的规则和资源。
