# 从用途映射到目标部位

| 原作关系 | 目标车可选承载面 | 需要确认 |
| --- | --- | --- |
| 连续蜂窝模块带 | 本车侧裙、附加装甲或成组外箱 | 板缝、共享UV、机械间隙、目标像素 |
| 仪器与技术线路焦点 | 传感器外壳、平整盒体或装甲内嵌区域 | 正确材质槽，镜片/开口/机构保护 |
| 泄压或检修警示 | 真实功能对应的顶板或检修门 | 单板边界、文字朝向和用途；不是每个舱盖都写BLOW-OUT |
| 小型彩色识别 | 武器站护罩、镜壳或辅助盒体 | 留白、可读尺寸、色标层级；不强制蜂窝 |
| 源车网布质感 | 目标确实具有对应网布的表面 | 模型/材质存在；没有载体时改为本车合理图形 |

母版可以变成匹配新承载面的子版。声明源用途、保持的视觉关系、布局/数量变化与理由；子版重新检查几何、透明与有效细节。按目标真实物理比例映射，不能用非均匀UV拉伸把正六边形压歪。

目标车N/AO与结构不从源车移植。颜色母版不创建真实浮雕；新材质效果依目标shader的已确认通道制作并验证。
