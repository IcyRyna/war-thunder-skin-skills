# 独立透明元素与规整母版

assets/elements 保留12件原作抠图的生图提取记录，只用于研究或明确的原像素复刻；不能直接作为已验证的风格制作图形。风格制作从assets/production与统一catalog选择经过内容/几何检查的母版，并按真实承载面制作子版。

| 元素 | 去掉的内容 |
|---|---|
| 两组线路 | 像素迷彩、底板、边框、螺钉 |
| 蜂窝阵列 | 外侧载体板及周边杂图；蜂窝实体本身仍有灰色填充 |
| APS 组合 | 梯形底板与外框；保留仪器元素组合 |
| 雷达图形 | 深绿色屏幕底与框，保留网格和标记 |
| 线束 | 凹槽底与外框，保留线、连接器和夹具 |
| 五种警示/文字及检修标识 | 大面积黑底与边框，保留文字/警示图案 |

这是独立图形组合，部分组合里仍包含多个元素，不声称每根线、每个蜂窝都已分成单独文件。PNG 真实 Alpha 已检查；浅/深背景展示图是检查用合成，不替代透明 PNG。

生图提取不等于像素精确复制，可能改变细线交汇、字形、小字和边缘。技术透明检查不代替视觉保真审查。按[提取与规整](extraction-and-regularization.md)分别验收两个阶段；需要源像素保真时使用[受控修复](local-repair.md)。

按任务选择：独立贴花用 elements；忠实完整面板用 native/aligned；原始母版用 native/cutouts；大面积迷彩/网布底纹用 patterns。不要把这些不同用途混成同一个“全透明素材库”。

放大检查外轮廓、残片、格缝和两端裁切。对等边/等角的重复几何采用同一母版，修边与规整不得顺便全幅改亮、改色或增加源图没有的结构。
