# 原像素优先的提取与修复

## 四种文件身份

1. raw：原 DDS RGB 的矩形裁片，不是透明贴纸。
2. cutouts + masks：原尺寸透明抠图母版和显式遮罩。所有 RGB 像素与矩形裁片完全相同，只给新的素材覆盖 Alpha；它与游戏 C 的 Alpha 是两种语义。
3. aligned：紧裁与方向校正。10 件仅紧裁；BLOW-OUT 水平镜像，无插值；APS 旋转 110°，有插值，保留梯形。母版始终保留。
4. repaired：可选局部修复件。只有像素板与 APS 两件；不能把模型整幅返回当成精确原作。

## 受控修复

使用内置imagegen时以真实抠图作编辑目标，明确允许区与保护区。源、模型输出、遮罩、提示与结果哈希留在制作任务；未经约束的全幅输出不作为默认生产素材。

模型仍会改动内部结构，因此最终只回写许可遮罩。文字、已确认的单元数量、灯条与线路应在保护区；保真颜色修补保持原Alpha，需要清除背景残留时明确采用Alpha修边模式，不能混用。

apply_local_repair.py 对模型非透明包围框作显式比例检查，长宽关系差异超过 8% 就拒绝。只有在当前修复范围已人工核对时才能使用；8% 是自动拒绝阈值，不表示以内即视觉合格。边缘相似不保证自动对齐，仍看前后对照。允许区默认不超过可见源像素的 15%，这是局部修复保护门槛，可按明确的缺损记录调整，不是美术评分。

校验遮罩外 RGBA 逐像素相等、原 A 不变，记录实际变化像素数。若文字或灯条进入允许区，先缩小遮罩或增加保护区域。生成图看着更清楚、分辨率更大，不代表原作细节更准确。

## 换车型

把提取件视为有来源、有固有形状的图形模块。先选可容纳它的本车承载面。改变方向和物理尺寸时保留比例；跨板分割必须理解真实 UV 与遮挡。缺图先从同一原作纹理找完整对应件，最后才允许局部补画。新补出的部分明确标记为推测，不能反过来作为作者原始设计的证据。
