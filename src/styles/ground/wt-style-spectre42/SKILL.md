# SPECTRE42 · 0.1.1

在目标车自己的 UV 和材质上重建风格。AZUR 整车生产已完成并获认可；这一结果证明已测试流程能交付该车，不代表所有车型已完成迁移，也不把串行返工算成多次独立成功。能力与证据边界见[验证范围](references/validation.md)。

## 先辨认原作与目标的真实部位

读[原作分析](references/source-analysis.md)与[模型＋UV 双向对照](references/model-uv-method.md)。原包加载到精确原车型，模型里确认部件、方向、缝隙与遮挡，在同一材质槽的原始 C/UV 中确认文字、线条、蜂窝、边缘和共享范围，再反查模型。目标车按同样方法核实承载面；文件名、矩形 UV 裁片和宣传图都不足以确定部位。

源部位不存在时按用途重新设计或省略。原作 M1 Trophy 的伪装网不能当作 AZUR 的真实网布；遥控武器站外护罩与被它挡住的机枪本体也不是同一个承载面。材质槽与选择面不一致时先修正对照，不继续贴图。

## 先提取，再规整，再制作子版

默认 `style_transfer`；仅用户要求原像素复刻时使用 `source_reproduction`。从[统一素材索引](assets/catalog.json)按 ID、用途和允许模式选取。完整原作面板只作为研究/复刻资料，不能因它有透明背景就作为干净贴花。

按照[提取与规整](references/extraction-and-regularization.md)产出两个独立阶段：先分离真实图案与透明覆盖，再规整几何、连接关系和文字。生图可做概念、提取、去污染或目标适配子版，但每次结果都要检查。规则六边形、重复条纹和已知文字用统一几何母版或实际字体约束；生图再次输出仍歪斜时不得直接入库。

素材是母版，不是必须整块套入的成品。按目标部件尺寸与用途生成/绘制子版，记录母子哈希、保持项、变化理由与数量变化。保持六边形规则、线宽节奏、色彩层级；目标没有空间时调整布局或明确减量，不拉扯成菱形或压糊密线。使用 `precision_decal.py` 可从显式几何声明生成透明 PNG/SVG；它重新制作几何，不声称恢复原图丢失的像素。

## 整车与材质

先安排整车明暗、模块带、焦点与警示用途，再增加细节。保留炭灰大面、模块层次和少量功能性色标；不要给所有部件同样密度。蜂窝可用于装甲模块，仪器/盒体可用技术线路，小部件也可只保留黄青色标。按真实板缝停止图形；不强制每个机枪或镜组都贴蜂窝。

底材、N、AO 与机械结构来自目标车。完整 UV 检查必须覆盖小件、岛边与留边、下部钢面、背面和外壳，不用节点名含 MG/decor 或统一高度阈值保护整组金属。镜片、孔口、橡胶、网布与轮履按实际材质分别保护。所有颜色/材质变化使用明确遮罩，新增颜色不会自动产生真实浮雕。

## 颜色不能只在编辑器里看对

读[固定颜色契约](references/color-and-material.md)。贴花 PNG 的透明 Alpha、固定颜色 C 的涂层覆盖、打包 N 的数据 Alpha 是三种不同语义。先核实模型 shader；已确认不透明固定漆面的 C 使用 `set_tex` / `camo_skin_tex` 和完整覆盖，各级 mip 检查。真正 alpha-test 材质不得统一刷成 255，N.A 也不得当透明度改写。

`fixed_color.py prepare/bind/check` 将该门槛落实为可执行检查，`export` 提供经逐 mip 读回的无损 BGRA8 基线。合成器保留源 A 不等于最终固定漆面可继续沿用 A=0。遇到偏绿/偏色先查绑定、覆盖与实际游戏资源，不能先对全部 RGB 盲目加黑。

## 工程与交付

按[原生 UV 接口](references/native-profile.md)与[生产工具](references/production.md)冻结本车输入、材质、区域和共享 UV，再试贴关键部件、做整车布局与细节。合成前使用源模型/UV 对照、素材资格和最终细节像素预算检查；不能绕过它们后用 DDS 文件合格代替美术检查。

Composa 使用 `scripts/editor_batch.py` 的完整受控批次。独立载具会话共用同一个编辑器锁；每批打开、组装、保存、导出、关闭自己的文档，重开只用验证副本。保留其他人的文档。工具报画布正在拖动或 revision 已变化时不重放贴图动作，按日志及 revision 检查恢复。Blender 工程保持实际模型、活动材质与 UV 图像对应。

最终以游戏包 DDS 重绑模型，核对每个材质槽的来源哈希，提供七视图与三张独立整车图；预览不放入游戏 ZIP。技术、用户视觉、游戏和独立迁移分别记录。游戏没有实测的部分保持未实测；完成整车生产不自动证明游戏中所有状态。新车型作品完成后按其具体审查结果发布。
