# 原生共享 UV 与 WTG 接入的证据边界

普通 UserSkins 替换纹理不会改变 UV。共用像素若有方向冲突，两侧不可能独立绘制同一方向文字；一张旗旁再添一张旗也不会解决共享。先从实际几何分别光栅化两侧/其他部位，给出修改区共享交集，再选方案：独立原生UV改位、无方向图形，或用户明确授权的模型UV研究。

研究文件与实际游戏资源分开。只改 Blender UV 的截图不能证明游戏支持。99A 后续经用户授权，保留外观接入 WTG 原生 GRP：实际写回各LOD UV、扩展纹理并重新解析回读；197个活动节点、210710三角形是该样本的记录，不是工具通用能力保证。新的车型和资源格式仍需单独研究。本包不内置99A硬编码GRP写回器。

接入时记录原游戏模型与所有受影响纹理/config的哈希，成套备份与回退；不只备份一张C。候选先写新路径，验证模型资源身份、结构、各LOD和纹理尺寸/绑定，再原子替换明确的WTG文件。禁止在与原游戏资源共享硬链接时直接原地写入。目标必须是用户授权的client；不要顺手改Steam或其他安装。

首次模型更换可能需游戏重载；后续仅DDS变化可按已验证刷新路径查看，是否需要重启按实际情况记录。模型UV改变后，旧皮肤可能不再配套；回退须恢复模型与纹理整对。离线引擎近似和原生解析通过不等于实机视觉通过。

当前99A运行组为13文件、AZUR当前组为16文件，这些只是资源清单规模。每次部署从当前清单核对变更文件、实际安装哈希、临时staging清空和非目标安装未变；不要将文件数当成通用验收标准。
