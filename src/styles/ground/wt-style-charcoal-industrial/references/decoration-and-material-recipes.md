# 部位装饰与材质：做到丰富、完整、有层次

本轮设计取向是**装饰充分、局部精细的炭灰工业风**。以AZUR为第一范本，不能停在“一层灰底＋两张铭牌＋几条色标”。先做大色区与主图组，再补中尺度装饰、原皮标记和真实小件；需要安静的大面也要有漆面、结构与邻件材质差异，不能用“克制”解释漏做。

素材可以直接取用或由AI按车型重排。下面是默认制作内容；目标车没有的部件不编造，用户明确指定的保留、撤除或布局优先。

## 三个尺度同时设计

| 尺度 | 默认要有的内容 | 怎样避免太素 |
|---|---|---|
| 整车与大面 | A/B/C灰区穿插；首上几何、炮塔焦点、侧裙蜂窝带、顶部警示和车尾暖色呼应 | 不把车体/炮塔各刷一种灰；没有贴纸时底色仍能读出板面层次 |
| 部位与板件 | 身份图组、成组警示、蜂窝大小变化、短刻度、边角块、局部条带、真实设备标识 | 主图旁安排有用途的副层级，外围与板缝、把手、盖板相呼应；不只贴一个孤立大字 |
| 小件与近景 | 原皮小字、标线、铆钉/焊缝、螺栓、铰链、插头、卡箍、防滑颗粒、玻璃/橡胶/金属差异 | 原皮可用细节先保住；缺少层次的区域再增加合适的小图形或材质区别，不靠全车随机微字填空 |

“小灰块可选”只表示可以选别的副装饰方式，不表示首上或顶部可以省略设计。原皮细节已丰富时，善用它们即可；没有原皮标记的板件，则从下表选择适合其结构的副装饰。

**丰富度按职责判断。** 大面积蜂窝和数码块只证明有纹样，不同时证明本车身份、副标识、原生小件和材料差异都完成。先隐藏纹样看大灰区，再看主字/图组能否成为焦点，最后看小件。装备名（如D-TECH）承担装备标识，不自动等于整车身份；用户选择无字时用有意设计的图形承担该位置，不强制补字。已经很密的区域，优先整理主次、恢复真实小件和材质，不继续叠第三种满铺纹样。

已有作品过密时先在真实分层工程中降低副纹样对比/不透明度，保留大灰区、蜂窝主带和必要微标；不必删掉全部细节。身份图组可将车名/型号放主层、已核实装备词放小副行，加入与现有风格一致的短刻度或徽记。左右沿各自实板排版并测实际图形是否越界。A7HU采用两侧LEOPARD/2A7HU主标、D-TECHNOLOGIE副行，车体/附甲数码块25%、炮塔35%；这些比例只描述该次整理，不是所有车的固定透明度。

## 材质默认分工

这里给的是视觉目标和部件对应，实际R/B按本车shader和转光结果选择。不得用一张跨车固定R/B表替代材质判断。颜色角色A/B/C/F仍默认34/47/65/26；材质不同不必每件都换颜色。

| 表面/部件 | 默认材质与观感 | 需要留下的细节 | 不应做成 |
|---|---|---|---|
| 主体装甲大面 | 中性炭灰细磨砂涂层，宽而柔的高光，板面间用A/B/C建立层次 | 原有焊缝、接缝、铸造/轧制微纹、适量结构阴影 | 均匀纯灰平板、全车亮铬、烘焙大脏斑 |
| 炮塔次级板与检修盖 | 与主体接近的半哑涂层，按板形选B或少量C | 盖板边、铰链、锁扣、原有编号/方向标记 | 每块盖板都亮白描边，或全都与主体同色同光泽 |
| 蜂窝装饰区 | 暗实心格与少量亮格，反射克制；相对主体有可辨的轻微表面差异 | 格内层次、边缘暗线、真实板缝 | 全白空心网格；把每个色格都做成夸张压铸凸块 |
| 观瞄/火控外壳 | F深灰黑，较集中但受控的高光，顶/侧/窄框完整 | 原小字、旋钮、线缆、壳体分件与紧固件 | 黑金双色黄边；整壳和镜片一起喷黑 |
| 镜片与灯罩 | 原生光学/透明或半透明材质，保持真实色调及必要反射 | 镜片边框、镀膜层次、灯内结构 | 人造整片蓝镜、消失的反光、统一Alpha255 |
| 裸露枪体、轴、活动锁件 | 深色枪钢/发黑金属，局部比涂层更紧的高光 | 原刻字、机构边缘、有限真实接触亮边 | 枪体塑料化、每颗螺钉刷银、全车“战损”干刷 |
| 枪托、握把、胶垫、线缆 | 深灰黑聚合物/橡胶，较软且低反射 | 原防滑沟槽、线缆包皮和接头分界 | 与枪钢同一高金属度或一片无结构黑 |
| 炮管/热护套/炮根 | 枪钢、涂装护套、布套分别处理；克制深灰，卡箍与分段可读 | 原套缝、卡箍、温度标记或确实存在的刻字 | 整根同材质圆柱、默认彩色环带、虚构烧蓝 |
| 防滑行走面 | 比邻近装甲更粗的颗粒与更散的高光，边界按原板块 | 原防滑边界与可信细粒；需要时按实际分辨率重建 | 一整片平黑贴纸、过大砂砾或压住警示文字 |
| 网布、帆布和绑带 | 原生织物/网布材质及裁切，低反射，褶皱跟随实际结构 | 织纹、孔洞、束带、扣件、合理AO | 把普通金属纹理铺到网布、涂死孔洞、虚构动态效果 |
| 备用履带、拖缆和工具 | 钢件、橡胶块、木/聚合物手柄分别判断；钢件用深灰或原生合理表面 | 链接边、钢索股线、扣环和原有手柄结构 | 整组刷成同一种灰塑料，或涂到运行履带 |
| 灯具、反光片、警示小板 | 透明件/反光材料保持原生；外壳按本车涂装 | 原红/琥珀色、小白片、支架与导线 | 当普通漆面压灰，或因其鲜艳而无依据删除 |

## 逐部位怎么搭配

| 部位 | 材质安排 | 主装饰 | 副装饰与原皮利用 |
|---|---|---|---|
| 首上主板/附加装甲 | 主体细磨砂，按真实模块穿插A/B/C；原防滑单独处理 | 沿板缝的大几何切分；少量低对比小块可选 | 优先恢复原有小警告、编号、箭头、扣锁标记；再选短刻度、角部小块或局部窄条，避开灯、孔口和铰链 |
| 首下与前向实板 | 较深主体涂层，折边和拖具材质分开 | 本车身份字标＋可选型号/主题副行；无可读面时改无字图组 | 配短橙黄斜条或角部色块；利用原拖曳标记、原编号、紧固件，不把大字藏在履带或拖具后面 |
| 前挡泥板/灯具护架 | 涂装板与橡胶挡片分开；灯罩保持原生 | 主体灰区向前缘自然收尾 | 可用短边条、小编号或包内色标；保留灯线、铆点、反光片及原有提示，不让左右机械相同而忽略实际结构 |
| 炮塔正面与前角 | 主装甲磨砂、炮根与布套独立；折面用灰阶区分 | 局部较大蜂窝/几何焦点，与侧裙细蜂窝形成尺度差 | 适合的实板上配小三角、短刻度或零件身份；原孔口、烟幕弹、紧固件作为真实节奏，不给工作面画纹样 |
| 炮塔侧面主焦点 | A/B主面搭配少量C，图形印刷与底漆同面而非额外厚金属牌 | 本车车名/型号、蜂窝徽记、确有依据的装备标识组成图组 | 主字＋小副行＋图标/短刻度形成层级；保留合适的原生数据牌、安装箭头、锁扣；左右分别排版 |
| 炮塔后侧窄肩/条形板 | 与主装甲衔接的次级灰，折边与侧壁完整 | 低对比小块、窄蜂窝、短条带三者按板形选择 | 原检修字、扣具和小插座优先保留；有连续母材关系时共享图案方向与节距，不把窄肩整条遗忘 |
| 侧裙主带 | 细密蜂窝涂装，保留板面粗糙度；框条/橡胶下摆另分材质 | 按真实板缝分段的连续细蜂窝，稀疏亮格 | 选择少量模块编号、角部标记或短色标，保持前后尺度；复用原固定螺栓、检修小字和挂点，不在每格重复大徽记 |
| 侧裙后段/折边/下沿 | 按实板、压条和橡胶分类，光泽连续但不一锅涂 | 主带在完整后半段和确定的折边上收尾 | 末端可用短灰块/暖色小警示回应车尾；保留原有铰链和固定点，禁止用遮罩侵蚀把细边裁没 |
| 炮塔顶面基础 | 顶板灰阶、防滑、设备金属与软材质分开 | 真实盖板的几何关系＋完整顶部警示作为焦点 | 原舱盖字、方向箭头、检修标线、紧固件、防滑颗粒保留；空白大板可增局部小块/短刻度，设备周围留出可读间隔 |
| 顶部维护/弹药盖 | 喷涂盖板与防滑分开；把手/铰链有独立材质读感 | 适用文字＋两侧/两排斜条组成整体；泄压盖才使用BLOW-OUT | 保留原把手标记、盖板编号和开合箭头；同位置已有正确原生警示时可保留并围绕重排，无需叠一套重复文字 |
| 舱盖圈、铰链、扣锁 | 主盖板/涂层；活动金属、密封胶圈分别处理 | 借真实圆/折线边界形成次级灰阶 | 原锁止刻线、开合箭头、橡胶缝与紧固件即是细节来源；没有依据不加满圈假仪表刻度 |
| 观瞄/火控/传感器外壳 | F深灰受控高光，镜片、遮光罩和密封件独立 | 深色材质本身作为焦点，少量真实识别图形 | 原序号、旋向标记、连接口小色环、线缆卡箍可保留；新增黄青短标只放合适壳体实面，不沿镜片涂黄框 |
| 机枪/遥控武器站 | 护罩炭灰、枪钢较紧高光、枪托/握把哑黑、弹链按原材质 | 护罩上少量成组黄青色标或适用小识别 | 原枪身刻字、射击/维护小标、握把沟槽、导线、弹箱标记和金属扣件形成近景；枪管不默认加彩条 |
| 炮管/炮根/防盾 | 炮管/热护套/布套分工，卡箍与主体有细微区别 | 优先利用真实分段与灰阶，不默认大图案 | 原温度指示、套筒编号、小字和卡箍标记合适则保留；没有原标记时可保持克制，用接缝和材质完成细节 |
| 发动机盖/车体后上方 | 盖板、防滑、格栅外框和叶片分开 | 按盖板结构设置灰区和适用小警示 | 原加注口标识、检修编号、吊点箭头及防滑边界优先利用；实板允许装饰，格栅空隙不当画布 |
| 车尾两侧实板 | 暖色图形配深色涂层，灯组/排气周围独立材质 | 左右可见实板上的橙黑/橙黄黑短条，随板形重排 | 配原车号牌、尾灯反光片、拖曳标记和维护小字；有原生正确警示可沿用并统一布局，不能只新贴橙条而留下旧底框 |
| 储物箱/附件盒/备用件 | 箱体涂层、钢扣、橡胶/织物绑带、备用履带分别处理 | 箱体灰阶或适用小型编号图组 | 利用原小铭牌、压印字、绑带缝线与扣锁；避免每只盒子都贴相同大标签；可见备用钢面要完成 |
| 拖钩/拖缆/外置工具 | 真实钢、橡胶、木/聚合物等分开，适量原生接触亮边 | 以真实结构和材质差异为主 | 原色环、编号、固定卡箍可保留；新警示仅放附近实板，不把整根钢索画成双色条纹 |
| 负重轮/主动轮/诱导轮 | 金属轮盘与轮缘橡胶分开；轮盘按本车范围协调灰阶，运行履带独立保留 | 真实轮盘分件和材质关系，不默认彩色轮圈 | 保留原轴盖小标、螺栓、胶胎刻纹及实际色点；不能把轮胎和轮盘一并涂成亮金属 |
| 天线座/烟幕发射器/小型支架 | 外壳涂层、接头/支架金属、绝缘或保护帽分别按实际材料处理 | 克制的结构灰阶，承担连接主图之间的近景细节 | 利用原小编号、线缆、安装标线和帽盖区别；装饰只上已确认实面，发射口/传感器工作面保留 |
| 百叶/孔口/设备工作面 | 叶片、黑腔、外框和传感器工作面分别分类 | 外框只在真实实板上延续对应灰区 | 利用原栅格、叶片和结构阴影；工作面不靠装饰填满，邻近实板可做编号/短色标，保持原功能边界 |

## 原皮小装饰怎样进入新风格

先按[原皮细节复用](native-skin-detail-reuse.md)清点并分层，再做中性底漆。原有细节可以直接保留、保留形状后调整颜色、提取为本车图形或换成同用途的新图形。

原皮已有正确的小警示、细刻度、序号或彩色环时，优先保留其用途和位置，用新的大灰区和主图组围绕它组织。不要先全刷灰再随意补假细节。原生小图与新增主图冲突时，AI调整布局或选择保留其中一套；不把两套文字重叠。

“利用原皮”也不是恢复整片原迷彩。原生脏斑、旧迷彩、错误身份和烘焙大阴影仍分开处理；细结构、合理AO和真实材质不要跟它们一起抹掉。

## 明确的完成观察

- 中距离看首上、两侧、顶部、车尾：每个可见主要区域都有清楚的灰区/主图职责，以及适合本车的副装饰或可见原生细节。某区只剩一色底漆时回到本表补设计。
- 近看机枪、观瞄、舱盖、附件箱和车尾：能分辨涂层、钢、聚合物、玻璃、织物及原皮小字/标线；不能只有几张高分辨率大贴纸而小件全灰。
- 远看仍以整车几何和蜂窝主带为先。增加细节后若主焦点消失，调整亮度、尺度和疏密，不简单全部删除。
- 原皮标记不一定可读为文字；可信微纹可以保留，不能锐化猜成假词。新承担阅读任务的文字仍满足实际字高与斜视检查。
- 上述是实际视觉检查，不用贴纸数量、覆盖百分比或“填完字段”自动替代。六区和局部可复用现有模型预览，不自动生成七视图。
