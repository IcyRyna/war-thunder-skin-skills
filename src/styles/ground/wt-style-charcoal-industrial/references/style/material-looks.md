# 材质观感

颜色和材质是两套层次，要一起完成。同色不同材质、同材质不同朝向都能形成层次；C 不能替代 N.R/B 和法线。全车一个 N 值，或为了"有材质"把金属度拉满，都不对。打包 N 的语义要按实际 shader 核实，已验证的地面 shader 是 R=光滑度（inverse roughness）、G=法线 X、B=金属度、A=法线 Y。N.A 是数据，从来不是透明度。应用方法见[材质参数](../contracts/material-parameters.md)。

## 相对关系（默认）

从哑到亮、从非金属到金属，排序如下：

1. **蜂窝区**：反射最轻，只比主体多"一点"差异，格内保留细节。
2. **车体主体**：克制的磨砂金属漆，高光宽而柔。
3. **炮塔主面**：比车体多一点轻金属反光。
4. **观瞄与火控壳体**：颜色最深（F 26），金属度最高，高光集中而受控，靠深色和高光来突出。

镜片读作玻璃，枪钢的高光比漆面更紧，聚合物和橡胶低反射，布料、网布、防滑分别处理。

已用过的数值只当起点和相对参照，不跨车照搬；最终值按本车 shader 的同光照和转光效果决定：

| 来源 | 车体 R/B | 炮塔 R/B | 蜂窝 R/B | 火控壳体 R/B | 其他 |
|---|---|---|---|---|---|
| AZUR 历史遮罩中位数 | 115/95 | 173/143 | 73/68 | 195/230 | 圆镜内侧 B147 是待游戏反馈的试验 |
| A7HU 本车选择 | 115/95 | 145/125 | 80/75 | 144/229 | 武器站护罩 95/50，独立观瞄外壳 150/110 |

需要金属插片或盖板时，用过的样本：
- **缎面灰银**：C≈143、R≈145、B≈229，磨痕对比约 18，用来压住天空蓝镜面；
- **枪灰黑**：在缎面灰银基础上把 C 压到约 82，磨痕对比收到约 6。

## 部件观感

| 表面 | 应该读作 | 要留下的细节 | 不要做成 |
|---|---|---|---|
| 主体装甲大面 | 中性炭灰细磨砂涂层，宽而柔的高光 | 焊缝、接缝、铸造或轧制微纹、适量结构阴影 | 均匀纯灰平板、亮铬、烘焙的大脏斑 |
| 次级板与检修盖 | 接近主体的半哑涂层，按板形用 B 或少量 C | 盖板边、铰链、锁扣、原编号和方向标记 | 每块盖板描亮白边；所有盖板与主体同色同光泽 |
| 蜂窝区 | 暗实心格加少量亮格，表面差异轻微可辨 | 格内层次、边缘暗线、真实板缝 | 全白空心网格；每格做成夸张的压铸凸块 |
| 观瞄与火控外壳 | F 深灰黑，集中但受控的高光 | 原小字、旋钮、线缆、分件和紧固件 | 黑金双色、黄边；整壳连镜片一起喷黑 |
| 镜片与灯罩 | 原生光学材质，保留色调和反射 | 镜框、镀膜层次、灯内结构 | 人造整片蓝镜；反光消失；统一 Alpha255 |
| 枪体、轴、活动锁件 | 深色枪钢或发黑金属，高光比涂层紧 | 原刻字、机构边缘、少量真实接触亮边 | 塑料感；每颗螺钉刷银；全车干刷"战损" |
| 枪托、握把、胶垫、线缆 | 深灰黑聚合物或橡胶，较软、低反射 | 防滑沟槽、线缆包皮、接头分界 | 和枪钢同样的高金属度；一片无结构的黑 |
| 炮管、热护套、炮根 | 枪钢、涂装护套、布套分开处理，整体克制深灰 | 套缝、卡箍、温度标记 | 整根同一材质；彩色环带；虚构烧蓝 |
| 防滑行走面 | 颗粒比邻近装甲粗，高光更散，边界跟随原板块 | 原防滑边界和可信的细粒 | 平黑贴纸；过大砂砾；压住警示文字 |
| 网布、帆布、绑带 | 原生织物，低反射，褶皱跟随结构 | 织纹、孔洞、束带、扣件 | 金属纹理铺到网布上；涂死孔洞 |
| 备用履带、拖缆、工具 | 钢件、橡胶、手柄分开；钢件深灰 | 链接边、钢索股线、扣环 | 整组刷成同一种灰塑料；涂到运行履带上 |
| 灯具、反光片、警示小板 | 透明件和反光材料保持原样，外壳按本车涂装 | 原红色或琥珀色、小白片、支架和导线 | 当作普通漆面压灰；因为太鲜艳就删掉 |

## 去污与磨砂

去污只去低频污迹、斑驳和烘焙大阴影，保留细颗粒、焊缝、卡箍、接缝、合理 AO 和原皮的有效印刷标记。C 里的色斑和 N 里的粗斑可能都在，只重涂 C 不一定干净；需要动 G/A 时，只在明确的漆面范围内处理低频斑，并如实记录。不要在已经处理过的 N 上反复乘系数，导致越处理越平。

## 防滑

素材包里有三套现成的高清防滑：方片 2048²、长片 4096×2048、窄条 4096×512。每套的 color、coverage、normal-rgb、packed-n 都来自同一个高度场。参数起点：

| 项目 | 起点值 |
|---|---|
| 颜色 C | 27/27/27，颜色噪声 1.3 |
| 光滑度 R | 中心 48 |
| 金属度 B | 128 |
| 坡度 RMS | 0.22 |
| Gaussian σ | 1 像素 |

- 颗粒大小按物理粒度乘以目标面的实际纹素密度来定，目标 mip 上的特征直径至少 2 像素。远处 mip 颗粒自然消退是正常的。
- 只在真实防滑区按板形裁切，保留缝隙、铰链和把手；不要为了"有材质"给全车加防滑。偏色要写明理由。

## 印刷图形

普通的印刷字和色标是薄涂层，主要改变 C，不自动加厚边、凹凸或金属度。凸字、金属牌、反光材料和原生粗糙度变化，按实际部件单独处理。已有的 R/B 印迹要保留或重建时，按真实范围处理。
