# 炭灰工业审美总纲

**唯一范本：勒克莱尔 AZUR（v29）。** 本页的形状、颜色和数值都取自 AZUR 的运行贴图（`leclerc_s2_body/turret`、`leclerc_azur`、`leclerc_s2_gun`），并对照了三张整车图（独立素材包 `references/azur-current-v29/`）。学的是它的构成方式，按目标车的真实板面重排，不复制贴图。用户对当前车的明确要求优先于本页。

**一句话：** 中性炭灰底上压着大块直边斜切碎片。侧裙铺满带亮格的实心蜂窝，炮塔尾舱侧面铺满暗色数码块，首上有一簇渐散的浅色数码块。炮塔侧放一组小而精的身份铭牌，首下是一行橙色斜体车名，顶部泄压盖是一块橙黑人字斜条，车尾两侧各一块橙黑短条。纹样覆盖充分，对比克制，彩色极少。

## 1. 颜色

漆面全部中性：R=G=B，漆面样本 |B−R| 均值 ≤2，p95 色度 ≤3。下面都是 8 位 sRGB 贴图值，不是渲染截图吸色。

**灰阶。** AZUR 实测：车体涂装面 p10/p50/p90 = 30/34/65，炮塔 = 27/35/65。底色就是 34 左右的一个灰，层次全靠下面四类元素叠出来：

| 元素 | AZUR 灰值 | 作用 |
|---|---|---|
| 主体底色 A | 32–36（中位 34） | 车体和炮塔的大面 |
| 浅斜切碎片 C | ≈64 | 少量大块浅色碎片，跨部件呼应 |
| 深斜切碎片 | ≈20–24 | 与浅碎片成对出现，压出深浅节奏 |
| 数码块五档 | 27/33/39/47/54；首上浅簇可到 68–84 | 尾舱侧面满铺；首上成簇 |
| 蜂窝格 | 20–52，偶有 64 | 侧裙主带；亮格另计 |
| 蜂窝亮格 | 152–168（浅灰白，不是纯白） | 侧裙的稀疏亮点 |
| 火控壳体 F | 25–28（中位 26） | 观瞄和火控黑金属 |

`style-policy.json` 里的 A/B/C = 34/47/65 是落地起点。其中 B=47 是给其他车型的中间档，AZUR 本身用深浅碎片和数码档实现这一层。60/30/10 只是可见涂装面积的构图建议，不是验收比例，不按 UV 像素算。

**彩色。** 彩色只出现在警示、身份和微色标上，全车加起来面积极小：

| 用途 | AZUR 实测 sRGB |
|---|---|
| 顶部 BLOW-OUT 斜条与字 | 橙 228–232/120/24（`#E67818`），黑底约 20 |
| 首下车名与 » 箭头 | 琥珀 234/138/36（`#EA8A24`），配橙 228/120/24 |
| NO STEP 字与虚线 | 琥珀 216/138/54（`#D88A36`） |
| 车尾短条 | 琥珀 205–211/144–148/36–40（`#D39427`），配橙 209/102/24（`#D16618`），黑底约 17/19/21 |
| 身份铭牌主字 | 冷白 192/200/208（`#C0C8D0`），副字灰约 136 |
| 铭牌旁小三角 | 橙 228/120/24 |
| 微色标 | 青 84/162/180（`#54A2B4`）、琥珀 216/138/48（`#D88A30`） |

- 警示色都放在黑色衬底上，不直接压在灰漆上。
- 不往贴图里烘焙光照。
- 这些不是本风格要素：大白线路、大徽记、日环、彩色炮管带、国旗。旧版 AZUR 的白色电路线和 APS-HUNTER 字样在 v29 已经撤掉。

## 2. 四种纹样尺度

**大斜切碎片（最大尺度，先定）。** 浅色（≈64）和深色（≈20–24）的大块直边多边形，形状是三角形和梯形碎片，斜切线可以跨板缝、跨部件连续。它们在首上、炮塔、炮管上形成整车的大节奏。

- 一块板上只出现一到两片，不切碎。
- 炮管上的大区可以是顺管身的长曲线分区。
- 首上不铺蜂窝，靠碎片和数码簇成立。

**数码块（中尺度）。** 正方形像素块，AZUR 节距约 65 mm，相邻折面共用原点和方向。用法有两种：

- **满铺带**：炮塔尾舱侧面，用 27–54 五档暗灰铺满整片板面，低对比、连续。
- **渐散簇**：首上只放一簇，浅块（最亮到 84）与深块（约 20）混合，从一处向外变稀，大部分首上仍是底色。

不能把数码块撒满全车，也不能在首上散成零碎小块。觉得过密时，先在分层工程里降低不透明度，不要删光。

**蜂窝（主带与焦点）。** 实心正六边形，格间是深缝（约 20）。

- **侧裙主带**：格子是 3–4 档暗灰的随机填色（20–52），每约 25–30 格放一个浅灰白亮格（152–168），每块裙板顶边中央有一个小白色缺口标。裙板按真实分段，上下排之间有深色横条，前后段密度一致，一直铺到栅格装甲为止。
- **炮塔焦点**：只在炮塔前斜板一块板上，用大约大一倍的六边形，填多档灰，其中一两个格稍亮，格缝更粗。
- 两种尺度一眼能分开。正六边形一律等边，按板宽重算列数，不拉伸。

**防滑颗粒（微尺度）。** 首上和炮塔顶的行走面是细颗粒防滑，近看有砂感，远看不改变灰阶。

## 3. 焦点与安静面

AZUR 的焦点只有下面几个，其余都是有磨砂和结构的安静面：

1. **炮塔侧身份铭牌**（左右各一组，独立排版）：
   - 文字列：粗斜体宽体大写主字 LECLERC，后跟橙色小三角；下面是小一号的粗斜体 AZUR，再下面是常规体编号 H-01。
   - 图标：7 个描边六边形组成的蜂窝花，两端两个是网点填充。
   - 微色标：图标两侧各一列，上面 3–5 条青色短横，下面 2 条琥珀短横。
   - 整组小而精，放在炮塔侧中部的平板上。两侧都按观看方向排成"文字在左、蜂窝花在右"，因此一侧文字靠车头，另一侧靠车尾，字始终正读。
2. **首下车名**：一行粗斜体大写的车名和变体（LECLERC … AZUR），两端带 » 箭头，琥珀色，印在下前板的深色带上。
3. **顶部泄压盖警示**：见第 4 节。
4. **车尾**：两侧实板各一块橙黑斜条短板（约 4 条斜条），上下边各有一道琥珀细边，黑底。
5. **炮塔前斜板大蜂窝**与**侧裙亮格**：是纹样中最亮的点。

怎样在其他车型上做到同样丰富，见[装饰手法](decoration-playbook.md)。没有用的东西：长电路线、大徽记、满屏小字。装备名不等于整车身份。已经很密的区域，先整理主次、恢复真实小件和材质，不再叠第三种满铺纹样。

## 4. 顶部警示的 AZUR 做法

- **泄压盖**：黑底上两列镜像的橙色平行斜条（每列 7–8 条，条宽≈条距），两列方向相反，组成人字纹。BLOW-OUT 竖排在两列中间，同为橙色。整组占满泄压盖。
- **炮塔顶边缘**：一条琥珀色虚线沿板边走，NO STEP 小字嵌在虚线正中。
- BLOW-OUT 只用于核实过的弹药泄压盖；NO STEP 用于实际不能踩的边缘或设备板。
- 盖板形状不同时，保持"两组镜像斜条夹着警示词"的关系：竖长盖板用 AZUR 的两列人字；横宽盖板改成上下两排斜条、字在中间（素材 `a6hel-roof-ammo-warning`）。默认带黑底；用透明版时，确认斜条在深灰底上对比足够。

## 5. 六区完成度

| 区 | AZUR 怎么完成 | 常见遗漏 |
|---|---|---|
| Z1 首上与车体前部 | 大斜切碎片、一簇渐散数码块、防滑颗粒；首下琥珀斜体车名 | 单色首上；首上铺蜂窝或碎块；文字被备用履带或拖具挡住 |
| Z2 炮塔正侧装甲 | 前斜板大蜂窝；侧面身份铭牌；尾舱侧面满铺数码块；碎片跨过侧面 | 只贴一个大标志；整侧同灰；文字跨缝；炮根留原皮 |
| Z3 侧裙 | 带亮格的实心蜂窝主带，加顶边白缺口标，按裙板分段铺满 | 后半段、折边、窄压条漏铺；框边残留 |
| Z4 顶部与设备 | 防滑颗粒；泄压盖人字斜条；边缘 NO STEP 虚线；机枪护罩少量色标 | 顶部一色；只放一张小黄牌；机枪本体或枪托漏涂 |
| Z5 观瞄与特殊材质 | F 深黑壳体覆盖顶面、侧壁和框边；镜片独立 | 只改了顶面；黑金属画成黄线；镜片 Alpha 被破坏 |
| Z6 车尾 | 两侧橙黑斜条短板；尾部钢面和备用件完成 | 车尾素灰；只做一侧；旧条纹重影；涂到格栅或尾灯 |

目标车没有某种设备时，写明替代内容，不虚构。

## 6. 默认不做

下面这些是用户否定过的做法，或者是 AZUR 已经撤掉的元素，都已转成默认规则。目标车有明确理由、或用户当次另有要求时才例外：

- 首上铺蜂窝，或首上散落零碎小灰块。首上只放一簇渐散的数码块。
- 顶部警示缩进盖板的空闲角落，或只放一张小黄标签。
- 身份铭牌加外框和底板。铭牌直接印在装甲上；警示斜条才用黑底。
- 白色电路线或折线；武器站铺大蜂窝或线路。护罩只留少量黄青色标。
- 没有依据的功能词（APS-HUNTER、ELECTRONICS ACCESS、给没有泄压盖的板写 BLOW-OUT），或把别车车名留在新车上。
- 宽选区导致的银白、亮金属误涂；高光滑材质把整片映成天空蓝。
- 黑金双色，或给黑金属壳体描黄边。
- 火控壳体比主漆亮。
- 车尾只做一侧；旧橙条在新底漆下留下底框或整片偏浅。
- 机枪本体、枪托、可见备用履带保留原皮。
- 去污时把细磨砂、焊缝、卡箍一起抹平。
- 中系车自动加国旗，或把某车的装备名（FY-4 ERA、D-TECHNOLOGIE）当默认。
- 色标被把手挡住；两侧色标到主图组的距离不等。

## 7. 交付前看一遍

- 缩小看整车：大斜切碎片的深浅节奏是否先被读到？隐藏贴纸后，整车是否仍像 AZUR 那样有层次？
- 看首上和顶部：碎片、数码簇、防滑、警示是否都到位，而不是一色盖板加一张黄牌？
- 看左右和车尾：蜂窝后半段、尾舱数码带、炮根、小件、两侧车尾斜条是否完整？有没有旧框或白影？
- 看贴纸：车名、编号、警示是否都有本车的真实语义？字号够读吗？左右是否分别排版？
- 转动光照：主体磨砂、蜂窝的轻反射、深黑壳体、玻璃、橡胶能否区分？去污后还剩微表面吗？
- 以上都在最终 DDS 实际绑定到模型后看。技术通过、离线视觉、游戏反馈和用户认可分开记录。
