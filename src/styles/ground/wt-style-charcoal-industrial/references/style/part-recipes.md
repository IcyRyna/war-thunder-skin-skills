# 逐部位做法

开工前先为首下身份、炮塔侧图组、顶部警示和车尾短条找好真实可见的承载面，再安排底色、蜂窝、防滑和小块。每个部位都要有三层：纹样场、焦点或副装饰、小件与原皮细节（见[装饰手法](decoration-playbook.md)，那里有密度预算和"太素"时的补救顺序）。副装饰不规定数量，原皮细节已经丰富时可以直接承担副层。颜色和材质数值见[审美总纲](aesthetic-direction.md)与[材质观感](material-looks.md)，文字规则见[贴纸与文字](decals-and-text.md)。

机器入口是 `style-policy.json` 的 `part_recipes`（13 项）和 `vehicle-review.template.json`。AZUR 默认已写进机器规则，`vehicle_review` 会强制检查：

| 部位 | 必需元素 | 可选元素 |
|---|---|---|
| upper_glacis | large_gray_geometry、native_antislip、**pixel_cluster** | — |
| lower_glacis | vehicle_wordmark | end_chevrons、paired_short_warning_stripes |
| turret_side | local_large_honey、vehicle_identity、**rear_pixel_band** | equipment_mark（本车确有装备时） |
| turret_roof | large_gray_geometry、native_antislip、quiet_equipment_space | local_microblocks、no_step_edge_line |
| side_skirts | fine_honey_band、sparse_bright_cells、complete_rear_sections | panel_top_notch_marks |
| barrel_mantlet | separate_gunmetal、clean_low_frequency_stains、retained_structure、**long_barrel_zone** | — |

图形角色：honey_band、module_focus、warning、micro_accents、**pixel_field** 都是必需（pixel_band、pixel_cluster 是 pixel_field 的别名），不做时要在 `graphic_omissions` 写本车理由。`circuit` 是受限角色，图形条目必须带 `user_request`（用户当次原话）才放行。每项的处理方式写成下面三种之一：
- `apply_default`：采用默认元素，必须实际包含它们；
- `adapted`：逐项写清替代或取消了什么；
- `not_applicable`：给出本车确实缺少该部件、或用户当次要求的证据。

## 13 项默认

| 部位 | 主装饰 | 副装饰与原皮 | 材质 | 不要 |
|---|---|---|---|---|
| 首上 | 一到两片大斜切碎片（浅≈64、深≈20–24）＋一簇渐散数码块（浅到 84、深到 20，只在一处） | 原小警告、编号、箭头、扣锁标记；短刻度或角部小块可选 | 主体细磨砂＋防滑颗粒；原防滑单独保留或按实际采样重建 | 铺蜂窝；数码块撒满或散成零碎小块；用任意矩形把板面截成两色 |
| 首下 | 一行琥珀色粗斜体大写车名与变体，两端 » 箭头，印在下前板深色带上（AZUR：»LECLERC … AZUR») | 保留原拖曳标记和紧固件 | 较深主体涂层；折边和拖具分开处理 | 白字或大字块；文字藏在履带或拖具后面；无限缩放硬塞；照搬别车功能词 |
| 炮塔正侧装甲 | 前斜板一块：大一档的多灰填色蜂窝；侧面中部：身份铭牌（三行斜体字＋橙三角＋7格蜂窝花＋两列青/琥珀短横）；大斜切碎片可跨过侧面 | 保留合适的原数据牌、安装箭头、锁扣 | 主体灰；铭牌直接印在漆面上，不做成厚金属牌，不加框 | 大标志或大字；文字跨板缝；压住把手；白色电路线 |
| 侧裙与侧装甲 | 实心蜂窝铺满每块裙板：格子 20–52 三四档随机灰，深缝；每约 25–30 格一个 152–168 浅灰白亮格 | 每块裙板顶边中央一个小白缺口标；上下排之间的深色横条；保留原螺栓、挂点、检修小字 | 蜂窝区反射轻于主体；框条和橡胶下摆另分材质 | 后半段、转角、压条、窄边漏铺；全白空心格；每块板重复大徽记；侵蚀遮罩把细边裁没 |
| 炮塔顶部底层 | 防滑颗粒＋大斜切碎片延续到顶面；顶边一条琥珀虚线，NO STEP 嵌在中间 | 保留原舱盖字、方向箭头、检修标线；设备周围留出间隔 | 顶板、防滑、设备金属和软材质分开 | 顶部一色；把防滑做成一整片平黑贴纸 |
| 顶部警示图组 | 泄压盖：黑底上两列镜像橙斜条（人字），BLOW-OUT 竖排在中间，占满盖板 | BLOW-OUT 只用于核实过的弹药泄压盖；其他盖板用适用的警示或无字斜条 | 喷涂盖板和防滑分开；把手、铰链单独处理 | 缩进空角；只放一张小黄标签；斜条压在浅色碎片上对比不足；旧防滑块在警示下留边框 |
| 观瞄与火控 | F 深黑壳体本身就是焦点，顶面、侧壁、压条、窄唇全覆盖 | 原序号、旋向标记、连接口小色环、线缆卡箍；新加的黄青短标只放在壳体实面上 | 壳体集中而受控的高光；镜片、遮光罩、密封件独立 | 比主漆亮；黑金双色；沿镜片画黄框；连镜片一起喷黑 |
| 机枪与遥控武器站 | 护罩炭灰，加少量成组黄青色标 | 原枪身刻字、握把沟槽、弹箱标记、金属扣件 | 护罩、枪体（枪钢）、枪托或握把（哑黑聚合物）、弹链（原材质）各自对应 | 枪管或枪托加彩条；武器站铺大蜂窝或线路；枪托或本体留原皮 |
| 炮管与炮根 | 顺管身的长曲线大分区（浅≈64 与主体灰），延续整车的大碎片节奏 | 保留原温度标记、套筒编号、卡箍标记 | 炮管、热护套、布套各自处理；卡箍和分段要读得出 | 整根同一材质的圆柱；彩色环带；虚构烧蓝 |
| 备用履带与备用件 | 可见的备用履带钢面纳入涂装 | 链接边、扣环、手柄结构 | 钢件和橡胶块分开；运行履带保留原状 | 按节点名把整组当保护区留原皮；涂到运行履带上 |
| 车尾 | 两侧可见实板各一块黑底橙黑斜条短板（AZUR 每块约 4 条），上下边各一道琥珀细边 | 原车号牌、尾灯反光片、拖曳标记、维护小字；原生正确警示可以沿用并统一布局 | 暖色图形配深色涂层；灯组和排气周围独立 | 只做一侧；涂到尾灯、排气、格栅、拖车耳、透空栅上；新条纹下留旧底框 |
| 格栅、百叶与设备工作面 | 外框实板延续相邻灰区 | 邻近实板可放编号或短色标 | 叶片、黑腔、外框、工作面分开分类 | 装饰跨进百叶或孔洞；给设备工作面画纹样或文字 |
| 贴纸收尾 | 文字按字形边界居中，行距均匀 | 移除旧图时清理旧底板和相关 R/B 印迹 | 印刷图形是薄涂层，主要改变 C | 默认加矩形底板或外框；两套文字叠在一起 |

## 其他部位

| 部位 | 做法 |
|---|---|
| 前挡泥板、灯具护架 | 主体灰向前缘自然收尾，可加短边条或小编号；涂装板和橡胶挡片分开，灯罩保持原样；保留灯线、铆点和反光片 |
| 炮塔正面与前角 | 局部较大蜂窝或几何焦点，与侧裙细蜂窝拉开尺度差；烟幕弹、孔口、紧固件就是现成的节奏；工作面不画纹样 |
| 炮塔尾舱侧面、窄肩 | 用 27–54 五档暗灰数码块满铺整片侧板（AZUR 节距约 65 mm），相邻折面共用原点和方向；折边和侧壁一并完成，不能把窄肩整条漏掉 |
| 侧裙后段、折边、下沿 | 主带在完整后半段收尾，末端可用短灰块或暖色小警示呼应车尾；铰链和固定点保留 |
| 舱盖圈、铰链、扣锁 | 借真实圆形和折线边界做次级灰阶；原锁止刻线、开合箭头、橡胶缝就是细节；不加满圈的假仪表刻度 |
| 发动机盖、车体后上方 | 按盖板结构设置灰区和适用小警示；格栅空隙不能当画布 |
| 储物箱、附件盒 | 箱体灰阶或小编号图组；钢扣和绑带分开；不给每只盒子贴同样的大标签 |
| 拖钩、拖缆、外置工具 | 以真实结构和材质差异为主；新警示只放在附近实板；钢索不画成双色条纹 |
| 负重轮、主动轮、诱导轮 | 轮盘灰阶与本车协调，轮缘橡胶分开；不做彩色轮圈，不把轮胎涂成亮金属 |
| 天线座、烟幕发射器、小支架 | 外壳涂层、金属接头、保护帽分开处理；发射口和传感器工作面保留原样 |
| 网布、帆布、绑带 | 保留原生织物材质和裁切；动态网布只在 shader 支持时替换周期图案（Barracuda 类网布继承基础迷彩图，见官方 [CDK 网布说明](https://wiki.warthunder.com/cdk/386-working-with-camouflage-nets)，工具 `net_pattern`），共享基础迷彩的钢件与运行履带要固定原生 C；不把网孔图案压到钢板上 |

## 首下身份

默认放本车车名或型号，可加变体或主题副行。短橙黄斜条是可选衬托，不强制两侧都有。

- 在完整的下前板上排版，用模型逐字检查螺栓、拖钩和备用履带有没有挡字。挡住了就整组移位或改排，保持字号。
- 侧面字正确，不代表首下已经完成。
- 实在没有可读平面时，依次考虑：有真实对应部件的功能词（例如确有拖车耳时写 TOWING POINTS）、缩短的身份图组、无字图形。

## 顶部警示图组

1. 先认出盖板的真实功能、把手、设备遮挡和原生防滑块，再选承载板。在设计阶段就把位置留出来，周围的灰块和防滑围绕它安排。
2. 图组是一个整体，按 AZUR 做法：黑底上两列镜像的橙色平行斜条组成人字纹，每列 7–8 条，条宽约等于条距；警示词竖排在两列中间。默认按完整盖板构图，核心文字放在实际看得见的分区里。盖板形状不同时保持"两组镜像斜条夹警示词"：竖长盖板用两列人字，横宽盖板改上下两排（素材 `a6hel-roof-ammo-warning`）。
3. 用户要求占满时，按完整原生盖板测两个方向的实际墨迹延展，起点为横向 ≥90%、纵向 ≥85%（已用过的一次：93%/87%，包围面积约占盖板 81%）。被设备挡住的只能是斜带，核心文字必须 100% 可见。占满不等于整板实心橙色，板边余量和孔口照留。
4. 起始检查：图组填充不低于盖板的 25%，可见墨迹不低于 95%。更小或遮挡更多时，写明本车的具体理由。
5. 警示和旧防滑重叠时，明确保留或清除旧 C/N 块，不要最后涂一块白底板去遮。
6. 文字按字形边界居中，条纹内上下留白相等，并检查板缝和手性。圆形舱盖默认保持连续炭灰，顶部不做整块大 V。
7. 炮塔顶边用琥珀虚线加嵌在中间的 NO STEP 标出不能踩的边缘。

## 机枪与观瞄逐组件完成

- 机枪至少分开 housing（护罩/枪座）、gun_body（枪体）、stock（枪托/握把）、ammunition（弹链/弹箱），每件都有实际面组或"不存在"的依据。黄青色标优先放在护罩上。
- 观瞄壳体的顶面、侧壁、压条、窄唇全部完成，镜片独立保留。
- 同光照转动时，主体磨砂、蜂窝轻反射、深色观瞄、枪钢和聚合物应该读得出差别。写进了不同数字，不等于观感上已经有层次。

## 覆盖范围

"完整覆盖"只针对已经决定要画的面。前向挡板、水平平台、折边、框条、百叶叶片和工作面要分别分类：某类面允许画，不等于必须画满。没有纹样的完整机械件可以保持素面，但不能只画上半截、把下半截叫作"安静区"。范围在制作前固定，不能在检查失败后缩小。
