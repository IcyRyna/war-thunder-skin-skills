# 装饰手法：怎样做得丰富而不乱

[审美总纲](aesthetic-direction.md)讲 AZUR 是什么样，本页讲换成任何一辆车怎样装饰到位。核心判断：**炭灰工业的丰富靠"纹样场＋焦点＋小件"三层叠出来，不靠加颜色、加大图或加线条。** 一辆车显得素，几乎都是某一层缺了，而不是颜色不够。

标"AZUR"的手法直接取自范本，标"延伸"的是同一视觉语言下为其他车型补充的做法。延伸手法同样是默认可用的，不需要逐项询问。

## 1. 三层，每个可见区都要有

| 层 | 是什么 | 远看效果 | 元素 |
|---|---|---|---|
| L1 纹样场 | 覆盖整片板面的低对比图案 | 车不再是一块灰 | 大斜切碎片、数码满铺带、实心蜂窝主带、防滑颗粒 |
| L2 焦点 | 小面积、高识别度的图组 | 让视线有落点 | 身份铭牌、首下车名、人字警示、车尾斜条板、炮塔大蜂窝板 |
| L3 小件 | 近看才读到的细节 | 近看有工业感 | 微色标短横、白缺口标、模块编号、刻度尺、NO STEP 虚线、原皮小字与紧固件 |

**完成标准：** 六区（Z1–Z6）每区至少有一种 L1，加至少一个 L3；全车 L2 有 4–6 个，分布在不同区。任何一块大于约 1 m² 的可见装甲板如果三层都没有，就算没做完。

## 2. 密度预算

以下以可见涂装装甲面积计，不按 UV 像素算：

| 视角 | L1 纹样场覆盖 | 安静底色 | L2 焦点 | 彩色面积 |
|---|---|---|---|---|
| 侧视 | 40–55% | 45–60% | 2–3 个 | ≤2% |
| 前 3/4 视 | 35–50% | 50–65% | 3–4 个 | ≤2% |
| 俯视 | 25–40% | 60–75% | 1–2 个 | ≤3% |
| 后视 | 20–35% | 65–80% | 1–2 个 | ≤3% |

- 低于下限就是"素"，高于上限就是"花"。
- 彩色指橙、琥珀、青，合计宁少勿多。白色亮格和铭牌冷白字不计入彩色，但全车亮点总数控制在一眼数得清的范围。

## 3. 构图原则

1. **前疏后密，下密上疏（AZUR）。** 首上只放一簇数码，炮塔尾舱和侧裙满铺；顶面以防滑为主，只放一个警示焦点。纹样重心落在车的后半和下半，车头和顶面留呼吸。
2. **一个角度族（延伸）。** 全车大斜切碎片的边只用两族角度，例如一族约 25–35°、一族与它近似垂直，并且所有碎片向同一方向"流"（从车头低处流向车尾高处）。碎片跨车体、炮塔、炮管时保持同一族角度，车就有整体的运动感。
3. **相邻不重复（延伸）。** 两块相邻板不放同一种满铺纹样，或者至少尺度差一档：蜂窝挨着数码带可以，蜂窝挨着同尺寸蜂窝不行。纹样场之间用安静底色或碎片边界隔开。
4. **亮点成三角（延伸）。** 最亮的元素（侧裙亮格群、身份铭牌冷白字、顶部橙色人字）在侧视和 3/4 视里分布成一个不等边三角形，视线能在全车走一圈。它们不能全挤在炮塔一处，也不能排成一条直线。
5. **焦点配小件（延伸）。** 每个 L2 焦点旁边一定跟一组 L3：铭牌旁的青/琥珀短横、车名两端的 » 箭头、警示旁的 NO STEP 虚线。孤立的焦点会显得像贴上去的。
6. **纹样收边（延伸）。** 纹样场在板边留一致的窄边（一格或约 2–4 cm），或在碎片边缘用像素渐散收掉。不能半格硬切，也不能溢到邻板。
7. **左右呼应不复制。** 两侧的纹样场类型和焦点一致，具体位置按各自板面排；亮格位置随机，不做镜像。

## 4. 装饰词汇

只用下表里的词汇。没列出的元素，先确认它能归入某一行再用。

| 元素 | 层 | 做法 | 放在哪里 |
|---|---|---|---|
| 大斜切碎片 | L1 | 浅约 64、深约 20–24 的直边三角或梯形，跨板、跨部件，同一角度族 | 首上、炮塔、炮管、车体侧上部；每块板一到两片 |
| 碎片边缘像素渐散（延伸） | L1 | 沿碎片一条边，用 2–3 排数码块由密到疏地溶解，块的灰值取碎片色和底色之间 | 首上那一簇就放在碎片边缘（与"数码渐散簇"合一，不另加）；另可在炮塔前部、车体侧前各一处，全车 1–3 处 |
| 数码满铺带 | L1 | 27–54 五档暗灰正方块，节距约 65 mm，铺满整片板 | 炮塔尾舱侧、窄肩、车体侧后上部 |
| 数码渐散簇 | L1 | 浅块到 84、深块到 20，一簇由中心向外变稀 | 首上一处；大的顶部设备盖可放一处 |
| 实心蜂窝主带 | L1 | 20–52 多档随机灰，深缝，每约 25–30 格一个亮格（152–168） | 侧裙或车体侧下部的主装甲带 |
| 大蜂窝焦点板 | L2 | 约主带两倍的格子，多灰填色，一两格稍亮 | 炮塔前斜板或单独的附加装甲块，全车一到两块 |
| 防滑颗粒 | L1 | 细颗粒，同一高度场生成 C、N、R | 真实行走面：首上、炮塔顶、发动机盖 |
| 身份铭牌 | L2 | 三行斜体字＋橙小三角＋7 格蜂窝花＋两列短横 | 炮塔侧中部平板，左右各一 |
| 首下车名 | L2 | 琥珀粗斜体一行，两端 » 箭头，深色带 | 下前板 |
| 人字警示 | L2 | 黑底两列镜像橙斜条，中间竖排警示词 | 真实泄压盖或检修盖 |
| 车尾斜条板 | L2 | 黑底约 4 条橙黑斜条，上下琥珀细边 | 车尾两侧实板 |
| NO STEP 虚线 | L3 | 琥珀虚线，字嵌中间 | 炮塔顶边、发动机盖边 |
| 微色标短横 | L3 | 竖列：上青 3–5 条、下琥珀 2 条；或斜双/斜三短条（素材 `color-ticks-mother`、`a6hel-side-accents`） | 焦点两侧；护罩；检修盖角 |
| 技术折线角标（条件使用） | L3 | 低对比灰蓝短折线，长度不超过所在板边 1/3，可带一对琥珀短条（素材 `optic-id-mother`、`roof-service-mother`、`hex-trace-mother`） | 只用于观瞄壳体角、顶部检修盖角；不放在侧面大板上 |
| 白缺口标 | L3 | 板顶边中央的小白色缺口或倒三角 | 每块裙板或模块板顶边 |
| 模块编号（延伸） | L3 | 冷白或浅灰常规体小字，"01"–"12" 或 "A-03"，字高 4–6 cm，按板序递增 | 侧裙每块板的一角、ERA 块组、附加装甲模块 |
| 刻度尺（延伸） | L3 | 一排 5–9 条等距短竖线，一端一条加长，浅灰或琥珀 | 炮塔侧板下缘、观瞄壳体旁、炮根护罩边 |
| 小三角警示符 | L3 | 橙色实心小三角 | 铭牌主字后；吊点、夹手位置 |
| 原皮小件 | L3 | 原有小字、箭头、色环、数据牌保留或保形换色 | 全车，优先使用 |

**禁用：** 白色或彩色长线条与电路线（素材包里的 `azur-child-circuit`、`azur-child-circuit-narrow` 是旧版 AZUR 子版，只在用户点名时使用；机器规则要求该图形条目带 `user_request`）、大徽记、日环、彩色炮管带、国旗（用户要求时除外）、铭牌外框和底板、满板白线空心格、大面积彩色块、满屏小字。

## 5. 救素：发现某区太素时，按顺序加

一次只加一级，加完退远看。够了就停。

1. **加碎片。** 让一片大斜切碎片跨进这个区，延续全车的角度族。
2. **加渐散。** 在碎片边缘加一段像素渐散，或在板面一角加一簇数码。
3. **铺纹样场。** 该区是独立的大板、而相邻区没有同类纹样时，铺数码带或蜂窝带，尺度和邻区差一档。
4. **加小件。** 补模块编号、白缺口标、刻度尺、微色标，并恢复原皮小件。
5. **加焦点。** 只在这个区本来就该有焦点（身份、警示、车尾）而又缺失时才加。

**不要这样救：** 加颜色、加白线、把现有纹样对比度调高、把字放大、给整车再铺一层新纹样。

**反过来，某区太花时：** 先把 L1 纹样不透明度降到 25–35%，再撤掉多余的 L3，最后才考虑删纹样场。焦点不动。

## 6. 按车型落位（延伸）

| 车型特征 | 蜂窝主带放哪 | 数码带放哪 | 碎片与焦点 |
|---|---|---|---|
| 有长侧裙（豹2、勒克莱尔、M1A2） | 侧裙全长 | 炮塔尾舱侧、车体侧后上部 | 炮塔侧铭牌；首上碎片加数码簇 |
| 侧裙短或带 ERA 裙板（T-90、99A） | ERA 裙板按块做实心蜂窝，或每块 ERA 用一个灰值拼成大尺度数码（块即像素） | 炮塔后部或尾舱盒 | 炮塔 ERA 块做大蜂窝焦点；首上 ERA 按块分三档灰 |
| 楔形装甲炮塔（豹2A5 以后） | 楔形装甲正面一块做大蜂窝焦点 | 炮塔侧后半满铺 | 铭牌放侧面前半平板；碎片顺楔形斜边走 |
| 车体光滑大平面（10式、梅卡瓦） | 车体侧下部板 | 炮塔侧大平面后半 | 大平面最容易素：每面至少一片碎片加一段渐散；梅卡瓦尖楔炮塔用碎片顺楔形 |
| 轮式车、无侧裙 | 车体侧下部带状区域，避开轮拱 | 车体侧后上部 | 轮拱上沿用刻度尺和模块编号做 L3 |
| 栅格装甲、网布覆盖多 | 栅格后不画 | 栅格外露的实板 | 焦点移到栅格不遮挡的炮塔和首上；栅格本身保持素 |
| 小炮塔或遥控炮塔 | 不放 | 炮塔侧一小段 | 身份铭牌移到车体侧上部或首下；炮塔只放微色标 |

无论车型，都要保住这几处：首上一簇数码、炮塔或车体侧的一组身份、顶部一个真实警示、车尾两侧斜条板。

## 7. 交付前对素/花自查

- 退到游戏常用距离看侧视和 3/4 视：每个区是否都读得到纹样场？焦点是否 2–4 个，而且分散？
- 逐区数三层：哪一区少了 L1 或 L3？按第 5 节的顺序补。
- 盖住所有彩色再看：只靠灰阶纹样，车是否仍然丰富？如果只有彩色撑着，说明 L1 不够。
- 眯眼看：碎片的角度族和"前疏后密、下密上疏"是否成立？亮点是否成三角？
- 近看三处小件区（铭牌、观瞄、车尾）：是否有编号、短横、刻度或原皮小字，而不是只有一张大图？
