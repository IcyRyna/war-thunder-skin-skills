# A6HEL 游戏失配与修复
本次是0.1.3候选自身制作实现的缺陷，不归咎于0.1.1、并行0.1.2或收尾钩子。

## 证据链
- v7游戏与离线预览明显不同。安装目录和包的哈希一致；删除两个测试目录、从最终包原字节重装后，用户截图仍显示问题，排除本轮文件残留作为解释。
- 关闭四项自定义N替换：用户说基本没变化。将三个已知网布资源Alpha清零：用户说网纹仍在。两项未支持原先猜测；不得说网布是已证明的根因或已成功移除。
- 首上A/B/C/D分区图确认新贴图实际加载。D同时改颜色与材质，只能说明组合有作用，不能拿它单独证明某一个通道。
- 找到当前生成器的硬分支：luma<22保留近黑，其余变成31附近。已验证的首上防滑子区域约64%原图像素落入这个分支，旧底漆中位数12。整图中位数30掩盖了它。
- v10取消硬分支，使用31+0.06*原生高频、限制27..40。装饰字节不变，N/AO字节不变。用户反馈有所减轻，但仍明显，并给出截图。
- v11在同一颜色上改为声明的哑光非金属涂层：R中心64/范围52..72，B=0，原生G/A强度55%。用户随后提供的正面近景显示斑纹和重黑边明显减轻；这是有限视角的图片证据，不是用户整车认可。

## 可复用规则
1. 正常暗色漆面不能被亮度阈值误当孔洞保护。保留区要有明确用途和材质证据，映射必须连续。
2. 从真实表面三角形生成UV掩码，分别审计关键部件底漆；不得用空白区域稀释问题。`carrier_color_audit`会拒绝明显黑色残留，即使整图中位数合格。
3. 新涂层的颜色和材料属性必须配套。原生N是来源，不能把“保持所有原始B值”当作新漆面必然正确。G/A可按声明的强度调整，但不能冒称原像素不变。
4. 导出前做实际游戏比较。预览AO旧值0.35、曝光旧值-0.7会改变外观；本次改为显式AO1.0、曝光0，不用展示参数掩盖缺陷。
5. 所有作用域与限制分别写清：静态Blender导出仍不能正确表达动态网布；当前正面裸装甲由游戏图对照，其他附件状态尚未验证。光照和相机不同的两图不能宣称逐像素或严格色彩一致。

## 实验规模
仍是一轮A6HEL整车制作的连续返工。原来的21项技术边界，加8项针对这次失败的新回归，不构成成品率样本；这次游戏改善也不自动证明0.1.3优于0.1.2。

## 装备语义与平衡布局的追加纠正
用户进一步指出A6HEL没有APS，要求采用D-Technologie装甲识别。原来的APS-HUNTER直接照搬是语义错误，不是风格要求。本轮改为D-TECHNOLOGIE，最初使用带底板图形，随后按用户要求撤掉外围边框和底板，改成transparent_element。原APS子版退出默认迁移列表，默认母版不含功能文字；特定标签绑定目标单位和用户/资料证据。

用户又指出左右色标距离蜂窝组不一致。现在蜂窝组中心x819，两列色标中心x619.5与1018.5，左右内部间距均20.574px；右侧外留白约73px，标题与左色标间约71px。平衡阶段保留标题、边框与警示三角，只排列右侧图形组；之后的无框派生仅移除边框和底板，保留前景内容与两侧间距。其三维承载面、字向与像素预算沿用已检查的目标面。

新增六项语义回归，涵盖无APS拒绝、确有能力且文字获准、目标装甲标识、不同车型拒绝、缺失profile拒绝、装甲模块承担视觉焦点。它们不是新整车成功样本。

## 无框派生的适用范围
用户要求当前A6HEL装甲识别不使用外框。以透明元素形式保留文字、蜂窝、警示和色标，让真实装甲成为承载面。外框不是SPECTRE风格的必需特征；是否使用边框/底板由目标结构与用户布局决定，不能把本次去框推广成所有车型禁用框线。

## 侧面线路与伪装网的后续反馈
用户要求删除两侧白色折线，侧面新点缀先提供方案。`circuit`允许带具体原因明确省略，不能为了凑满角色强制添加装饰。本车原生模型具有body_net、turret_net和gun_barrel_net，对应Barracuda b/c/d网布材质；另有net_f/net_j，不得混为同一对象。包内camo-net-native是原作表面参考裁片，尚非净化且获准迁移的子版。网布方案需要在目标原生网布UV上另制子版，保护真实裁切和网布材质；不将网孔图案压到普通钢板，也不冒称当前离线隐藏的动态网布已在游戏验证。

以上“网布尚未实装”为早期方案阶段记录；后续已实装并获得具体可见性确认，当前方法与限制以 native-surface-corrections.md 和 validation.md 为准。
