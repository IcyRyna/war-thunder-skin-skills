# 装甲面、完整蜂窝与几何边界

从实际节点/三角面/材质建立可涂面，分别列主斜面、顶窄面、侧折面、前立面、边框及底面。不能只涂最大的朝上三角形便说覆盖整块爆反，也不能用统一法线阈值漏掉窄折面。相邻板各自的底色、板缝和螺栓保持真实。

99A 的失败有两类：侧裙补图在上方/铰链处溢出，与相邻板留边不同；靠边出现半格和大空角。先核对面遮罩，再选择网格原点、单元尺度与留边。要求完整单元时只保留落在允许内区的整格，并重新排布以缩小空角；要求连续全覆盖底纹时允许在真实外缘裁切。两者由本次设计决定，不能一边承诺完整格，一边随意裁去半格。边框和五金不纳入蜂窝承载面。

炮塔前蜂窝曾出现部分变淡变糊，须查源图是否自身渐隐、有限画布边界/Alpha 是否被投到窄折面、图层是否混入原皮、局部 texel 密度及 mip；不能只加深整张图。车体首上边缘漏填的已查实原因是源画布留白进入实际面。修复在物理表面坐标上延展纹场，最后用真实三角面裁切，检查全部选中面都被覆盖。

`hex_surface.py` 接受逐纹素表面坐标 u/v、paint/protected/shared 二值遮罩，生成无限 flat-top 正六边形场。半径、缝宽、底色和调色板都必须显式给出；坐标单位自行统一并记录。它不替代几何到 UV 的光栅化，也不把共享像素擅自分给一个部件。

```text
python -B scripts/hex_surface.py --input body.png --maps surface.npz --radius 0.05 --gap 0.003 --base 24 --palette 36,41,46 --out NEW_body.png
```

NPZ 包含与图像同尺寸的 u、v、paint、protected、shared。paint 必须已排除保护区及共享冲突；否则拒绝。全部选中纹素必须有有限坐标。输出保留 Alpha 和范围外 RGBA。规则图形仍需检查实际模型尺度、接缝、可读反差和游戏 mip。

99A 本车当前：炮塔前部与首上使用暗实心三灰度，炮塔侧为较大轮廓蜂窝，侧裙为细密实心。首上最下沿六个窄前立面明确素色，不计缺失。灰度 24/36/41/46 是当次配方，不当全车型强制色值。
