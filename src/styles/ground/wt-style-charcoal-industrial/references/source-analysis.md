# 原作拆解：观察、作者说明与推断分开

来源：[WT Live 1192186](https://live.warthunder.com/post/1192186/en/)，作者 Fying_。2026-10-22（Asia/Taipei）下载 98,096,008 字节原包，SHA-256 `79e3bf02c6984d64601c5a12428bb410dd1ea74b9ef672ebb9fb736de91222da`。原件留在领域项目，本包提供精确裁片、原作展示图及哈希来源索引。

## 原包到底包含什么

13 个文件：1 张 1024² 通用迷彩图；炮管 C/N 各 2048²；Trophy、附加装甲、车体、炮塔 C/N 各 4096²；一个车型 BLK 与 README。11 张 DDS 均为 DXT5，分别有 11/12/13 层 mip，层数覆盖到 1×1。5 张主体 C 的 A 通道全部为 0；通用迷彩图 A 全为 255。它们不是可直接按透明度合成的 PNG 贴纸。

BLK 把 9 个美国基础迷彩名重定向到 camo_spectre；各主体 C 同时出现 set_tex 与 replace_tex，N 单独替换。重复绑定是原包事实，不能直接复制为另一车型的通用资源规则。原包没有独立 AO 文件，也没有模型、可编辑 PSD/CMPS、图层或作者脚本。

作者 README 说该作沿用 SPECTRE v8 的迷彩并做了 PBR 调整，提到 Leopard 2A7V、M1A1 HALO 与 2RI RAIJIN。**这些其他作品本轮没有下载或检查，不能算三个迁移成功样本。** README 对粗糙度、金属边缘等的说明是作者自述；本轮核实贴图存在和数值分布，不把自述等同于经过我们游戏内验证。

## 第一层：低频底色

整车主体是偏冷的炭灰/枪灰，角状灰块面积大、数量少。`camo_spectre.dds` 的 1024² 全部像素做 median-cut 聚类，最终出现 5 个代表色：`#2b2d32` 25.72%、`#292c31` 25.10%、`#1c1e21` 23.15%、`#585d62` 17.62%、`#292c2e` 8.40%。这些是压缩纹理的近似聚类中心；近似灰色可能来自底色轻微变化，不能据此宣称作者有 5 个独立调色板颜色。

**分母是通用迷彩图 1,048,576 像素，不是 UV 已用面积，更不是整车可见面积。** 主体纹理包含 UV 空白区，不能统计整张主体纹理后声称“车辆橙色占 X%”。

远景中低频底色把各模块归为同一车辆，且让下部轮履退后。完全纯黑会吞掉接缝；把灰块也换成小像素会失去尺度层次。宣传图上的蓝色海报背景、白色大标题和角线属于展示设计，不进入车身风格。

## 第二层：模块节奏与两种侧裙表现

0.1.1 已将原包加载到 M1A2 SEP V2 Trophy 原生模型并对照 UV：当前包两侧主侧裙均是蜂窝板；炮塔附属盒、端部与前甲板局部使用像素线路。宣传图里存在像素侧裙，但尚未查明其制作阶段。当前制作以原包和原模型配对结果为准，不将不同展示混合成一套默认方案。见[模型与 UV 对照方法](model-uv-method.md)。

像素复合板内部由低对比方块组成；外框、角部紧固细节形成独立舱体，浅灰线路在舱内转折、端点收口。长条板、中号板和小方舱用同一种语法但不同线路，不是缩放同一图案。蜂窝区使用中低对比灰色单元，少量亮单元打破均匀；板边结束蜂窝，不让它无条件穿过结构缝。

移植时应保留：**连续的模块带 + 可读板框 + 内部低对比变化 + 零星技术线路**。模块列数由目标车的板缝决定；没有连续侧裙的车辆可以改为外侧储物箱/附加装甲组，不能把模块画在履带、轮胎或空隙上。

## 第三层：炮塔前脸与仪器焦点

炮塔两颊是 APS-HUNTER 传感器面板：倒角外框、少量较大的蜂窝“装甲块”、左右窄蓝/橙灯条、警告三角和小字；邻近炮盾的深色凹槽画有蓝/灰/米色线束、扎带和连接头。它将抽象工业图形绑定到“防护系统”主题，而非任意装饰。

蓝色与橙色集中在小型仪器部件。另有绿底雷达显示面。截图不能证明这些区域实际发光；不要把漫反射颜色当 emission 参数。原作大部分立体感可由颜色/打包 N 实现，但本轮未证明每处都是模型结构还是纹理浮雕。新车应保持自身轮廓，若要新建网布或凸起几何必须另行制作，不能靠涂装声称已增加几何。

主视觉块附近需要安静空间。炮管大部分保持深色，炮盾/近端有布网，炮口保持机械读感。将蜂窝铺满整根炮管会破坏焦点层级。

## 第四层：布网、识别与警示

车顶侧板、前甲板、炮盾罩等可见灰橄榄色网布纹理；网布的细密孔洞与像素块、蜂窝构成材质对比。部分识别标记叠在网布上，包含光学定位图样和 M-3/ID 字样。精确裁片保留原始字向：UV 上倒字不说明游戏里倒字，迁移要核实目标表面方向。

原作橙色最显著的位置是前下装甲电子检修门两端、弹药泄压板和窄警示带。BLOW-OUT、HOT SURFACE、NO STEP 和 HIGH VOLTAGE 指向不同功能。模板移植不能只保留字形却丢掉位置含义。原 QR/定位符是否可扫描未验证；重建的条码仅作装饰，不声称编码了真实信息。

## 材质与做旧

原 README 描述哑光污渍、中等漆面、亮磨损边、雨痕和露金属。截图可见板框旧化、边缘高光和布网的柔软视觉。可观察到做旧存在，但无法从最终压缩贴图还原作者所有图层顺序。移植建议采用独立边缘磨损、布网、装饰面、结构 AO 层；这是工程建议，不是作者工艺复原。

原作者结构细节、螺钉、孔口和局部阴影不能整片搬到新车。原作裁片属于研究对照；可复用模块先从原图精确抠取，再限制性修复，目标车的 C/N/AO 与机械结构独立保存。初次制作保留 `reference-worn` 风格意向，但先做干净模块检查，再按真实边缘加磨损，避免把可读文字磨成噪声。
