# 去污、磨砂与金属层次分开诊断

用户要求去污不等于抹掉坦克细磨砂。把低频污迹/斑驳、细颗粒、焊缝/结构、AO、光泽和金属度分开。先看 C 中的色斑，再拆已确认打包 N 的通道；本次 99A 的 R 为光泽、G/A 为切向法线分量、B 为金属度，但每个新 shader 都要重新核实，不把普通 RGB 法线当这个格式。

清理炮管污迹时，C 的大块污色和法线中的粗斑可能都参与；仅重涂 C 不必然干净。需要改 G/A 时只在明确漆面处理低频污斑，保留细粒、接缝、卡箍和其他材料边界，并记录实际改动，不能再声称法线逐像素未变。不要反复对已经处理过的 N 做乘法造成累积变平。

全车金属质感是各材料之间的关系：主体为有细磨砂的克制金属漆，火控金属壳体更突出，光学窗口仍是光学材料。备用履带块可按用户设计加炭灰涂层，运行履带、橡胶、布料、玻璃分别处理。节点含 track 或 MG 不能成为整组不涂的理由。

对称部位发白或重影时，按同一物理区域排除橙条、五金、孔口，比较 C、R、B、G/A、AO；再用同相机、对称光照查看两侧。不要用不同灯光截图直接推断材质值，也不要先把所有通道调黑。

99A 的实证：只修旧橙条轮廓后，右后仍有浅色底框。左漆面 C 的 q10/50/90 为23/24/25，右为29/42/62；两边 N.R 中值66、N.B90、AO255。原因在 C 整片偏浅，最终右板对齐24±1，现有五条橙标RGBA保持一致，N/AO/模型及其他C区域不改。21872 是允许修复范围，实际变化20796纹素，不能混用。新画面等待用户评价。

`surface_finish_audit.py` 只读取显式对应漆面遮罩，不按颜色筛出“看起来合格”的样本；遮罩来自实际承载面，再减去已声明装饰/保护区。两侧图集可不同尺寸，但区域必须语义可比。报告分位数和通道差异，不自动判断哪种材料正确，也不执行修复。

```text
python -B scripts/surface_finish_audit.py --left-c left.png --right-c right.png --left-mask left_paint.png --right-mask right_paint.png --left-n left_n.png --right-n right_n.png --left-ao left_ao.png --right-ao right_ao.png --out NEW_comparison.json
```

已确认不透明固定 C 的覆盖 Alpha、独立贴花透明 Alpha、N.A 数据三者分开；逐 mip 读回最终 DDS。若 C 一致而仍发白，再查材质、灯光、AO、真实加载文件与刷新，不能把某一次 C 故障当所有发白的唯一原因。
