# 常见症状与诊断

先定位问题出在哪一层（C、N.R、N.B、N.G/A、AO、绑定、加载文件），一次只改已经判明的那一层。阴性的试验结果也要记下来，不要把没有起效的改动写成"已证明的根因"。

| 症状 | 先查 | 修法 | 不要 |
|---|---|---|---|
| 游戏里偏绿或橄榄色，离线正常 | 实际 shader、BLK 里的 from/to 资源、固定颜色覆盖语义、每级 mip 的 C.Alpha、实际选中的目录 | 已确认不透明的固定漆面 C，配套写 `set_tex`、`camo_skin_tex`，Alpha 设 255，并逐 mip 读回 | 只把 RGB 再调黑；归咎于缓存 |
| 正常漆面上有黑斑、重黑边 | C 是否走了亮度硬阈值分支（例如 luma<22 保留原黑）；用真实三角面遮罩逐部件统计 | 底色映射改为连续映射；保留区要有用途和材质证据；颜色和材质属性配套调整 | 只看整图中位数；把暗像素都当孔洞保护 |
| 去污后磨砂消失、表面变平 | 高频细纹、法线扰动、粗糙度、低频污渍分别动了哪些 | 只去低频斑，从冻结输入一次性应用参数 | 常数 N；全局去噪；反复相乘 |
| 一侧发白，或有旧贴纸重影 | 排除图案、五金、孔口后，同一物理区域左右的 C 分位数；再看 N/AO；用同相机、对称光照比较 | C 整片偏浅就整片校到另一侧水平；旧条纹残影逐通道清理 | 只擦旧条纹的轮廓；不同灯光截图直接比数值 |
| 整片映成天空蓝 | 光滑度和金属度是否过高，环境反射，目标材质角色 | 降光滑度，改成缎面金属（R≈145、B≈229、C≈143 附近，带磨痕） | 只改 RGB |
| 镜片灰白，或没有反光 | 同一张图里漆面和镜片的像素分区，C.Alpha、玻璃 shader、镜片 N | 恢复镜片 C.Alpha；只对确认是玻璃的 N.R 设下限 | 外壳修正顺手覆盖镜片；全图 Alpha255 |
| 银白误涂到盖板、边条 | 选区是不是宽包围盒或质心选的 | 改用显式的完整三角面清单；撤回时 C 和抛光 N 一起回退 | 只改 RGB |
| 窄边、折边、细框漏涂 | 选面是否用了"至少两个可见样本"、全部顶点共面、遮罩侵蚀之类的条件 | 按完整原生三角面清单选；C 遮罩不收缩；N 下采样保留四分之一覆盖的小面 | 总覆盖 95% 就放行；跨无关 UV 岛去涂抹 |
| 蜂窝发淡发糊，有半格或大空角 | 源图是否自带渐隐；有限画布的留白或 Alpha 是否投到了窄面；纹素密度；mip | 在物理表面坐标上延展纹场，再用真实面裁切；重新选网格原点和尺度 | 整张图加深 |
| 文字被挡，或镜像 | 用模型检查承载面和遮挡；frame 的 u×v 是否与面法线同向 | 整组移位或改排；修正轴向后重新计算探针 | 无限放大；靠斜条露出来就宣称"可读" |
| 原皮的彩色小件被压成灰 | 在模型上定位小件，对比原 C 和最终 C 的同 UV 样本，R/B 是否也被主体覆盖 | 只在确认的小范围提取原 RGB，放到底漆之上的恢复层，同时恢复对应 N 的 R/B | 保留了 G/A 或高通层，就以为小件也保住了 |
| 首下或顶部显得空 | 是否只做了侧面；身份和警示的承载面在设计阶段有没有留出来 | 回到[逐部位做法](../style/part-recipes.md)，先放身份和警示，再排灰块和防滑 | 最后硬贴一张小牌 |
| 整车太素 | 先查这个区缺的是材质区别、原皮细节还是副装饰 | 按缺什么补什么 | 全车铺蜂窝或白线 |
| 整车太花 | 副纹样的对比度和不透明度、主焦点是否被淹没 | 先降副纹样不透明度，恢复大灰区和主焦点 | 把细节全部删光 |

## Alpha 的四种职责

1. **贴花 PNG 的覆盖 Alpha**：边缘预乘滤波，格缝和孔洞透明。
2. **固定漆面 C 的覆盖 Alpha**：只对已核实 shader 的不透明漆面设 255。
3. **玻璃或裁切 C 的透明数据**：alpha-test 的网布、格栅、镜片照原样保留。
4. **打包 N.A**：法线数据，绝不当透明度用。

同一张纹理可能同时被钢面和镜片使用。shader 白名单只是必要条件，代替不了像素级的保护区。

## 游戏对比

- 比较前固定当前的文件身份和游戏实际选中的目录。
- 预览显式设定 AO 1.0、曝光 0，不用展示参数掩盖问题。
- 静态离线渲染表现不了动态网布；离线隐藏网布只用于检查钢面。
- 光照和相机不同的两张图，不能宣称逐像素一致。
