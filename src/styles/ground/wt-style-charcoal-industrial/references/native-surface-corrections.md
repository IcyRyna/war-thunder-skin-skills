# 原生部件、伪装网与顶部层次的追加纠正

本地候选，来自一轮 A6HEL 连续返工，不能视为跨车型成功率，也没有全车美术认可。

## 伪装网是基底图案继承

Barracuda 动态网布继承载具基础迷彩。使用基础迷彩图的 replace_tex 定义独立周期图案；已改固定涂色的钢面用 set_tex/camo_skin_tex 绑定。实际同样使用基础迷彩的物理履带必须固定其原生 C，不能漏掉。保持网布原生 C/N/AO 和裁切 Alpha，不用擦除网布 C 的 Alpha 冒充当前 shader 已支持自定义替换。依据：[官方 CDK 网布说明](https://wiki.warthunder.com/cdk/386-working-with-camouflage-nets)。

`net_pattern.make_pattern/check_scope` 检查周期边缘、独立图案及共享基础迷彩的固体材质。用户在真实游戏中确认色标和网布都出现；右青标被把手遮挡后移到黄标下方，首上零碎灰块撤掉，用户确认两处正常。这是具体可见性和部位修正认可，不是整套通过。

## 小部件和透明裁切

机枪座护罩、机枪金属本体、枪托和弹链分别定位。用户要求枪托也改成黑色后，使用显式 UV 多边形涂覆金属和聚合物；ammo 独立材质不改。`cutout_coating` 保持本体 C.Alpha 和打包 N.G/A 精确；R/B 按金属和聚合物配方分别处理。编辑器用不透明 RGB 画布加独立裁切 Alpha，合并后比对 RGBA，不把数据 Alpha 当图层透明度。

## 字向和警示中心

不能把屋顶局部坐标系的左右手性写死为侧板习惯。`native_carrier.fit_carrier` 接受显式 u_hint，维持 cross(u,v) dot n < 0，文字不镜像。BLOW-OUT 仅用于本车左后弹药盖，NO STEP 的虚线避开字形，条纹内部文字按可见字形上下间隙检查，本车源图为 24/24 像素。首下用 TOWING POINTS 指向真实拖车耳，不沿用其他车的 ELECTRONICS ACCESS。

## 灰阶层次与精确部件选区

AZUR 的制作基准包括相近灰色板块和低对比度方块；全车统一灰31会丢失结构层次。`panel_tones.tonal_overlay` 在目标原生板面按声明灰阶偏移，保留少量本车细纹。方块必须同时满足完整落在目标平面、该原生 UV 有足够采样、顶部无遮挡，不放在行李下面。

用户否定了宽盒选择造成的银白误涂：对侧整组矩形盖板、边条和三孔三角板均恢复炭灰。金属插片改用冻结几何哈希加显式目标三角面清单，不能以一个世界矩形包围盒代替部件。`uv_paint_scope` 逐采样检查所有已声明可见 UV 使用者；全三角形质心不是逐像素作用域。共享的后部窄附件须明确记录，不能声称唯一 UV。

`surface_finish.polished_finish` 仅在显式银白区调整 R/B，并对 G/A 做有权重的局部平滑以获得抛光效果；遮罩外四通道精确，遮罩内不得宣称原 G/A 不变。恢复炭灰时同时撤销银白 C 与抛光 N，不只改 RGB。

## 验证和工具边界

同一模型的原生全表面 UV 缓存可用于分析，但顶部作者遮罩需要向上外表面范围，避免底面覆盖相同 UV。缓存记录模型哈希、面过滤和分辨率。动态网布不支持离线静态变形，离线隐藏仅用于钢面检查，不是游戏去网或所有附件状态通过。

Blender 批处理加 --python-exit-code 1；只在输入 scene/bindings 完成后启动渲染。一个 GPU 同时只跑一个重型整车渲染，避免显存争用。

## A7V 材质参照的后续否定与替换

v25 恢复错误银白位置获用户游戏确认，但同一版光滑高反射材质被指出像整片天空蓝，不能把选区通过等同材质通过。用户最终改用 A7V 1162771 灰银金属为参照，取代早先 A7HU 与黑金提议。读取原作 C/N 只用于分析，不复制像素。原作顶部样本中 C 中位143、N.R179、N.B229；当前目标为了减轻环境蓝色镜面，采用R145附近并以本车细节形成局部起伏、B229、C143附近的磨痕。G/A改为微弱本车高频扰动，明确记录为新表面，不声称保留原生防滑凹凸。`satin_metal` 为本次候选实现；技术测试不能代替游戏材质评价。

## 深色金属与完整框边

用户后续要求三块金属板及周围间隙成为枪灰黑金属。C由143附近压深至82附近，磨痕对比由18收至6；R145、B229方向保留。该范围包含实体框边、连接条和完整压片，不向相邻三孔三角板和对侧盖板扩大。

v28仍被用户指出漏边：已确认部件的小折边不能再用“至少两个可见样本”丢弃，不能用所有顶点必须落在平面内的条件切掉压片，也不能对整套框边继续侵蚀UV遮罩。对具体部件使用完整原生三角面清单并检查别名；C遮罩不收缩，N下采样保留四分之一覆盖的小面。UV留边与真实三维间隙不同，不能靠跨越无关UV岛涂抹来假装补齐。新增完整边框版本仍分别记录本模核对和真实游戏反馈，前一次有限材质认可不自动扩大。

完整部件选择使用 native_components.face_components 与显式已核对组件清单；expand_reviewed_components 支持保护邻件。不能将整座炮塔连成的大组件自动扩涂；本车仅对已核对的小壳体、压片、边框及紧固件扩展。原生拓扑检查补足投影范围的局限。

最后的漏边还暴露了作用域门槛缺陷：总面积覆盖95%会放行一整条细铰链被裁掉。当前真实样本要求527185个目标采样全部保留，不能为了保护未知共享UV而静默裁半块板。先追踪共享面并明确登记，核对其实际可见外观，再允许相关采样；有未决共享或未映射目标时停止导出。当前明确登记四个车侧面与两个小侧支架的共享关系，不声称目标使用唯一UV。

## 材质层级

用户要求主要炮塔有轻金属反光、蜂窝真的只有一点、火控/瞄具更黑以突出。本车主要炮塔B48/R增加24，蜂窝B6/R增加4；瞄具壳体C20、装甲识别面C22且B0/R56，玻璃独立保持原生。既有枪灰盖板保留原配方。finish_hierarchy.apply_region 仅改明确遮罩内R/B，保持G/A和遮罩外精确。B的八倍参数关系不等于实际反射亮度八倍。数值属于本车本次方案，不能固化成所有车型通用参数。

## 车体、炮管与光学追加

图形候选面用三角形包围盒与承载区域相交判断，不能只取质心而丢失跨区域的大三角；绘制仍裁到精确边界。车体长条仅沿外侧平面，通风栅有独立保留遮罩，后转角与顶折边不重复蜂窝。下侧炮塔前角单独补齐，焦点深色遮罩避让该图形。炮塔、车体和炮管采用不同黑色金属配方，布料、轮履、孔口和印字分别保留。`optics_finish` 仅提高经shader确认玻璃的N.R下限，保留C、透明和N.G/B/A；不得把玻璃当金属漆。新贴图以内容摘要命名，记录实际绑定；这不证明此前差异由缓存引起。
