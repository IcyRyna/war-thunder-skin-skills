# 原皮细节复用：先分清，再喷底，再复合

目标是保住原皮已经提供的真实小装饰和部件质感，让新的炭灰工业涂装有足够细节。不能将整张原皮C压成灰后，把残留高频噪声当成“细节都保留了”。basecoat的连续映射会改变原小字、标线和色标，它不是原皮装饰提取器。

## 先从本车实际输入识别四类内容

| 内容 | 怎么识别 | 默认处理 |
|---|---|---|
| 印刷/涂画小装饰 | 原C里的检修字、编号、方向箭头、警告、小线条、瞄准/锁止刻线、色环、数据牌 | 合适就保留；按风格需要可限定换色、重排或提取为本车子版 |
| 结构细节 | 螺栓、铆钉、焊缝、压筋、铸字、凹槽、孔洞、接缝和卡箍；结合模型及N/AO辨认 | 保留真实结构方向和合理阴影；不是给所有螺栓手画高光 |
| 材质与功能细节 | 镜片镀膜、灯/反光片、橡胶胶圈、钢索、弹链、握把沟纹、布套织纹、防滑颗粒 | 按真实材料与shader独立处理，不能被主体灰漆统一覆盖 |
| 需要清理或替换的旧外观 | 旧迷彩大块、低频泥污、旧作品图框、与本车不符的字样、明显烘焙照明 | 限定去除或替换，不顺带抹掉前三类；旧C/R/B/G/A/AO分别判断 |

原皮本来没有的细节不假装“提取”出来。特别小或模糊的原文字可保留其原有纹理作用；需要清晰可读时只使用能确认的内容重新排字，不能猜读。

## 逐项选择四种处理

1. **原位保留。** 适用的原警示、编号、箭头、小色环、反光片等维持原内容和位置。对独立部件直接使用已有preserve材料/面组路线；对漆面上的印刷标记，在底漆前识别实际字形和符号范围，避免被重着色。
2. **保形换色。** 原图形用途和形状合适，但底色变化导致太亮、太暗或配色不协调时，保留字形/位置并限制在油墨范围改色。透明覆盖和实际轮廓仍单独处理，不能把周围旧迷彩也留下来。
3. **提取重组。** 将本车原生小图形变成独立透明子版，与包内铭牌、蜂窝、斜条或色标组合。重排时重新检查方向、字高、间距和部件语义；不复制带螺钉/阴影的整块原车金属底板到另一处。
4. **替换或移除。** 身份错误、语义不适用、用户明确撤除或已与主图冲突时，用正确的本车图形替换，或在结构/原皮细节已经足够时删除该图。清除实际残影涉及的通道，不只盖住颜色。

这些选择由AI根据本车输入和现有要求完成，不逐个标记询问用户。用户指定保持原样的标识优先按其要求保留。

## 在现有制作链里落实

**底漆前。** 对模型部位和原生C/N/AO成对观察，找出要用的细节。记录本车资源、UV位置/实际面、处理方式和变化原因；所有记录留在当前车型任务中，不建立中央登记。整车源码图不跨车搬用。

**独立材料/独立面组。** 灯、镜片、胶圈、握把、钢件、织物等按既有preserve、paint或特殊材质路线处理。原位保留区域要落实到真实面和资源；不能把一张混合纹理全标为preserve，也不能将轮履、镜片或网布裁切混入底漆。

**同一漆面上的小字/符号。** 优先提取实际油墨为独立透明“原皮标记”图层，使用本车局部素材目录；再做干净底漆，最后在原位置或新布局复合标记。透明图只含实际字形/符号，清理其旧背景和色边；难以干净分离时保留原件并在本车可编辑层中重建能确认的图形，不把整块旧底色当透明贴花。

同位置直接保留也要有真实范围；仅在paint_mask上随手挖洞，不能证明完整物理面的材质颜色已经核验。对已纳入喷涂材质的面，原皮印刷图形应进入实际图层/decoration_mask证据，而非用任意大排除遮罩跳过颜色检查。图层资格与新的源图测量按[素材使用与AI适配](asset-use-and-adaptation.md)执行。

**底漆与结构。** 重着色只作用于确认的漆面。N.G/A原生结构法线及合理AO按原通道保留；增加微颗粒时使用已有RNM与独立coverage。C中的结构明暗可以克制保留，但不重复烘焙大阴影或把所有暗点都认成孔洞。

**小图材质。** 普通印刷字/色标默认作为薄涂层图形，主要改变C，不自动增加厚边、凹凸和高金属度。确有凸字、金属牌、反光材料或原生粗糙度变化时，按实际部件和材质单独处理。已有R/B印迹需保留或重建时检查真实范围，N.A不作为图形Alpha。

**导出前。** 在真实编辑器中将原生标记、包内主图、AI改制子版和精确材质处理分别保留可追踪来源；保存、导出和副本重开。最终C必须能由声明底层和实际图层重现。原皮提取图不自动获得跨车通用资格。

## 本车记录建议

### 同UV局部对照

对每种实际采用的保留方式，选可见代表小件检查原C/N、无装饰底色、实际编辑器导出和最终DDS解码。发现异常就扩大到同类部件；抽样通过不代替完整部件覆盖。先在模型确认位置，再选字形或小件内部像素；红色阈值、暗色阈值只供找候选，不能据此把所有红块认作尾灯或所有黑块认作孔洞。

保留红/琥珀色小件时检查颜色是否还在，也检查相应R/B是否被主体覆盖。提取高频结构仅能留下部分凹凸明暗，不能恢复原彩色标记。高通底层名称带“native detail”不是证据。保形换色、提取重组和撤除按实际选择验收，不强制与原皮逐像素相等；原字义和新布局的可读性仍要看模型。

可用随包工具测量已确认、保持同归一化UV的小范围：

    python -B -X utf8 scripts/native_detail_probe.py DETAIL_SAMPLES.json --out NEW_DETAIL_RESULT.json

输入schema_version=1，samples是非空数组。每项含id、physical_location、action（retain/recolor/extract_recompose/replace/remove/inspect）、mapping="same_normalized_uv_texel_centers"、reference/current/mask的file与sha256、channels（例如C的RGB、N的GA或RB），可选max_abs_error（默认0）。mask是reference尺寸的非空二值L图。先确认两张图对应同UV；移动后的提取图应另建对应，不能把这个诊断当成自动重定位。

工具在原图纹素中心取当前图样本，逐通道报告误差、异常像素和采样数。不同尺寸时同时报告映射到多少个当前纹素；它不是面积覆盖或重采样正确性证明。retain超容差时退出2，其余action只测量，不自动宣布设计通过。只有C可将RGB/chroma解读为颜色；N的RGB是打包数据，A绝不是透明度。没有实际A的RGB输入不能用于GA/Alpha保留证明。无损canonical与有损DDS分别判断，压缩容差来自实际编码合同，不任意加大。

### 已被压灰的小件怎样补回

先从原皮候选局部和真实模型确认要恢复的彩色插片、标线、色点等，排除锈色和低频污斑。只在确认的小范围提取实际图形，必要的一圈边缘也使用该范围的真实源像素，不恢复整块旧迷彩底板。原C的RGB与图层覆盖分别处理：覆盖来自已确认遮罩，不能把原C的迷彩控制Alpha直接作为新图层透明度或最终C Alpha。

在编辑器将恢复层置于会覆盖它的底漆/纹样之上，同时恢复对应N网格上的真实材质通道。C为4096、N为2048等情况分别生成范围；不可将N当普通RGBA缩放。最终DDS再对照所有恢复纹素，不能只证明生成的透明PNG正确。

A7HU修正中，13个已检查的原生彩色局部在最终C对应6200纹素，RGB全部精确恢复；同一红色圆形小件的197个内部样本同时恢复原R/B，G/A保持原生。这个案例中原C Alpha是控制数据，最终固定RGB贴图仍保持Alpha255。随包负例及修复后的正例均保留，见[工程副本回放与修正](existing-project-replay.md)。

模板native_detail_plan中的inventory为制作备注，每项记录：part、source_resource、source_file/sha256、source_region、kind、action、retained_content、changed_content、layer_or_material_ref，以及实际观察结论。它们用于落实设计，不代替既有coverage、真实图层、materials和channel_repairs字段。

例如，保留原舱盖开合箭头：记录原C与舱盖UV位置，action=retain；若做成图层，layer_or_material_ref指向真实图层ID；若改白字为暖灰，action=recolor并说明仅油墨改色。只有纹理上实际存在的箭头才能这样记录，不能把这条示例当作所有车型必有的部件。

## 最后逐类对照

- 原图有而现在消失：小字、盖板编号、方向箭头、涂画刻线、色环、反光片是否被底漆误盖？
- 原图有而现在变平：焊缝、铸字、握把沟槽、防滑和钢索是否被N/AO全局处理抹掉？
- 新图加了却显假：是否出现重复警示、毫无对应设备的小词、每颗螺钉都亮银、所有孔洞都画黑？
- 整体仍太素：先找该区域缺的是材质区别、原生细节还是副装饰，再按部位配方补齐；不直接全车铺蜂窝或白线。
