# 共同规则与旧资料读取顺序

先读 SKILL.md、primary-anchor.md 与本页，再按问题读取旧专题。旧参考的历史配方、试验值和认可状态仅解释各自快照；后续纠正只在对应问题和目标范围内优先；不把分支配方提升为整车模板。AZUR仍为第一范本，见[主线映射](azur-primary-workflow.md)。

| 通用决定 | 具体做法 | 不推广的案例 |
|---|---|---|
| AZUR首要、M1美术参考 | 从AZUR源码学习整车角色，模型与UV反查 | 不复制整车贴图或把A6HEL配方提升为默认 |
| 母子素材两阶段 | 先提取，再规整，再适配真实承载面；透明和工整分别检查 | 不宣称程序重画是生图，不强求每次必须重画或生成 |
| 标签真实 | 按车型／部位语义、单位身份、获准文字重排 | D-TECHNOLOGIE、FY-4 ERA、APS不通用 |
| 真实面覆盖 | 分应填、禁绘、保留、共享；完整窄组件与UV留边 | 不以95%总覆盖放行遗漏铰链，不把所有三维间隙当UV留边 |
| 大块与小块有主次 | 主板面较大几何分区，局部低对比像素块 | 99A ERA分块和A6HEL首上大块选择不互相覆盖 |
| 清污留磨砂 | 分离C低频污渍、微纹、N反射／法线和AO | 不用硬亮度阈值保留正常漆面黑斑 |
| 材质分工 | 主体、蜂窝、火控壳体、镜片、轮履、网布各自遮罩 | 不固定R/B或法线强度；黑金属不加黄线 |
| 混合材质Alpha | 同图漆面与镜片像素分区，所有mip和共享者检查 | 不全图Alpha255，不把N.A当透明度 |
| 共享UV诚实 | 列出全部使用者，选择可实现方案 | 独立双面字向不能靠重复贴图；改模须单独授权 |
| 真实实装闭环 | 实际选择名、路径、配置、文件哈希、刷新后反馈 | 离线正确和写入磁盘均不等于游戏视觉获准 |

规则的证据身份与适用范围见 rules.json，车型例外见 [vehicle-cases.md](vehicle-cases.md)，镜片与材质诊断见 [material-and-alpha.md](material-and-alpha.md)。
