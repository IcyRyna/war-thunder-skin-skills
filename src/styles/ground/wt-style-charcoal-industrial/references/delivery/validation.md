# 炭灰工业 0.2.0 验证范围

## 已验证

- **AZUR 范本**：v29 运行包（`勒克莱尔AZUR_磨砂金属涂装.zip`，SHA-256 4f9e0ab2…，与保留身份一致）的车体、炮塔、侧裙、炮管、栅格 5 张 C 贴图在内存中解码并逐块测量；审美文档中的灰阶、碎片、数码、蜂窝、警示、铭牌和点缀色数值都来自这次测量。
- **回归**：292 项单元/集成回归全部通过，包括新规则测试（AZUR 默认元素、`pixel_field` 必需、`circuit` 须附用户原话、未知角色拒绝）与 32 项素材的细线/字高区域检查。
- **素材**：14 项 AZUR v29 子版由确定性程序生成（重复运行哈希一致），逐张目视验收；平铺块 2×2 重绘无缝，侧裙亮格最小间距 ≥4 格。原有 18 项与三套防滑四图保留原字节。
- **安装**：独立解压覆盖 Skill 单独使用、兼容入口 `verify_package.py`、缺素材包拒绝、并排目录、任意路径与环境变量定位；Skill 与素材包逐文件哈希校验。

## 明确保留的边界

- 新规则和 14 项新素材只在合成用例和素材检查中验证，**尚未用于新车整车制作**；美术认可由用户判断。
- 按 0.1.6 写的车辆工程需把 `policy_version` 改为 0.2.0，并补 `pixel_cluster`、`rear_pixel_band`、`long_barrel_zone` 与 `pixel_field`，或改 `adapted` 写明理由。
- 装饰手法中标"延伸"的做法和密度预算区间是在 AZUR 视觉语言内的经验值，待实车调整。
- 没有新的游戏实装、其他 LOD 与全部运动/附件组合验收；AZUR 圆镜 N.B147 仍待游戏反馈。
- 工具检查验证范围、身份、像素和回执，不能决定美术是否认可。
- 历史研究图库、原车裁片、未核实 AI 元素和过程记录不进入发布包；公开包不携带机器绝对路径或内部聊天。

## 使用前检查

```text
python -B scripts/verify_release.py
python -B scripts/verify_release.py --assets "独立素材包目录"
```

完整制作仍用 `vehicle_review`、真实编辑器/模型回执与 `delivery_validate`；包完整性检查不替代涂装验收。
