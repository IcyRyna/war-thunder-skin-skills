# 实装、验证与工作集

实际选择名称、安装目录、BLK 绑定、DDS 集合与逐文件哈希组成同一部署回执。包体更新时可在本次授权内同步同名游戏目录；写入磁盘、游戏加载和刷新后的视觉确认三项分开。新文件名或哈希改变不证明旧差异是缓存造成。

用户说“没有实装”时先核对真实选中名称和对应目录，不用另建一堆相似名字让用户猜。诊断临时字母、材质开关或 Alpha 试片完成后恢复正式声明版本，记录阴性结果。重装后仍不同应继续查 C/N/AO 与 shader，不能继续归咎于残留。

最终 DDS 回绑模型，全部 mip 与保护区核验；左右成对、顶部、首下、附件和小件按实际风险检查。离线 AO、曝光、纹理来源和附件状态明确记录，不能用展示灯光掩盖实车问题。普通 UserSkins 无法改模型 UV；改模路线需要单独授权，模型／纹理配套回读与回退。

按[包体预算与任务收尾](package-budget.md)执行：游戏ZIP < 100,000,000字节，解压文件总和 < 200,000,000字节，逐成员回读核验。制作中保存必要原生工程/检查点；完成后不保留源码工程压缩包或完整回退工程包，不再建立替代备份。原始下载、公共模型与参考输入保持原归属；不长期保留每轮完整解包、展开基线链或重复渲染。游戏包仅运行文件，图片另交。

七视图按次明确授权，日常修改只用必要近景与现有图。Composa 每批核对自有文档、保存检查点并关闭，不能关闭用户原有文档。单 GPU 的重型整车渲染串行运行。

技术数据、离线视觉、游戏反馈、用户评价、独立跨车复现和发布授权分栏记录。当前未见车型独立迁移未运行，技术回归数量不等于整车成功率。
