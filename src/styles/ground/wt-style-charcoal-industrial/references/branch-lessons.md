## 不直接合并的选择

1. 中系炮塔 ERA 配低可视国旗是 0.1.2 的阶段要求。99A 后来明确取消。保留“装甲模块图案与侧裙区分”，撤销“中系自动加旗”的通用规则。
2. 99A 首上最终是按实际 ERA 块组织的灰阶＋暗实心蜂窝，最下窄立面素色；A6HEL 首上最后不要蜂窝，改较大的中性灰几何分块。两项按车型并存。
3. APS-HUNTER 是源图装备声明。AZUR 和本次 A6HEL 的用户纠正均不支持直接继承；D-TECHNOLOGIE 和 FY-4 ERA 也只在本车已批准语义内使用。
4. 诊断时暂改 N、网布 Alpha 或试验字母，只能说明对应实验观察。无变化的试验保留为否定证据，不能写成已证明根因。
5. A6HEL 的 A7V 材质参考、R/B/C 数值、法线缩放、金属增幅均是案例。用户后续改变了材质方向，旧配方不能倒灌为默认。
6. 0.1.3 Skill 登记仍待修订；A6HEL v43 作品获发布授权不等于该 Skill 已审或整体全部细节获认可。0.1.4 的 99A v52、AZUR v29 的圆镜也各有未评边界。

## 后续最需要改进

- 用 AZUR、A6HEL、99A 的已见经验建立反例回归，再选一个未参与提炼的新车型做完整独立迁移；当前没有新的未见整车结果。
- 选区检查同时度量总面积和每个窄部件的完整性，检查共享使用者、遗漏及越界；不能用漂亮单视图代替。
- 工具调用链把装备语义接到实际合成入口，并以真实带标签素材验证错误车型拒绝、正确车型可用；本候选补通了传参。
- 同一 C 图建立漆面／镜片／裁切材质像素分区；shader 允许不透明漆面不等于整图 Alpha 可以统一。
- 游戏对比固定当前文件身份和实际选中目录；相同光照用于定位颜色与材质，但离线近似仍不代替引擎结果。
- 旧分支曾保留压缩自包含当前／回退对；该保留策略已被2026-10-27[体积与收尾要求](package-budget.md)替代。制作中按需取材与临时导出，完成后不保留源码工程压缩包。
