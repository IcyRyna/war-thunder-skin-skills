# 清晰度与风格迁移

把原作拆成用途与视觉关系：炭灰大面、连续模块、少量亮格、技术线路、仪器焦点和有功能位置的橙色警示。目标车按真实板缝、设备和装甲组织这些关系。完整C面板中的螺钉、接缝、烘焙光影、网布和源车磨损不能随透明底一起搬入新车。

透明不是内容正确的证明。分别检查提取和规整；规则几何共用母版，连接/端点、格数和已知文字有显式核对。按最终UV尺寸测有效线宽、字高与间距，不能拿大PNG画布当高细节。容不下时改位、减量或重制，不能拉伸压糊。

母版可用于目标适配子版，也可只保留其配色和标记节奏。AZUR完成版的遥控武器站外护罩最终采用黄青小色标；这展示了小件需要留白，并不规定所有车型同一部位都必须只有色标。蜂窝和线路母版仍是其他合适承载面的可选词汇，不是全车默认贴花。

本车原始底材与材质提供结构。先检查整个UV与全部部件，再按材质保护镜片、网布、橡胶、履带等；不要因节点名或高度一概保留整片原色。平面颜色素材不自动增加真实浮雕或新模型几何。
