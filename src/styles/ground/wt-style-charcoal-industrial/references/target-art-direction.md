# 每辆车开工填写

在本车任务设计记录中填写实际选择，不能只写“使用S42风格”。

| 项目 | 要给出的具体决定 |
|---|---|
| 车型与附件 | 精确型号、原生UV、游戏可见附件、共享/镜像区域 |
| A/B/C主灰 | 目标RGB、主次范围、哪些真实板面采用B/C；比例只是构图建议 |
| 大几何 | 首上/炮塔/顶部各自的大块边界和板缝关系 |
| 小灰块 | 哪些区域有、灰阶、节距、密度、邻面延续与安静区 |
| 蜂窝 | 侧裙主带与炮塔局部的尺度/线面区别、禁绘面、窄面/留边 |
| D01—D04 | 本车身份和实际功能标签、依据、位置、尺寸、两侧朝向；不存在则写明替代 |
| D05—D06 | 黄青微色标位置；车尾橙黑线的两侧承载面、条数/角度/边距 |
| 材质分工 | 主体、蜂窝、火控、炮管/炮根、玻璃、橡胶、网布的处理与保护区 |
| 六区完成度 | Z1—Z6各自已完成、未完成、明确不适用项与理由 |
| 最终验证 | DDS/mip、绑定、实际加载目录、文件哈希和游戏反馈；七视图授权单列 |

缺内容先完成实际设计决定，再上车；此表不授权虚构不存在的设备，也不要求每次生成六张图片。
