# 母版 → 生图适配 → 二次规整 → 原生UV

使用生图前读取环境提供的 imagegen Skill。输出独立透明图形时请求真实透明背景；目标模型截图仅说明载体，不允许把截图的阴影、金属底板和螺钉烘进贴花。

1. 打开母版、对应原作/认可AZUR局部，以及目标实际模型与UV成对证据。声明本次用途、物理长宽、UV变形、板缝、禁绘区、目标像素预算和保持项。不能只给一张宣传图。
2. 第一次提取：从来源分离图案，保留形状、连接、颜色层级；检查外缘、格缝与孔洞。保存提取结果、来源哈希与问题记录。已有干净母版可复用，不重复抠图。
3. 目标适配：将母版和目标边界一起交给生图模型，生成适合目标的子版；可以重新排布、改变行列、局部裁切，但不要拉伸正六边形。用户要求只使用现有素材或几何变换已足够时可省生成，并记录理由。
4. 发现歪斜/线宽不齐：再次调用生图，以第一次结果为输入，明确“只规整允许区域；等边六边形、统一间距、正确连接、保留原数量或已声明的新数量；保持外轮廓和配色；透明格缝”。保留前后两版。不能因为Alpha存在就认定完成。
5. 二次结果仍不合格：报告具体失真，不无限盲重试。以共享正六边形网格/路径/实际字体辅助约束，再进行局部回填或重制；区别几何重制与原像素修复。不得以大幅简化丢掉原风格的材质层次、亮格节奏和面板关系。
6. 入库前：原尺寸与放大、深浅底、外缘/格缝、数量/连接、已知文字、与母版同尺度并排；未知微字省略/保留模糊，不补成假清晰文字。看实际目标模型上的最终像素，合格才合成。

记录 parent、extracted（若复用母版注明）、generated_child、regularized_child、target_preview 的文件与哈希；prompt原文、生成方式/工具、允许改变区域、保持项、实际变化、技术与视觉判断分开。目标子版视觉pending不等于母版几何失败。

建议适配提示：以给定母版为图形来源，按给定目标边界重组；保留暗实心单元/稀疏亮格/细线路的层级；只输出正视二维图形，真正透明背景，无外加金属底板、阴影、照明、未知文字；不修改目标模型结构。

## 99A试验新增门槛

二次生成必须同时比较几何、色相、明度和布局。色偏改善但整体变亮，仍需范本灰阶校准与模型回看。生成原图和最终C图校色分别留存，不能把后期处理归功于生成模型。案例见pilot-99a.md；不把包围盒相近或单元数一致说成全部六边形精确等边。
