# 实际承载面与最终像素预算
1. 冻结原模型三角形、UV、材质槽和节点身份。以物理用途选部位，不把文件名或 UV 矩形等同部位。
2. `carrier_visibility.py` 的 BVH 三采样射线剔除被遮挡面，UV 零面积另行拒绝。至少两个样本可见是本试点粗筛；它不能证明所有摄像机角度无遮挡。保留原始完整几何。
3. `native_carrier.fit_carrier` 测量真实板面法线、切向轴、米制范围及局部 texel 比例；拒绝空面、零 UV、越界偏移。左右表面单独测量，不假设等宽或可镜像文字。
4. 每个细线/文字子版用 `style_quality.check_detail` 在最终分辨率校验。A6HEL 的初版8px线路落地仅1.322px；窄左门最终使用18px线路子版。不得关闭检查来贴进去。
5. 每个图案单独 rasterize 所选承载面；多层共享 UV 的全局“最后写入面”不作为放置权威。对称无字字段与有字独立面分别验收。
6. 用关键近景反查：框线、字、六边形不能被上层螺栓/架子挡住到不可读；移位必须仍在本板面。实际遮挡检查在整车高分辨率之前执行。
