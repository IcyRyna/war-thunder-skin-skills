# AZUR生产学习记录：失败 → 原因 → 修正 → 检查

这些结论来自同一AZUR的串行返工；不能把多次修订视为独立成功。作品评价保留各阶段范围；0.1.2分支不单独发布，筛选后的规则纳入本0.1.5。

| ID | 失败与证据 | 解决步骤 | 验收与适用边界 |
|---|---|---|---|
| L01 | 原作完整面板被误当透明贴花，夹带机械底板/模糊 | 原作模型+UV配对；分离图形后规整；母子版留身份 | 源/子版/目标三方看；透明不等于干净 |
| L02 | M1网布在无该几何的AZUR上变成平面纹理 | 识别真正载体，AZUR首上改本车漆面灰块 | 不向无网布车型搬网布明暗；不是全车型禁止网布 |
| L03 | 游戏偏橄榄，离线正确 | 已核实不透明C使用set_tex/camo_skin_tex和完整Alpha覆盖 | 全mip+游戏刷新；联合修复，不伪称两处独立因果 |
| L04 | 后续主体偏蓝，用户要求压黑哑光 | 主体漆面中性化、一次压暗；按已核实N通道调哑光 | 颜色契约优先于原作“偏冷”；保护彩色细节和N数据 |
| L05 | 镜壳、下部、背面、UV岛边仍有原皮 | 按材质拆保护，全C图底色覆盖，再局部装饰 | 完整UV遮罩与模型回查，不按MG/decor整组跳过 |
| L06 | 顶板警示跨板缝，灰棋盘像贴纸 | 顺真实单板布局、撤去被否定灰块与多余标记 | 继承板缝关系，不规定所有车型只能一块警示 |
| L07 | 蜂窝歪斜，透明也不合格 | 提取与规整两阶段；再生图修正，必要时几何约束 | 数量/连接/间距/同尺度对照；不能用简化重画替代风格保真 |
| L08 | 点缀贴到隐藏机枪而非可见护罩 | 模型确认材质槽和可见承载面再映射UV | 本车外罩最终黄青小标；不泛化成所有机枪只许色标 |
| L09 | 后续三车型只剩灰黑+大蜂窝+黄青装饰 | 整车视觉参照、颜色目标、主要图形家族、阶段审查 | 三车型为已见偏差样本；不把9项工程单测当跨车视觉验证 |

最终认可基准文件哈希见 azur-reference-lock.json；本地研发 evidence 保存源脚本、用户要求归纳与负例证据，不在独立包塞入全部对话和机器环境。

- L10：第二次生成消除偏蓝但提高灰阶 → 同时审计色相/亮度/布局，最终C图按范本校准并明示后处理。
- L11：选中的节点仍共享8270个UV像素 → 从其他三角面覆盖求交，保护共享像素后回贴；不能只验证贴图外部不变。
