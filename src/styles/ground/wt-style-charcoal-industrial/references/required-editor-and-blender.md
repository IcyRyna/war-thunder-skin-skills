# 必须实际使用PS工具，Blender可用时必须调用

本约定适用于实际涂装创作和实质修订。编写Skill说明、只读查资料或单纯重新压缩，不需要为了凑调用而伪造编辑过程。

## PS / Composa是必经制作阶段

本工作区的PS风格分层编辑入口是Composa MCP。当前工作区和独立包的写批次优先使用随包scripts/editor_batch.py串行互斥；它调用随包composa_mcp.py。photoshop-tools项目的通用客户端可用于只读诊断，直接编写客户端调用脚本时应使用同一editor_lock覆盖完整写批次。真实Photoshop桥若由目标项目明确配置，以其已实现接口为准，不把Composa说成Adobe Photoshop插件。

开始先连接并读取实时工具schema，核对打开/新建、导入图层、描述、保存、导出及自有文档收尾能力。用户已启用Allow AI Control时直接进行本次已授权操作，不反复要求勾选。暂时无工具先重连诊断；确有连接/权限阻断时保留响应，报告具体未完成阶段，不把纯脚本合成冒充PS已完成。

实际制作至少有以下可核验工作：

1. 在编辑器中打开或新建目标尺寸的基底/原生工程，核对文档身份与颜色/Alpha职责。
2. 导入本车的底漆、几何分区、蜂窝、车型贴纸、微色标及车尾警示等实际图层，命名并组织顺序；需要修改时在编辑器内修改或用经过检查的目标图层完成实际分层组装。不是只打开最终平图再关闭。
3. 保存原生可编辑工程。本环境使用CMPS；若真实Photoshop桥采用PSD则保留实际PSD。不把格式改后缀冒充原生工程。
4. 实际导出关键颜色图/需检查的层，与声明的规范合成来源比较；复制原生工程到验证目录，重开并核对图层和导出结果。已证明的半透明RGB舍入容差只能在对应区域使用，不能扩大到Alpha或保护区。
5. 保存本批会话回执、原生工程和关键导出哈希、重开结果；结束前核对并关闭本批自有文档。原本已打开的用户文档不变成AI所有，保存失败或身份冲突时保留工程与检查点。

Python可辅助精确几何、遮罩、源数据处理与DDS/mip导出，不能取代必需的真实分层编辑器阶段。打包N.A等数据Alpha不能当图层透明度；必要时用RGB画布和独立数据通道配合规范脚本，明确谁是最终合成来源。

独立批次示意：

```text
python -B scripts/editor_batch.py --calls calls.json --out NEW_EDITOR_SESSION
```

calls.json必须按本次实时schema编写；不把示例参数当跨版本固定API。当前曾核实open_document、place_image、new_layer、describe_document、export_image、save_document、document_state、save_checkpoint、close_document，后续环境更新后重新核对。

## Blender有实际可用能力就必须调用

不能因为没有GPU或使用网页预览器，就省略已具备的Blender模型检查。先从项目固定工具入口、配置、PATH或已验证的便携运行时发现实际程序，检查版本、后台bpy与本车导入能力；旧日志中的临时路径不是仍可用的证明。不得静默升级固定版本，也不因一句“有能力”无限下载/更换工具。

环境可用时，在实际制作流程调用Blender完成：

- 用本车真实模型检查部件、材质槽、原生UV、共享/镜像、顶面遮挡、附件和两侧字向；模型定位与UV细节配对。
- 将本次最终DDS按已确认C/N/AO语义重新绑定，记录实际输入哈希，检查首上、炮塔、侧裙、顶部、观瞄、车尾六区及变化部位。不能只重开未更新的旧blend或查看概念图。
- 保留本车模型/UV工程或具名检查报告与必要证据；原工程先复制到验证路径再测试，不覆盖交付原件。普通路线不改原UV，改UV须本次另有授权。

后台方式可用时优先脚本化，使用实际二进制并设置--background、--python-exit-code 1；只读模型检查可使用隔离的factory-startup和禁用嵌入自动执行。具体导入/材质API依据已安装版本核实。

Blender调用不等于必须渲染整车图片。默认展示仍复用本地交互预览器；只导出本次需要的近景，七视图逐次取得明确授权。需要重型渲染时单GPU串行。

如果程序、API或目标模型导入确实不可用，记录已检查入口、错误与未覆盖项；可继续PS和其他可完成工作，但不能将Blender阶段或独立模型检查标为通过。

## 最低制作回执

本车任务保存：实时schema与编辑器批次、真实编辑/图层组装说明、原生工程、导出与重开检查、owned文档收尾；Blender能力发现与实际调用/输入/结果，或真实不可用原因。公开作品页不附内部会话、机器路径和调试日志。
