# 补齐 AZUR 主图形家族

assets/azur-shapes 原字节保留AZUR生产链的蜂窝单元、APS面板、线路、警示、NO STEP、ELECTRONICS/ACCESS与箭头图形；不是新的已认可目标成品。它们的早期RGB可能含冷灰，使用前依 visual-contract.md 在明确子版中调整颜色。不要因本候选包含它们而跳过style_quality授权；未形成独立合格子版的源形状仍是研究输入。

| 家族 | 可复用内容 | 目标适配要点 |
|---|---|---|
| honey-unit | 实心单元、边缘关系 | 按真实装甲幅面生成较细连续带，少量亮格，不改成满板白线 |
| aps-wide | 外框、蜂窝组合、两侧窄灯条与文字层级 | 有真实对应用途再用文字；不照搬不相关硬件名 |
| circuit-traces | 转折与端点连接 | 依目标平面重排线路，不每块板重复同图 |
| blow-out / no-step | 警示与边界层级 | 仅用于合理承载面、符合板缝；AZUR只保留单块顶板警示不是所有车型数量规则 |
| electronics/access/edge-chevron | 小型功能标识 | 核实字向与真实区域；不跨折面或虚构接口 |

主入口不再只提供四种小件点缀。整车成套关系见认可七视图；灰块和蜂窝带在目标物理空间重组，原始图形与最终配色资格分别记录。灰色武器站大蜂窝/线路被用户取消；hex-trace母版可作其他位置研究，不把被取消的位置称作已认可方案。
