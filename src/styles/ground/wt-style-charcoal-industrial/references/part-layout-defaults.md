# 各部位默认做什么

**来源顺序：AZUR整车构成与制作方法 → 当前目标车真实承载面 → 后续车型纠错。** 适配案例只补充边界；13项的来源关系见[AZUR主线映射](azur-primary-workflow.md)，机器入口为style-policy.json的reference_hierarchy与primary_basis。

这是制作前的默认配方，不是交付前才看的遗漏清单。先确定首下身份、顶部警示和侧面焦点的承载面，再安排底色、蜂窝、防滑和微色标；当前用户对本车的明确选择优先。默认要求处理该设计角色，不代表所有车型都有同一种设备。

## 首下：先确定能看见的身份构图

默认本车型字标，可有变体/短主题副行；短橙黄斜条是可选衬托，不强制两侧都有。首下被备用履带/拖具遮挡时先核对可用平面：能成立的真实功能词、缩短的身份图组或无字图形均可作为替代。禁止照搬ELECTRONICS ACCESS、TOWING POINTS或另一车名称；禁止无限缩放去塞遮挡处。

## 炮塔顶部：底层、警示、设备三个层次一起设计

1. 先定位实际盖板功能、把手、设备遮挡与原生防滑块，选警示图组的承载板。警示要作为完整文字/斜条组合安排，不能只放一张很小的黄标签就算完成。
2. 记录carrier_size_m、graphic_size_m（旋转前源画布在板面上的物理宽高）、rotation_deg及margins_m（左/右/上/下）。由真实面探针计算旋转后的四角、实际边距和可见性；不能仅填写readable_at_normal_view或手填余边作为通过证明。两组数量、90度旋转、固定米数都不是跨车默认。
3. NO STEP用于适当可见位置；BLOW-OUT只在本车确有对应弹药泄压盖并有依据时使用。不存在泄压盖就改真实适用警示或无功能文字图形，不能用风格名义虚构。
4. 在警示及设备周围安排A/B/C几何、局部低对比块、高清防滑和安静区。图组与旧防滑冲突时，明确保留或清除对应C/N旧块；不要最后靠涂白底板遮住。文字居中按字形边界，检查上下留白、左右色标间距、板缝及手性。
5. 圆盖连续灰、撤去大V、某车更大警示均是具体目标选择。通用规则是按真实板件和可见性设计，不是所有车强制纯色圆盖或禁用所有V。

现有警示被附件遮挡时，先固定真实完整盖板的构图范围，再计算可见区域供核心文字选位。图组可拆成文字、斜条等重新排布，但不能把整组缩进一个空闲角落；要求占满时，斜条与副图形继续覆盖整块盖板的构图范围，包含设备下方原本就存在的板面。保留必要板边余量和实际孔口，不把占满理解为整板实心橙色。

核心文字遮罩绑定改制后源图，独立测可读性。非文字斜条受本车设备自然遮挡时，按当前明确整板要求记录具体取舍；不能同时放行被挡住的核心文字。A7HU先前“缩到右侧可见块、全部墨迹100%可见”的方案已被用户否决，不能复用为成功配方。新的整板布局横向延展93.17%、纵向86.77%，图组内容包围面积占完整盖板81.17%，核心文字仍100%可见；整体墨迹可见率77.95%的原因是实有武器站遮挡，而非删除被遮区域。数字仅适用于本车当前静态装配与所检俯视。

## 机枪与观瞄：必须逐组件完成

机枪至少分别定位housing（护罩/枪座）、gun_body（金属枪体）、stock（枪托/握把）、ammunition（弹链/弹箱）。分别填写实际coverage_id与face_group_ids或不存在的依据；不能让同一枪座面组证明所有组件完成。黄青微色标优先护罩，其他承载面须有明确构图理由。枪托聚合物与枪体金属的R/B分开。

观瞄壳体完整处理顶面、侧壁、压条与窄唇，镜片独立保留。主体磨砂、蜂窝较轻反射、深色观瞄、机枪金属与聚合物应在同光照和转光时读得出差异；写入不同数字不等于实际材质已经有层次。

## 把默认落实到模板和脚本

style-policy.json中的part_recipes是机器入口；vehicle-review.template.json已带13项内容。apply_default必须实际包括默认元素；adapted逐项说明被替代/取消的元素；not_applicable必须有本车缺失或当前用户要求的证据。local_microblocks是可选细节，首上与顶部仍必须完成大灰区、防滑及必要留白；不要求为了过检查强加数码块。所有实际部位记录遮挡/字向/留边检查。备用履带按本车实际位置归入首下或车尾，不固定Z6。

每个部位的完整覆盖只针对已经决定的面。前向挡板、水平平台、折边、框条、百叶叶片和工作面分别分类，允许某类面绘制不等于默认必须画满。

## 材质、主副装饰与原皮细节一起落实

制作时必须结合[部位装饰与材质配方](decoration-and-material-recipes.md)的材质表和21类部位搭配，以及[原皮细节复用](native-skin-detail-reuse.md)。13项机器配方各有surface_recipe；模板各有finish_plan，提供材质起点、主图、副装饰选项、应检查的原皮细节和最终观感目标。

可见主要区域不能只填“已刷灰”或“有一张铭牌”。副层级可由适用原小字、刻线、编号、真实小件和材质对比提供，也可选择新短条、角标、小块或色标；不要求固定贴纸数量，不把所有可选元素堆满。原皮无此内容时由AI按真实承载面选其他组合。

finish_plan与native_detail_plan是设计/制作备注，AI随本车工作完成；它们不独立产生技术通过。实际图层、范围、材质和通道变化继续绑定既有严格契约；最后用已有模型预览确认丰富度与主次。
