# 分阶段送审与独立证据

G0 输入：资源/模型哈希、原生UV、材质语义、占用与保护理由。缺一项则先查清，不进高分辨率贴花。
G1 底材：目标中性基底C与明确paint mask统计；灰块明暗；同灯光AZUR/目标并排。首先暴露偏蓝、偏亮和材质高光。
G2 布局：侧面贴纸按目标车型重新设计；99A取消国旗，使用本车FY-4 ERA和差异化蜂窝。将炮塔蜂窝与车体蜂窝同屏比较（见vehicle-specific-decals.md和vehicle-families/cn-turret-era.md）。整车主模块带、炮塔次级模块、首上灰块、少量警示与留白。只给颜色+蜂窝清单不算布局通过。按实际承载面说明改位和数量变化。
G3 子版：母版→生成→规整→透明与几何检查→目标模型；存在歪斜或像素预算不足就退回该子版。
G4 全UV：所有资源职责遮罩、未分类/重叠为0、保留区逐像素检查、未变漆面疑点人工回查；小件与背面截图。
G5 交付：最终DDS/mip、模型重绑、CMPS副本重开、本次已授权的部位预览、游戏验证状态；七视图须逐次获用户明确授权。技术通过与视觉通过各有状态。

每阶段记录输入SHA、输出SHA、命令/工具、问题与修正、review(pending/accepted/rejected)、reviewer与证据。自动统计不能把review写成用户认可。模型/照片曝光不统一时不得据截图RGB下最终颜色结论。

新版本试验先冻结候选，再独立重跑；本轮AZUR和99A/A7V/A6HEL均已见，用来回归不能算未见迁移样本。未执行整车重跑保持not_run。真实成功率分母包括失败、放弃与工具异常；局部工具单测不是整车成功率。
