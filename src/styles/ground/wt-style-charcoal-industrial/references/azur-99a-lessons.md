# AZUR 范本 → 新 Skill → 99A 实车验证

本会话的起点是根据S42风格的AZUR源码梳理Skill，再用新Skill制作99A检验迁移。AZUR有实际模型、原生UV、C/N/AO、分层工程和生产代码，适合追溯每层作用；M1仅美术参考。不能把99A历次失败输出重新包装成独立成功范本。

历史AZUR整车曾获认可；当前登记为AZUR v27、99A v52的近期修订尚待分别评价。当前身份与原始证据哈希保存在本地任务，公开可分发包只带方法和精选参考，不带本机绝对路径、对话、整个模型或全套游戏资源。

| 已遇问题 | 可迁移的解决方法 | 范围 |
|---|---|---|
| 只贴符号，没有学到AZUR整车关系 | 顶部/首上相近灰色交错、低对比几何切分与方块衬托；先整车层级再微字 | 风格关系，具体块面逐车重排 |
| 首上单块爆反出现无理由两色 | 依实体板缝给每块主色；几何切分另有意图，不能用任意矩形掩码截断板面 | 设计/遮罩 |
| 侧裙后半漏铺、铰链溢出、半格与缺角 | 实体面清单、网格原点/尺度与留边、完整格或连续底纹模式明确 | 目标几何依赖 |
| 前爆反某些蜂窝淡糊或边缘漏填 | 检查源图渐隐、Alpha、密度和mip；物理坐标延展纹场后用真面裁切 | 有限源画布问题已在99A查实 |
| 模块名称不适合目标车 | 无字母版起步，标签先核实，再按车型制作子版 | 不允许FY-4 ERA通用化 |
| 国旗难认、共享UV反向、误放两个国旗 | 查真实共享并解决方向；当前99A按用户要求取消国旗 | 本车最终要求，不泛化禁令 |
| 文字被板缝、顶部附件和备用履带遮挡 | 模型验证可见承载面；改位、重排或只用花纹 | 不是一味放大 |
| 去污后磨砂消失 | 分离C污色、N低频脏斑与细磨砂；保留结构，单独设金属层级 | 需核实目标通道 |
| 首下备用履带仍原皮 | 识别备用履带块与运行履带、金属/橡胶各自遮罩 | 不按整组节点名保护 |
| 后橙条只一侧、右侧重影和浅框 | 两侧同屏检查；旧轮廓与整片底色分别检查，保护新橙标 | 99A最终C修复技术通过，视觉待评 |

本次明确保留项也要进入表面计划：炮塔侧已有蜂窝不重复覆盖，顶部初始禁铺范围按后续用户圈选变更，首上最下沿素色。当前请求优先，不能重放过时布置。

源码经验不是把历史脚本整段复制为通用流程。坐标、节点ID、灰度、N参数、文件数及安装路径均属实例；重用选择/保护/合成/读回的方法。旧残留需从实际图层和最终文件删除，不能只在新图案上盖一层。
