# 分板 UV 原像素适配

## 先在平面图里确认输入

在编辑器打开原尺寸 RGB UV，再定位目标图案涉及的全部板件。一个完整徽记可能分布在底板、附加板、连接条及窄倒角上，UV 岛相距很远。某片上的黑色三角缺口可能由另一片补齐；它不代表原图缺损。保留原图层，把对应 UV 片、边界和标注独立分层。

包内 B11、B12、B13 为 A7V 原作车首的分板裁片，来源和坐标见 `assets/reference-a7v/front-panel-map.json`。B12 包含主面以及旁边很窄的倒角条。它们是带机械基底的原图参考，不是三张独立贴花；坐标只属于该原作。

## 保留承载面与原作笔画

按真实板件与材质关联 UV 片，包含主面、边缘、倒角、孔壁和背面。按朝上法线或单个平面筛选，会漏掉印有笔画的陡倒角；完整板件筛选又可能混入独立螺栓，需要区分板件的连通表面与机械附件。构件大小、节点名字和最近距离只能辅助判断，逐片核对它实际承载的图形。

拼装检查图从原 UV 采样，记录每片的原图范围、变换和目标 UV 归属。目标车的板缝位置不同时，按完整图形的连续关系重新分配到目标各片，再检查实际空间接缝。用纯颜色查看图核对字形、轮廓与份数，随后用模型检查侧壁和遮挡。UV 共用或退化成线、点时，按实际采样足迹处理，方法见 `formats.md` 与 Skill 的细墙说明。

原作同一品牌可能在炮管、侧裙和车首使用不同字标。按原作复刻时保留该位置的字形、副标题、字距和相对大小，不能把另一个位置的标志当作替代母版。

## 材料与生图的分工

图形相同不代表机械基底相同。颜色层中的旧螺钉阴影、材质纹理与真实印刷分开检查；法线与 AO 按目标结构核对。清理漆面时保留细字和轮廓，筛选机械辅助面时保留真正带图案的小装甲板。

有完整 UV 片时，直接复用原像素。生图适合实际缺损、复杂底图分离或新纹样；生成结果若改动字体、副标题、内部负形或等高线，属于候选重建，不能标为原作复刻。具体检查见 `editor-and-extraction.md`。把失败候选留在任务证据中，不混入正式贴花库。
