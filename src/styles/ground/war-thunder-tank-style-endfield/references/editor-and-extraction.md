# 可视化与素材提取

## 原生 UV 查看

对 DDS 使用 `scripts/export_uv_reference.py DDS... --out 新目录`。这个工具只导出原尺寸 RGB 查看副本，并逐像素复查；原 DDS、原 Alpha 不变。零 Alpha 的 RGB 数据仍可能是 `replace_tex` 的正确输入，不能凭编辑器中全透明就重做整张涂装。

可视化时为本任务建立独立文档，车体、炮塔、炮管按原尺寸分开。底层保留原作 RGB，坐标框、构件标签与修改建议放在上层，便于隐藏。测试打开交付的分层工程前先做验证副本。

## Composa

包内 `scripts/composa_mcp.py` 是标准库 STDIO 客户端，自动查找安装程序。先运行 `python -B scripts/composa_mcp.py --out 本任务新会话目录`，读取真实 `tools.json`，再按返回的 schema 构造调用 JSON。`--launch` 可启动编辑器。输出目录必须新建或为空；批次出现错误后先核对会话结果，再决定下一步，避免重复插层。

连接需编辑器的 `Help > Allow AI Control` 已启用。连接返回零工具时说明实际连接状态，按用户当前授权处理，不通过修改设置文件绕过编辑器开关。

先调用 `list_documents`，识别已有工程。`open_document` 在新页签打开原尺寸图，`new_document` 创建独立画布；后续每次操作用已确认的 `document` 编号。`place_image` 导入原图和标注；原尺寸叠放时用 `fit:false`。`set_layer` 改名、显隐；`save_document` 保存 CMPS；`render` 读取整图或原尺寸区域。编号与参数以本次实际 schema 为准。没有必要切换或修改其他任务的文档。

## 抠图与生成的选择

已取得透明 PNG 或 SVG 的官方标志，保留清晰母版。单色印刷图形落在深色机械底上时，编辑器颜色范围选区通常比重新画标志更能保留原轮廓；例如原作 T07 在 Composa 中选择白色、fuzziness 95，新建透明层填白、隐藏原裁片，再旋转阅读方向，得到原尺寸提取图。该阈值只属于这一次裁片，其他图按边缘、底色和抗锯齿重新判断。

生图可辅助复杂背景抠离、缺失边缘恢复、非标志纹样整理或扩展。输入中明确标出编辑目标和辅助参考，约束应保留的轮廓、文字、负形和色彩；需要透明时请求真正的透明背景。保留原裁片作对照。

对徽记核对三角尖端方向、外框断点、等高线、中央负形、字形与字距；对透明输出放在深浅两种底色上检查。请求透明不代表内部负形就正确；分辨率变大也不证明恢复了原始细节。若结果改变轮廓或字形，留作候选，改用母版或编辑器提取，不能当作 1:1 素材。

本次两次 T07 生图试提都未通过：第一张把内部负形填实，第二张还改变了三角结构方向。因此可用素材库保留官网母版和 Composa 提取图，没有把这些生成候选当成正式贴花。这个案例用于选择方法，不代表所有图形都必须经过相同的重试次数。
