# 运行时素材与可选资料

Skill 的资源必须有可执行用途。原作参考图供观察明暗、字形、负形和布局；真实车型四视供判断承载面；透明 PNG／SVG 供直接制作。这些图保留。带大标题、重复说明和排版装饰的图板、展示网页、演示工程供人审查，展示图板留在仓库文档，演示工程留在本地研究记录，不进入运行包。

## 实际制作素材

- [整张英文工业透明 PNG](../assets/legacy/decals/endfield-industries-en-native.png)：400×400 画布、有效墨迹 122×122。统一缩放与平移，保留整体三角、轮廓、ENDFIELD、INDUSTRIES；不裁断、不拆字、不加独立不透明底板。大尺寸先检查清晰度。
- [中文工业 PNG](../assets/legacy/official/endfield-industries-cn.png)、[英文游戏标题 SVG](../assets/legacy/official/endfield-title-en.svg)：保留原来源、身份和用途。游戏标题不是工业组织徽记，也不是可输入任意文字的字体。
- [社区英文工业 SVG](../assets/identity/community/endfield-industries.svg)：可缩放社区版本，保留 [MIT LICENSE](../assets/identity/community/LICENSE)；与 A7V 原作者母版区分，按目标尺寸核对细节。
- [25 个第一批可编辑组件](editable-drafts-index.json)：路径、几何、标签、纹样等 SVG／PNG 草案，可改、可不用。
- [D02–D08 七个可选模块](optional-components.json)：前肩负形、前后明暗、偏置前甲板、安静尾部、设备字级、等高线、微量辅彩。按各部位重新组织，不当作完整车身贴纸。

普通编号／辅助文字可以编辑；品牌组合保持母版几何。字体没有随包分发，目标尺寸检查字宽、间距、负形与缺笔。默认无做旧，颗粒、做旧和材料结构分开。生图可补非标志新纹样或概念，不重画精确品牌字形，也不生成假车型替代真实模型参考。

## 视觉参考与旧资料

[分区与预设图索引](visuals/index.md) 解释图中各色区域、读取时机和限制。三种车体布局原图及 SVG 作为可选参考随包，不包含网页和大标题图板。

[A7V 原作多视与作者照片](../assets/reference/a7v/) 和 [25 个原作局部](../assets/legacy/reference-a7v/crops/) 用于核对真实视觉关系。裁片带旧车机械阴影／孔／脏污，不直接当另一车贴花。车型四视在各家族 profile，由主入口按需读取，颜色只区分部件。

旧 1.4 的 **40 个文件、61,905,979 字节** 全部原字节保存在可选 `wt-style-endfield-v0.1.0.legacy-assets.zip`；[完整索引](legacy-assets.json) 标明哪些随运行包、哪些只在资料库。[逐件用途](assets-index.json) 继续保留。运行包选入 32 个旧文件，其余 8 个全图 UV、研究板、提取工程和历史 manifest 留在资料库，不要求安装旧 Skill，也不要求正常生产加载资料库。

此前 A7V 九处真实 PS 裁区、两份图板 CMPS 和排版图板继续留在本地研究／既有审查记录。它们是研究和检查过程的资料，不是执行者每次必须打开的生产工程。实际新车的可编辑 CMPS 应由该车任务制作和验证。
