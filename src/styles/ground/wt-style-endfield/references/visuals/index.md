# 给执行 AI 的视觉参考

这些图各有读取任务，不要求一次全部加载。

- 判断本车部件：先读 [车型索引](../vehicles/index.json)，只查看选中家族的侧／前／后／顶原始参考图。大部件颜色与含义见 [index.json](index.json)；光照会改变显示色。H/T/G/M/A/R 分别为车体／炮塔／炮管／机枪座／附件／行走机构，P 是玻璃光学，U 是未分类。子区仍要在实际 UV 定位。
- 理解风格：看 [A7V 原作解析](../a7v-analysis.md) 指到的原作视图和局部，不从演示排版图抄参数。
- 考虑兜底时：[F01](F01-hull-example.png)、[F02](F02-hull-example.png)、[F03](F03-hull-example.png) 是同一勒克莱尔车体的三个不同示意，可比较色块、主标位置与黄色职责。图中炮塔未设计，只说明组合关系；既不是必须采用的方案，也不是原生 UV 遮罩或游戏验收结果。配套 SVG 可编辑。

原透明徽记整张保留，不裁标、不拆字、不额外垫不透明底板。不要采样这些车辆示意的阴影／像素作新车贴图；生产使用对应透明母版、自己的结构基底和实际 UV。
