# 已观察的失败及适用边界

这些是单一执行者的开发实验，不能充当独立复现或用户认可。使用真实模型、原生 UV 与原尺寸局部；DDS 裁区的全 mip 读回和源工程重开是技术证据，离线模型比较是代理视觉证据，二者分开。

**纹样表示错误。** E01 把原图灰绿色墨迹改成白色，并把原最大 Alpha 140 归一到 255，再比较图层0／18／65%。E02 在这个白色重制版本的18%上挖出品牌保护区。它们表现为主标干扰与裁切断头，但不能说“所供 PNG 原样18%也失败”。E03 依次恢复 RGB、恢复原 Alpha，保持其余条件，原样组更安静。保留来源的 RGB 与 Alpha；改变表示必须单列变量，不把变过的素材冒充原件。

**安静底色不等于实际承载面。** E04 第一轮按灰色选区安排局部曲线，实际越过了向上的板件；这轮被拒绝。第二轮移进真实承载区并设计自然端点，减少了与主信息的竞争；保留原布局仍是有效选项。局部路径、数量、位置一起改变，是组合探索，不能归因于某一个透明度值。无需每辆车都增加纹样。

**直线与层级。** E05 比较稀疏单线、粗主线加细伴线、等宽双线三个组合，保留同一徽记、设备信息、底色和材质。用户明确要求炮塔侧面用直线，旧折线候选全部退出该部位的采用范围；新比较按平直路线重做。粗细只是在该表面表达主次的方法，不是全车必须两条线、固定像素宽度或固定面积比的依据。

**图层存在不代表内容已出现。** Composa 1.4.0 的 SVG2 `href` 图像／复用元素曾静默变为空层；本机实际测试中 `xlink:href` 可用。另一 SVG 栅格器又漏了文字。最终必须检查实际有效墨迹、完整徽记和设备字段，再评判设计；编号变化若最终像素没有变化，应判为无效实验。不要只检查命令成功、图层数或文件生成。

**完整徽记需要两种检查。** E06 的显式真实平面映射保留了完整源图比例和原生 UV 承载边界；平面像素矩形不能代替真实比例。99A 开发迁移又表明，源图没有裁切仍可能被模型凸起挡住。需要同时核对源图完整性、最终图集及真实可见关系；避让时整体平移、等比缩小或换面，不裁掉品牌的一角。弯折面上的均匀投影不等于沿曲面等比。

**共享 UV 与遮挡按具体面判断。** 99A 内层炮塔侧板有对侧共享 UV，且被外层反应装甲遮挡；它不是可见外表面的替代。真实可见的外层装甲另有映射，必须分别核对。初轮将完整身份移到顶面，后续核实外层独立 UV 后，按真实外表面补上可分别正向阅读的较大身份与设备组。母版不拆裁，实际窄缝的墨迹中断、外边界与文字可读性分别检查。这个案例已经用于修改，不再是未见留出样本。

当前这些结果仍待具体版本的用户审查；没有游戏实测。不要把技术读回、一次局部可行或代理偏好提升为整车审美稳定性。


## 后续用户选择与修正

用户对 EMBT 对应三处局部选择了：顶盖 A（保留原 RGB／Alpha 的纹样）、肩部 C（等宽双直线组）、正面 B（实际面映射的完整徽记）。这些选择只覆盖对应版本和部位。因此不把“局部纹样必优”“主黄线必须粗、伴线必须细”写成硬规则。纹样的原样低对比表示与整体阅读需要同时判断。

99A 用户进一步指出黄线要顺爆反斜上缘、侧面应有三色条和对应徽记，初轮徽记过小；用户把后续比例判断交给执行者。较大的完整工业身份与三色设备组按实际外层装甲重新排布，源母版未拆裁。真实内部窄板缝会中断少量墨迹，单独记录并检查整体阅读；源图外边界裁切仍为零。不能把“一块装甲只容一个小标”当成通用限额。当前是开发修正与受委托判断，没有整套 Skill 或发布放行。


**放大后仍堆叠。** 99A R11 保住了识别尺寸，却把主徽记、三色条和设备信息集中在同一段黄带下方，用户明确指出堆在一起不好看。它作为布局失败保留。后续从清洁底层重新合成，内部比较前／后主标两个方向，采用主标后置、路线前上、设备组前下的分区；保留主标尺寸并拉开角色空间，不通过缩小整组掩盖拥挤。实际左右模型视图已检查，未把内部比较称为独立复现。
