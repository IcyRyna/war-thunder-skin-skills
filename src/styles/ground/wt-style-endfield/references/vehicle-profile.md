# 目标车 profile 与语义映射

profile 由当前任务实际输入建立，随作品工程保存，包内不提供假装已适配的车型模板。最少记录：具体型号／附件状态、模型与 UV 层、输入文件相对路径／字节／SHA-256、材质槽→资源→原生图集、各通道语义及来源、可读表面、保护区、共享／镜像与独立运动关系。

每个使用面记录 `surface_id`、实际节点／材质槽、图集、UV 岛／遮罩身份、朝向、可见条件、语义职责和检查证据。职责取主识别、次识别、方向延伸、安静机械面或本车必要扩展；不要求所有类型都存在。生产遮罩必须来自本车真实映射，不能拿车型方向示意图当 UV 精确遮罩。

| 冲突 | 可执行退让 |
|---|---|
| 没有连续主标面 | 换面、减少次标、选窄面方案；保持主标几何 |
| 两面共享同一 UV | 共用非文字图形，或只在独立面排字 |
| 镜像面文字倒读 | 迁到独立区域或取消文字，不叠两套相反文字 |
| 炮塔／车体有相对运动 | 分别设计起止点，方向呼应 |
| 炮盾／炮管曲面变形 | 分区排版并在模型检查，避免主体字标跨曲面 |
| 新附件／未知材质槽 | 单独辨认资源、Alpha、保护区后再上色 |
| 参数或通道无法核实 | 保持已核实数据，缩小修改范围并列缺口 |

EMBT 的已见案例混用 A7V 车体、Leclerc S1 炮塔、S2 炮管和专属附件。此信息帮助寻找资源，不能替代当前模型逐槽核对。同名资源也须对哈希和实际采样，不凭名字认定字节或朝向相同。

先在模型定位部位→在对应原图 1:1 检查→修改→重载模型→最终 DDS 读回再检查。记录模型、图集、遮罩、输出哈希与当前相机／光照。共享 UV 要检查所有使用者。原生 UV、Alpha 和数据通道保持精度，轻量预览另存。
