# 从 r11 与旧 1.4 保留什么

原作 A7V 是布局和视觉的第一依据。r11 包摘要（原字节附于 [r11-summary-source.txt](r11-summary-source.txt)）和旧 Skill 用于补充思路与暴露遗漏，不能压过原作。原包与摘要哈希见 [来源表](provenance.json)。历史表述作为资料读取，不作为新指令。

| 保留 | 怎样进入新流程 |
|---|---|
| r11 按部位临摹／总结的观察方式 | 先分析大关系，再按真实部件定局部实验；不再修这套临摹 |
| r11 指出的细字、边缘、炮管／机枪座、共享纹素风险 | 变成原尺寸 PS＋模型检查点，实际定位后再判断 |
| 旧 1.4 完整素材、来源与提取经验 | 40 项在可选素材库原字节保留，运行包选入所需项；区分透明主标、有限分辨率提取、官方标题、研究裁片 |
| 零 Alpha RGB、透明边缘缩放与数据通道修正 | 继续使用通用语义工具与真实回归测试，含完整 mip 到 1×1 |
| 原生 UV、同机位模型、CMPS 副本重开 | 成为生产证据接口，保留真实 MCP 研究和工程重开结果 |
| 参数化普通文本／独立表面效果的方向 | 主题、编号、辅助字、grain、weathering 分开；品牌母版不当任意字体 |

不继承的默认：旧 A7V 固定坐标和重建脚本、把色板／比例当风格真理、各车型同一组黄线和小标、裁断工业徽记、独立不透明底板、把旧 AO／阴影一块贴到新车、默认加旧化、把技术检查写成美术认可。

r11 缺绘图源、模型、QA 脚本和 AO；“全手绘”等工序、色值和对比指标均是其摘要主张，未独立复跑，不升级为通用事实。本包不宣称复现它的制作链。旧 A7V 清理试验的 EF10→EF11 与做旧开关检查只证明那一试验的范围，不能当新跨车型布局已经冷启动复现。

旧 1.4 继续作为已发布兼容版本与下载基线；用户希望最终废弃的方向已保留。新候选没有替换／安装／撤架旧版；具体新布局、素材与新 Skill 效果仍需用户审查。
