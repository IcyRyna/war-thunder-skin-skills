# 贴图、材质与交付契约

| alpha_semantics | 含义 | 缩放／mip |
|---|---|---|
| fixed_rgb | 固定替换颜色，零 A 下 RGB 仍有效 | 声明色域的 RGB 滤波，A 独立；禁止用 A 预乘 RGB |
| opacity | 实际透明／裁切覆盖色 | 线性光预乘覆盖滤波，恢复 straight RGBA |
| packed_data | N 等打包数据 | 四通道独立线性处理，A 不是透明度 |
| scalar_data | AO 等数值 | 分量独立、linear、不作颜色 gamma |

manifest 每项填写 `file, role, alpha_semantics, color_space`；color 可选 fixed_rgb／opacity，normal 用 packed_data，ao 用 scalar_data，数据必须 linear。预览绑定能显式覆盖本车默认；新增材质必须确认，不能给全车静默套同一 Alpha 策略。

新车保留自己的机械基底，颜色、结构、材料和表面效果分层。不把 A7V 裁片中的孔口、螺钉、AO、污渍转到另一车型；作者材料与原厂材料不是一回事，native 接口名称不证明原厂来源。对 N 通道的法线／粗糙度／金属度约定须和实际 shader、资源及预览实现核对，不把 N 当普通紫色法线或任意 RGB 图。颜色迁移成功不证明法线切线方向正确，跨旋转／镜像岛须单独处理。

默认 weathering none：去旧要分别检查 C 残影与 N／材料影响；微颗粒另设开关，关闭不能留下对应材质改动。保留焊缝和结构不代表必须保留划痕，保留作者 N/AO 也不证明所有原厂机械细节未改。未完成分类的材料保持范围说明，不整图替换掩盖差异。

跨板和 UV 边界看实际采样：共用 UV 可能同时影响多处，退化三角仍会采样纹素，扩色不能污染相邻已用岛。旧跨车型重投影的 AO 漏写、邻岛污染等问题没有在本包解决，也没有把旧工具装作本包能力。

模型与纹理检查按[Blender ↔ PS/Composa对照](model-uv-cross-check.md)关联同一构件、材质、UV岛和资源身份；共享UV须检查其他使用者。最终DDS读回后重载模型，核对实际文件哈希、朝向、边界和遮挡；两边单独通过不能替代对应关系的确认。

DDS 检查 BLK 引用、资源数量、尺寸、通道、头和完整 mip 到 1×1，最终 DDS 再读回。RGBA8 精确基线和 BC3 有损候选分开记录；生成 mip 不等于小字在各距离仍清楚。固定色零 Alpha、真正透明边缘、N/AO 的独立数据通道分别回归。本轮保留的技术测试不等于新整车已经视觉／游戏通过。
