# 透明素材与编辑

[目录](../assets/catalog.json)逐项给出文件、用途、来源类别、哈希、画布与有效 Alpha 边界。`identity/` 放完整徽记；`components/` 放路径、几何、标签与纹样。所有 PNG 都是 RGBA，SVG 无全画布底板；模块内部的实色块是有意的图形，透明外部不代表模块内部必须处处镂空。

## 三种素材身份

1. `original-reference`：保留原字节的 400×400 英文工业透明原件，有效墨迹只有 122×122。小尺寸使用前确认清晰度，大尺寸换已标明来源的向量，不把插值放大当细节恢复。
2. `community-vector`：Yue-plus/endfield_icons 的社区工业 SVG 与黑／白完整组合，保留 MIT LICENSE 和来源。它们可缩放，但不冒充 A7V 作者母版或官方指定字形。
3. `project-editable-component`：项目已有可编辑图形，经本轮筛选保留。路径／符号可拆改；标签文字须替换车型与编号。它们是制作起点，不是已通过新车视觉验证的预制答案。

主徽记统一缩放，不裁、不拉伸、不拆字。按有效墨迹定位，但保留透明画布原件。整张图像的 Alpha 与 RGB 原样保存，避免黑边／白边；背景棋盘是预览，不写入 PNG。可用 `python -B scripts/asset_pack.py check` 核对实际透明度、哈希和有效尺寸；`sheet --out <会话TEMP>/素材预览.jpg` 生成轻量检查表。

SVG 中设备字段仍可编辑，PNG 是即用快照。修改文本后在编辑器／SVG 渲染器检查字体、字宽和缺字，再输出透明 PNG；字体未内置，不把系统字体可用性当作跨机器保证。品牌母版不替换成普通无衬线字。

可通过 `place_decal.py` 把透明 PNG 按有效墨迹宽度放到透明画布，输出单独图层与变换回执；它不会自动选择 UV 岛、裁切到车体或证明 3D 可见性。大于原墨迹分辨率时回执会明确提示放大，工具不伪造矢量清晰度。图层不直接当最终固定装甲颜色 DDS。

参考照片／原作 UV 裁片有旧车阴影、孔口、AO 和污迹，不进入生产素材。包里没有整套车型四视、模型和原 DDS；来源图只用于必要的风格观察。
