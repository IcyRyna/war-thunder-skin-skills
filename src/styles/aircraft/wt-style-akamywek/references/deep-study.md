# 第二轮实物研究：构形与分视面布局

本轮从上一轮概述继续做源图分组、构形重建、原生网格反查和受控删减。下面的像素数仅定位本次作者参考，不是新机型的默认尺寸。重建误差描述对已知源轮廓的接近程度，不证明自主设计能力。

## 1. F2A 与 F16 的“嵌套”怎样构成

F2A 主白形可以分解为一个连通的外形和两对内部负形；测量后按中轴对称整理的构形，用14个外轮廓控制点与4个内孔复建。F16 的主红形则是更简单的6点外轮廓、两对侧内孔，加一个独立的中央折形内孔。黑色间隔与中央白色尖形仍是另外的色层。

这两套不能概括为“多画几条V”。设计时需要同时控制：

- 外轮廓的最长肩部和前后收束；
- 中央折返形成的正负形；
- 两对侧内孔的长短与错位；
- 外侧细轮廓伴形的单独起止；
- 主形结束后的小箭组和长细条。

构建方法可以是封闭形状布尔切割，也可以是等价的多多边形组合。**不要把它强制归为“只能切格”或“只能逐条画线”。** 先复建实际正负形，再选工具表示。

源测量后对称整理的两份构形，相对选定源颜色主体的mask IoU分别约为0.981和0.984。它们是已知源重建，不是留出或迁移成绩。F2A实际原生UV上的删减实验仅填掉4个内孔，颜色图改变42,134个像素；保持几何、相机与外轮廓后，俯视有523个输出像素变化、斜视有645个输出像素变化。这个对照支持内孔对层级的作用，不能推出每个新设计都必须有4个内孔。

生产时保持“有主形、有负形、有伴形、有退场”的关系，按目标曲面重新确定控制点、宽度和退出站位。F16 的白底也没有取消嵌套结构，而是重新分配红、黑、白三层的职责。

## 2. Su27：错位底片，不是统一描边

作者原色atlas的一组粉色长条，在选定截面中可见上方白片、粉色主体，以及下方直接回到浅灰背景。原始行采样在x=5450..5550的100像素带内取中位数：白片占y=3762..3782，粉色占y=3783..3841。下方没有等厚白边。

可用一块向上／向左错位的白色底形与粉色主形复建这个可见关系；这是等价构建方案，不是已经取得作者图层证明。不要给粉色主体统一扩张一圈白描边，那会改变白边出现的方向和形状。

该长条及相邻青色长条属于具体atlas观察组；未取得Su27原生网格时，不把每条在atlas中横放的区域擅自认成发动机脊或侧面。大范围色场、细白底片、局部短斜杠的关系可以学习，具体物理表面要再核对。

## 3. F15：重复序列和渐变扇形是两件事

原作一组箭头明确是每排6个单元，两排共12个。在本次观察窗中，单元包围盒约307–310像素宽、259–264像素高，横向节距约243–246像素。包围盒在横向有重叠，但实际多边形之间仍有空隙，不能用bbox相交判定图形粘连。

各单元几何相近，颜色按蓝→紫→灰紫→棕金→金的次序变化。分成“蓝色mask”和“金色mask”会漏掉中间的低饱和单元，不能据此把6个箭头读成两组残片。

另一组尾面扇形是单块形状内部的连续色带。选定扇形的一个源像素横向采样带，RGB线性近似的均方根误差约2.79个8位通道值；这个局部拟合支持按形状内部ramp处理，不能据此给全机套同一渐变。先确定大三角／折形边界，再把渐变裁在其中，文字与细轮廓另成一层。

因此，重复单元本身不是缺点。采用重复时明确它的承载区域、组数、节奏、色序与终点；采用扇形渐变时明确它是一个形状的填充，避免把色带阈值边界当几何边界。

## 4. 阵风：鸭翼是完整的小构图

两处鸭翼观察窗中，都有红色三角主体、折转白色主体、深底间隔和短字标。红形与白形不等长，白形也不是红形的等距外扩轮廓。它们在本片上收尖，靠色序和方向呼应机身，而不是把主翼人物接过去。

atlas窗口A/B的图形关系已观察，但尚不能在没有原生网格的情况下把A/B直接命名为“左／右”或“上／下”。旋转的字样只是atlas排布；落到目标鸭翼时重新确认实体方向、共享与镜像关系。

活动面的研究仍需要中立／代表偏转状态。当前原帖与atlas支持静态设计关系，不能提供全行程遮挡结论。制作J10C、台风或鹰狮时，鸭翼自己的尺寸、轴向和遮挡必须来自目标机型。

## 5. 人物实例必须先分视面，再谈接续

上一轮曾把几组相邻的角色图块笼统写成“跨控制面接续”。本轮原生网格反查纠正了这个说法：

| 具体观察 | 原生几何结果 | 执行含义 |
|---|---|---|
| F2A atlas(575,1975)与(6230,2270)附近 | 同为wing_l，但法向分别朝上、朝下 | 是上下两个印刷实例，不能拼成同一幅跨面立绘 |
| F2A atlas(1980,1555)附近 | wing_r下表面 | 先建立下表面布局，再比较与上表面的呼应 |
| F16 atlas(4260,470)与(4270,1290)附近的两张脸 | 同为elevator1，分别是上、下表面 | 是同一片平尾的两面，不是相邻角色的身体续片 |
| F2A两处尾面人物 | tail节点的不同侧向表面 | 字标和人物朝向需逐侧验证 |

这些结论来自归档原生几何、源颜色图、按材质筛选的三角形重心坐标反查，并与原生UV俯仰视布局核对。它们不是当前游戏版本的兼容认证。

反查时先固定纹理对应的材质。F2A多个材质都使用0–1 UV范围，混合查询会让同一个像素“命中”座椅、玻璃和机翼等不同部件，形成假的共享关系。只有在同一个纹理资源／材质域内，才能进一步讨论真实共享与镜像。

每幅人物至少登记：实际节点、上／下／内／外表面、阅读方向、姿态、头饰／主手势、文字和邻近几何的关系。确认两个碎片确属同一实例、跨真实接缝相邻后，才讨论接续。Su27、F15、阵风本轮仍以作者atlas与原帖相互核对，尚未取得的网格绑定不按F2A／F16补写。

- **F2A：** 上表面两翼不同姿态；下表面是另外的可读实例。机背主白形负责中轴，人物不需要进入它才能建立整机关系。
- **F16惠惠：** 主翼上下面选择不同的姿态和图文密度；一片平尾的两面可安排人物，另一片以几何呼应。先核对真实节点，不依据俯仰截图的屏幕左右判断物理左右。
- **Su27爱音：** 来源俯视中的大主像、较小副像、吉他与斜标题共同占据宽翼身区域；不能把下表面空白或另一面小图自动补成同一套人物。
- **F15黍：** 宽翼面的人物／长衣装，与较安静的机背长条、尾面独立姿态分工；渐变细节和重复箭头属于不同的图元语言。
- **阵风让·巴尔：** 主翼人物、尾面人物和鸭翼标识各有独立视面职责；鸭翼色形完整收尾，不承担主翼关键动作的跨面接续。

需要检验新创作时，应使用新人物与已核实的目标profile，实际生成分层稿并在原生UV和模型上检查。上述源重建、局部删减和布局观察不能冒充这一步，也不能代替用户美术评价。


## 7. 实际换图练习暴露的布局失败

本轮另用官方透明立绘，在F16已知原生几何上自运行新姿态布局：A把人物放得过前，头／帽／手大面积落出承载面；B仅后移就保住声明关键区域，却仍有难看的腿部裁切和偏小人物。C改用明确的上半身职责和相向旋转，仍发生左侧关键点裁切；D/E的关键区域和实际导出alpha均保留，但整体构图没有被标成完成。

这支持以下制作判断：先看源姿态的长宽、帽子／伸手的横向代价和实际承载区，不强塞整身站姿；需要胸像或上半身时明确改变视觉职责，并从完整源图的同一关键集合检查保留。**源关键点全保留只是工程条件，还要看人物大小、整翼重量、身体裁切、文字和留白。** 大片空场不能靠增加零碎标记补救，素材不合适时应重新选姿态。

这只是同一已知机型上的自运行换图练习，没有完成新题材或陌生机型验证，不能当作跨任务稳定性。官方PNG属于研究输入，未随Skill内置；原图、设计稿、失败和输出哈希在单独研究包中。
