# 从机体到构图

## 先画视觉职责图

先按[发动机类别与气动布局分支](airframe-families.md)建立骨架。常规尾翼单发中轴型、单发鸭式三角翼、双发宽融合／双脊／双侧走廊型分别设计主线路径、人物承载和字标通道，再画职责图。

把目标机体分成承载人物的连续大面、带动视线的长轴、辅助识别面和安静区。这是设计职责，不是固定的 UV 岛名。角色动作可以跨相邻曲面，但脸、关键手势不能未经验证跨过断裂、深槽、喷口或活动关节。

先以很小的预览确认三种重量：人物的脸和动作、主色场与主线、字标和细节。关掉装饰细节后构图仍须成立。若一开始就靠小字、蜂窝、重复箭头撑满机体，应先重画大关系。

「人物优先」不表示主线永远最细。F2A 的白色中轴尖束本身很醒目，但在双翼人物之间留有独立的深色带；F16 惠惠在浅色脊背上用红黑嵌套尖束，把双翼人物放在暖色场；Su27 爱音用连续浅色与青色边界组织宽翼身；F15 黍把较安静的双脊与复杂翼面分开。共性是**分工和间隔**，不是同一个配色比例。

## 决策顺序

1. 记录发动机类别、常规尾翼／鸭式气动布局及具体分支，再指出前机身、主翼根、尾面及发动机分离区。常规尾翼单发组织主要中轴；单发鸭式把前鸭翼、翼根过渡和后主翼一起组织；双发处理宽翼身／两侧纵向体量与中央区，再确定转向、分流和退场。
2. 摆入不同动作的人物实例。先检查头部、颈肩、手与道具连接，再看两侧视觉重量；允许姿态和面积不对称。
3. 给字标预留可读走廊。字标可以沿机身、翼缘或尾面，但必须在目标视图中正确朝向。不能因俯视排版好看，就让侧视机身字倒置。
4. 画主色场与一组主线。判断它是收拢、展开、绕开人物还是强调机械体量。伴线和短节奏标记只在需要加强这个方向时增加。
5. 最后加局部图案和细字。图案受主色场约束，接近脸、重要文字或狭窄接缝时退让。不要将四套参考的所有元素累加到一架飞机。

## 不把参考缺陷变成规范

F15 黍某些浅色头发与浅底接近，且翼面角色和附属图形较密；这支持「需要局部对比检查」，不支持人物必须淡化。Su27 主人物跨宽翼身区域，从俯视能读到整套动作，但不能因此认为每个侧卫模型都能跨中央区印脸。F16 的参考姿态按翼面作了裁切；本次人物若有另一种关键动作，应重新安排，不把参考裁切线硬套过去。

用户选择一套参考作为学习对象，只认可其入选。不能把它记成已认可整套作品、所有部位或新 Skill 的发布。

## 重新布局的触发条件

如果脸／关键道具落到机体断裂处，先旋转、平移或换姿态；局部裁切仍不能保持动作时换承载面。若主线必须穿过脸才保持「原版」形状，修改主线的分叉或终点。若旧文字和新角色争夺同一安静区，先确定 brief 中的主次，不盲目缩小两者。

发动机类别是必须落实的布局分支。实际连续面积、肩部宽度、机背高度、鸭翼与垂尾关系用于在类别内部细分和适配，不能成为两类共用一套骨架的理由。没有测量依据，不给全机统一的线宽、人物面积百分比或空白比例。
