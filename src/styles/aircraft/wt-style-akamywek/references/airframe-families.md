# 先区分单发与双发，再细分机体布局

单发与双发使用不同的构图起点。先确认发动机类别，再在该类别内按真实机体选择子分支；实际几何用于落实和细分这项区别，不能把单发／双发差异弱化成可忽略的信息。这些参考分支还需目标机型自己的profile、原生UV与活动状态验证。

## 必须先选的布局分支

| 发动机类别与分支 | 线条／色场骨架 | 人物与字标职责 | 必须排除的错误 |
|---|---|---|---|
| 单发＋常规尾翼 `single-axis`：F2A、F16 | 单一主要机背轴，嵌套主形与负形沿纵向收拢；后段围绕单一发动机体量退出 | 双翼人物分别展开，机背与长字区分隔两翼焦点 | 把全翼人物缩小来迁就中轴；把此骨架原样移给双发或鸭式机体 |
| 单发＋鸭翼 `single-canard-delta`：J10C类（整机方法候选） | 单一纵向导向，加前鸭翼短节奏、翼根过渡和后三角翼展开；主翼与鸭翼各有独立终点 | 大人物使用已验证的主翼连续区，按后掠斜边和姿态安排身体／衣摆，字标分到机背通道和人物余下空区；先核对鸭翼遮挡 | 只给F16稿加两块鸭翼装饰；虚构后置平尾人物区；套用阵风双发整机布局 |
| 双发 `twin-blended`：Su27 | 宽翼身和外肩色场向两翼展开，中央连续大面可参与画面，横向联系与纵向机体同时设计 | 主像／副像分出重量，手势和道具可利用已验证的连续翼根；标题参与宽画面 | 强塞F2A／F16窄中轴、机械切开连续主人物、强求两翼相同大小 |
| 双发 `twin-spines`：F15 | 分别建立左右纵向体量、台面与通道，处理中央沟槽，后部按两侧承载区收尾 | 翼面人物和长衣装分别适配，文字／留白区隔开复杂翼面；尾面独立设计 | 把两个机背体量压成一条窄脊，用一整个大V代替双路组织 |
| 双发 `twin-canard-lanes`：阵风 | 白色中央场与两侧黑色长字走廊共同组织三角翼，鸭翼短形独立收尾 | 大人物沿各自翼面对角线展开，两侧通道分隔人物与中心 | 因有中央尖形就改套单发骨架，或把鸭翼连接成主翼人物续片 |

上述分支决定完整构图，不只决定画几条线。单发、双发可以共享尖端、负形、伴形等局部语言；主形位置、宽度变化、分流、人物尺度关系和文字通道必须按各自布局重新建立。

发动机类别与常规尾翼／鸭式气动布局共同确定整机分支。鸭翼会改变主翼前方的节奏、可读区域和遮挡，必须在摆人物时一起处理；鸭翼表面上的短图形再独立适配。阵风到J10C的既有试作只验证局部红白复合形，没有证明两架飞机可以共用整机布局。

开始画之前记录：发动机类别 → 气动布局 → 具体分支 → 主线路径 → 人物承载区 → 字标与留白通道。双发稿如果只是把单发尖束拉宽再放两个人物，或单发鸭式稿仍沿用F2A／F16的主翼—后平尾分配，判为分支未落实，先重排构图。

| 参考分支 | 主路径／安静区 | 立绘的主要承载关系 | 迁移时首先重测 |
|---|---|---|---|
| F2A M4 | 窄机背中轴尖束，后部细带退出；深底隔开双翼 | 左右不同姿态，头部在较宽翼面；单垂尾用另一个识别像 | 翼根与脊背的高度、翼面实际可见面积、尾面镜像 |
| F16 惠惠 | 浅脊背、红黑嵌套尖束、暖红翼场 | 帽沿／手势优先；两翼体量相互平衡，不复制同一姿态 | F16具体改型、背脊附件、翼面与控制面分片 |
| Su27 爱音 | 宽翼身面、青色外肩边界、浅色中央场 | 大主像与较小副像；指向手势／吉他可在宽连续区建立横向关系 | 双脊间实际连续面、垂尾遮挡、左右尾面和侧面共享 |
| F15 黍 | 双台面长轴、中央分隔，前机身留白；尾部双路收束 | 大翼面容纳长发和长衣装，尾面独立识别；中央脊保持可读通道 | 进气道台阶、机背双脊与凹槽、保形油箱和双座改型 |
| 阵风让·巴尔（鸭翼专项） | 白色前机身／中心场，黑色两侧文字走廊；鸭翼独立收尖 | 主翼人物在鸭翼之后，单垂尾另选头肩／上身图 | 鸭翼上下表面、枢轴方向、转动遮挡、海军型差异 |

## 窄中轴单发：F2A 与 F16

先找能容纳主尖束的脊背宽度，确定文字走廊能否独立存在。若机背附件打断原参考的通道，主尖束应在附件前退场或按实际表面分成两侧；不要把附件涂成平面来假装完整。

人物铺到左右翼时，姿态的重心沿翼展展开。脸与帽子的完整性以源图和模型核对；胸像、坐姿和站姿使用不同裁切。平尾或腹面可以延续配色与少量节奏，但本次参考里出现的人物数量不是所有任务必须达到的数量。

F2A 红黑底与 F16 惠惠白红底提供了对照：风格关系可以在底色反转后保留。保留的是嵌套大形、独立伴形、字标走廊和翼面焦点，不是强制 70% 深灰一类无分母比例。

## 单发＋鸭翼：J10C类鸭式三角翼

本分支的整机方法来自单发参考的纵向导向、J10C真实机体与原UV、鸭翼局部迁移的组合研究。没有已获选的Akamywek单发鸭式整机原作作正向范本，也没有完成该分支的整机新作；不能把本节描述为已经复现作者完整J10C布局。

1. **线条：** 以一条主要机背轴组织前后导向，进入宽三角翼后按翼根、肩部和翼缘展开辅助路径，给人物与字标保留可读区。前鸭翼采用独立短尖形／伴形，单独起止；不要求与主翼在偏转时连成一条线。
2. **人物：** 将脸和关键动作放在实际连续的主翼可读区，再按三角翼后掠和姿态安排头发、身体、衣摆与道具。不能把F16的人物坐标、缩放和裁切搬过来，也不能把阵风双发的中央场宽度与双侧通道原样压窄。
3. **前中后节奏：** 前部鸭翼短形负责呼应，中部翼根和字标承担过渡，后部主翼承担大人物场；三个区域共同构图。J10C没有F2A／F16那样的后置水平尾翼，不能继承其后平尾人物／扇形区。检查实际部件位置，不能因为两机都有elevator0／elevator1节点就赋予相同视觉职责。
4. **遮挡与文字：** 在所需俯视和斜视核对鸭翼对翼根图案的遮挡，再决定人物位置；对未验证偏转状态保留未知。长文字优先使用机背／侧面通道和主翼余量，鸭翼小字须经实际尺度和朝向检查。
5. **验证范围：** J10C现有成果是8K鸭翼局部红白复合形、四面采样与模型上下视检查。整机主线、人物比例、字标与游戏活动状态仍需独立实做，不由局部通过推导完成。

## 宽融合双发：Su27

先验证机身、翼根、两发动机脊之间哪些区域实际连续。爱音参考的主人物与吉他跨过较宽的翼身融合区，副人物放在另一翼，构成不同视觉重量。其中央并非必须留成完全空白，也不能照 F2A 画一串窄 V。

朝向机头的长边、翼面外肩色场和尾部粉色短斜杠，各有职责。人物放到前景后，不把主标题、线条和图案全部提高对比争抢同一位置。

参考 atlas 中可见机身长形、翼面三角形、发动机侧面和尾面分开排布，不能用 atlas 上的间距推断物理间距。原包的 `su_27_n.dds` 引用缺文件，本次不建立其材质配方；新的工程以目标机型的完整模板为起点。

## 双脊与台阶双发：F15

分别建立左右脊的长轴和翼面的展开方向。关键人物放在连续翼面，长发／披风可以接近内侧边界，但脸与主要手势不跨深槽或进气台阶。白色前机身的相对安静和后翼复杂图形要一起设计。

两脊可用相似的色序和长短节奏，但不要把不相同的几何做成假镜像。尾部两组收尖分别对应自己的承载面，双垂尾的内外面也要分别读。某一侧因共享 UV 无法独立印字时，改用无方向符号或一致图案。

黍参考的金紫蓝色渐变、翼面密集素材和浅色发丝是这一套题材的处理，并非 Akamywek 统一色板。新题材应保留双脊与翼面之间的分工，重新检验人物边缘对比。

## 鸭翼：独立活动面 + 有节制的呼应

阵风原图和 atlas 交叉观察显示，鸭翼采用深底、小字标和红白尖形，主翼使用大人物。鸭翼 UV 被独立排在 atlas 的不同位置，方向也不同；不能把「贴图里朝右」直接当作「机上朝后」。

生产步骤：

1. 在目标模型确认左右鸭翼、上下表面、枢轴与中立姿态。用编号／箭头定位图验证朝向和共享关系；不能只根据 atlas 形状认岛。
2. 每片鸭翼先决定独立主色场与一个主要方向。沿其前缘或后掠方向给短尖形，终点留在本片活动面内。以色序、角度或线条粗细呼应主机身。
3. 短字标只有在实际观看尺度和旋转后仍可读时才放；共享／镜像冲突时选无方向图形。避免把关键脸或细长道具放在枢轴／薄边。
4. 主翼人物位置与鸭翼遮挡共同检查。至少查看中立状态和本次可获得的有代表性偏转状态；对无实测的状态明确记录未知，不拿静态原帖冒充全行程验证。
5. 鸭翼、主翼在一个俯视角度似乎相连时，也不要求运动后连成一线。存在刻意的间断是合理的；错误的接缝错位、倒字与人物永久裁切分别处理。

第三轮已将阵风A窗的两组红形分别反查到elevator0上／下表面，B窗两组反查到elevator1下／上表面；不能把一个窗笼统认成一个面。另用本机J10C实际网格做了红白复合形的局部迁移，记录外接框失效、实体角点对应和目标内收过程，见[整机语法](whole-layout-grammar.md)。这只支持该局部开发案例；EF2000、JAS39以及其他J10改型仍需独立profile，不能继承本例的坐标、内收值或控制行程。
