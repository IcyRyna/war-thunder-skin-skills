# 立绘：先保动作，再适配表面

人物布局先服从[单发／双发分支](airframe-families.md)。单发F2A／F16以机背中轴和字标走廊分隔双翼人物；双发Su27可让大主像和动作链利用宽连续翼根，F15则把人物、衣摆与两侧纵向通道分别安排，阵风沿三角翼展开人物并保留黑色双侧走廊。不能只把单发两个人物的位置和大小等比搬到双发，也不能把双发一律压成左右等大的两张图。

单发加鸭翼的J10C类机体另选 `single-canard-delta`：大人物使用后三角翼的已验证连续面，先核对前鸭翼遮挡，再安排脸、关键动作及沿后掠边展开的身体／衣摆。没有可继承的F16后平尾人物区；鸭翼短形与小标识也不能替代主翼人物构图。该分支整机人物布局仍需实际试作，现有局部鸭翼通过不证明人物已适配。

## 从原图建立关键部位

查看未经裁切的原图和 alpha。确定头型／头饰、脸、颈肩、主手势、手握物连接、主要道具及构成姿态的肘膝。按这次 brief 指定必留部分；不是每一张半身图都必须保留不存在的双脚，也不能把缺失的原图部分说成后续裁切造成。

眼睛和嘴可辨只是最低检查。比如惠惠的大帽子、帽沿与手势、M4 的头部与手臂关系、爱音指向观者的手和吉他、黍的长发和服饰动作，决定了实例旋转和承载方向。不要用所有人物统一的「脸在翼根、脚到翼尖」公式。

## 每个实例单独设计

现有姿态不能在所需尺度保住脸、头饰和动作时，按[按布局生成素材](generated-assets.md)先明确目标面、锚点、身体方向与文字余量，再按任务需要调用生图模型生成／编辑配套姿态；不要仅靠继续缩小或非等比拉伸解决。生成后仍逐一检查原图、真实Alpha、UV落位和模型可读性。查看与保存流程见[编辑器／Blender](editor-blender-workflow.md)。

先在一个连续承载区安排源人物轮廓，再决定是否延展到可验证的相邻面。左翼坐姿和右翼站姿可以使用不同缩放；看的是头部可读性、动作方向、重心和与字标的关系，不是两个 bounding box 一样大。

角色原图看向或动作指向内部时，可帮助把视线带回机身；这是条件判断，不要求所有角色必须朝中间。为了朝向而镜像图像前，检查源图里的文字、徽章、持械手和衣服结构。优先选择适合的一张源图，不能默默镜像有文字的素材。

翼面要保留向外展开的空间。F2A 左右不同动作把脸放在较宽的翼根附近，身体沿翼展展开；F16 惠惠的帽子与手势需要比普通头部更多上方空间。大武器、长发可以在经过验证的宽融合区跨到机身，但人物的脸或握持关系不要跨两发动机之间的深沟／缺面。

## 尾面与鸭翼

垂尾是独立识别面。根据实际高度和后掠选择完整胸像、头肩或能保住主动作的姿态，不按整个人物等比例压入。检查内外侧和镜像 UV；双垂尾可以只让可读外侧承担主体，内侧使用线条或符号，不机械放四个相同头像。

鸭翼通常更适合短色块、方向条或小标识。是否放人物取决于具体面、姿态和用户要求；不要为了增加角色数量把小脸塞进活动面。鸭翼与主翼靠得近时，要看作者参考或目标模型的斜视与转动状态，确认它对主翼人物的实际遮挡。单个角度挡住部分图像不自动判整套失败，但源裁切、实际缺纹素或必需视图中关键动作永久不可见必须处理。

## 必须分辨的四种损失

| 情况 | 怎样判断 | 修法 |
|---|---|---|
| 原素材本来缺失 | 回看完整源图 | 换原素材或明确半身职责，不虚构补全 |
| 设计／UV 裁切 | 源关键遮罩经同一变换落到输出外或 carrier 外 | 调整实例变换、承载面或真实裁切，重新导出 |
| 几何遮挡 | 输出层确有图形，但当前视角被另一部件挡住 | 核对其他必需视图和活动状态；改位或接受明确的局部取舍 |
| 材质／显示吞边 | 纹理中有形状，指定光照下脸／白衣融合 | 调整局部对比或经验证的材质；不要直接抹平所有法线 |

## 检查原图到实际输出

保存源图 SHA-256、关键遮罩、源到目标变换、每个人物单独的输出 RGBA 层以及目标 carrier。用 `layout_audit.py` 逐源像素检查关键部位，不把裁切后的 alpha 再当作「完整原图」建立遮罩。

检查器只覆盖 2D 仿射实例。真实曲面投射、非线性变形或拼岛必须使用实际映射／采样证据，不能为了运行检查器伪造一个仿射矩阵。即使关键像素全部落在 carrier 内，仍要检查实际模型的投射伸缩、朝向、遮挡和整体构图。

最后在整机尺度确认人物仍可辨、文字不穿脸、线条没有与眼线／发丝合成新轮廓。再看原尺寸局部。不要用自动保留率平均掉一个被裁去的关键手指、帽尖或握持点。

还需检查人物之上的字标、清理层及其他叠层。H试作的人物独立alpha完整，但右侧标题覆盖154个固定保护源像素；因此应沿实际源到UV映射检查最终叠层，而不能停在人物单层。可取消次要标题、改字量或移位，再用同一保护集合复核。具体上下表面分工、连续肩部和身体下缘的实际失败见[整机语法](whole-layout-grammar.md)。


## 先分类实例，后判断接续

原生反查已确认：F2A几处相邻人物分别落在机翼上／下表面；F16两张相邻平尾人物分别落在同一个elevator1节点的上／下表面。不能先把atlas里相邻的手、头或衣服拼成一张图，再用它解释机上布局。

先按真实纹理资源和材质筛选三角形，然后标记节点、法向和阅读方向。不同材质共用0–1数值范围不等于共用纹素。只有同一印刷实例跨真实相邻接缝时，才核对身体／衣服的延续。检查少数关键点只证明那些点的映射，不证明整个人物轮廓都安全。证据及限定见[第二轮实物研究](deep-study.md)。
