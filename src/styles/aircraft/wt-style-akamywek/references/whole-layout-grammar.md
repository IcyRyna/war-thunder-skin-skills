# 从整机关系设计线条与立绘

选图、画主线前阅读本页。局部配方回答怎么画，本页回答为什么放在那里。第三轮已用本机真实LOD0和原生UV核对Su27、F15、阵风与F16A Block 10，F2A沿用已核验的归档几何。选点见[实物映射数据](whole-layout-measurements.json)。这些都是开发样本，不是未见评测。

**单发与双发必须先分开建立布局。** F2A／F16的单发中轴型、Su27的双发宽融合型、F15的双发双脊型、阵风的双发双侧走廊型分别处理线条、立绘与字标。按[分支表](airframe-families.md)选定后再使用本页；不能用下面的共性取消两类区别，鸭翼局部迁移也不能替代整机分支选择。

单发加鸭翼另列 `single-canard-delta`，在整机阶段共同设计前鸭翼短节奏、翼根过渡和后主翼人物场。它不能简化成在F16稿上添加鸭翼装饰。J10C局部迁移提供了几何与短形证据；当前五套正向作者原作没有覆盖单发鸭式整机，此分支的完整线条和立绘方案仍待实做验证，见[具体方法](airframe-families.md)。

## 五个案例的整体分工

| 案例 | 构图骨架与人物关系 | 不应错误迁移的做法 |
|---|---|---|
| F2A M4 | 深色纵向机身隔开两翼，红鼻和白色连通尖束收拢视线；不同动作、衣装与斜向底场组成两翼，尾部改用细长节奏 | 不把连通主形拆成若干等宽描边；不强制两个角色的像素框等大 |
| F16 惠惠 | 浅色字标走廊、红黑白嵌套中轴与暖红翼场形成三层；帽沿靠近后掠边，身体落到翼后缘，外侧斜标题填人物余下的位置 | 不将完整站姿缩成小贴纸；不先裁成短胸像再留一条无意义的下方空隙 |
| Su27 爱音 | 青色边界沿外肩展开，主像大于副像，指向手与吉他建立横向联系；所选主像脸点实际在fuse连续翼根面，副像在wing_r | 不要求所有脸都在相同翼展位置；不因双发就切开中央大画面。腹面以青色翼场、星标和粉色平尾为主，不重复顶部人物 |
| F15 黍 | 白色前机身与双纵向通道隔开复杂翼面；左翼是人物加金蓝大背景，右翼由长人物与衣摆展开，后平尾用渐变扇形收尾 | 不为脸等高而压缩长衣装。腹面仍有翼面人物，中央用两排六单元箭头；不能套Su27无人物腹面 |
| 阵风让·巴尔 | 白色前机身尖场、黑色两侧文字走廊与分段白线；坐姿、躺姿沿不同对角线展开，头发、腿与道具占据宽翼面；鸭翼承担短形和小标识 | 不把鸭翼接入主翼大图，不从atlas方向推断实例上下。A窗含elevator0上下两面，B窗含elevator1上下两面 |

共性是职责、方向和间隔；人物数量、脸的位置、色板和腹面是否放人物都随案例变化。

## 姿态先与表面配对

同时查看完整源图和真实承载面，标出帽／头型、脸、表达动作的手及颈肩连接，再看头发、披风、衣摆怎样占余下形状。帽尖、伸手和披风的相对位置随素材改变。把人物旋到翼后掠角，并不保证姿态可用；第三轮的较大正反旋转搜索也保留了失败。

先用脸和动作在整机尺度的分量决定大致大小，再用连续表面、裁切和选图解决边界。不要在把全身塞入翼面后，才发现角色已过小。不同姿态不使用统一裁切模板。

有意的身体下缘应落到翼后缘或明确画面边界。G先把人物裁成短胸像，产生悬在翼后缘上方的截口；H保持原关键区域与变换，向下延展原源图，让非关键身体由实际翼缘结束。不能通过改保护遮罩抹去失败。

## 连续承载区不等于一个节点

F16翼根存在可印刷的fuse肩部。仅选wing/slat/flaperon会排除真实可用区；扩大到整个fuse又会盖掉字标走廊。人物承载区、背景清理区和保留文字区应分别映射到当前profile，检查材质、法向与接缝。

换图需处理原人物覆盖的可见目标面，包含斜肩和缝边。只清理水平翼面会留下原帽子或衣服边。用原包作背景的研究试作必须指出保留区域，不能冒充整机新作。

## 线条按构形组织

F2A和F16的外轮廓与负形共同设计。Su27肩部色场包围连续大画面，局部白底片有方向地错开粉条。F15平尾扇形分为粗黑结构、渐变主面、细色尖形和独立字区。阵风鸭翼则是三点红形与转折白四边形，拥有独立起止点与暗缝。

鸭翼迁移先认前根角、外侧前角与外侧后角，再核对折边、曲率与UV。阵风→J10C按物理外接框映射仍裁切；用对应实体角点后，对整组轻微内收才通过本例四面边界采样。0.95是本次目标适配值，不是通用风格比例。实际设计见[鸭翼构形例](../examples/canard-compound/design-j10c.json)，构造与身份见[说明](../examples/canard-compound/reference.md)。

## 标题服从真实余量

人物换了，原来的两行标题未必还能放下。允许一翼保留机型两行，另一翼只保留人物名，不为两个文字框一致而压住披风或手指。

检查完整合成顺序。人物层alpha正常，不证明最后仍可见。H右侧标题覆盖了154个原先固定的保护源像素；I缩成单行并改位后，两个固定保护集合在实际8K层与上覆标题中均保留；J另清理旧字标残片。检查数值只回答声明区域与实际图层的关系，不给整套审美打分。

## 目前的证据范围

已完成五套原作的具体分析、若干源构形重建、实际模型选点和视面反查，以及J10C鸭翼局部结构的开发迁移。F16换图已分层烘焙、修正并检查，但人物姿态和整机分量仍与参考有差距。独立重复、完整新涂装、用户美术认可和游戏动画验证没有完成，不能将这些局部结果称为全面精通。
