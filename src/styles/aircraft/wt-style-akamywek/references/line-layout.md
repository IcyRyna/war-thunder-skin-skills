# 线条布局：场、主线、伴线、终点

先确认[发动机类别与气动布局分支](airframe-families.md)。常规尾翼单发以主要中轴组织收拢与退出；单发鸭式三角翼同时安排中轴、前鸭翼短形和后主翼展开；双发分别组织宽翼身外肩、双脊通道或中央场加两侧走廊。共享局部图元时，必须重新确定职责、进入位置、分流和终点。

## 观察线条时记录关系

对一组线条，记录承载面、进入方向、转折／分流位置、最宽段、收尖位置、退出方向、与相邻线的负形，以及它为哪个人物或文字区域让路。把外轮廓和内部暗缝都画出来；仅量中心线会丢掉嵌套楔形的性格。

区分四种形态：

- **长主形：** 决定机背或侧面的流向，可以是实体楔形或色场的边界。
- **伴形：** 与主形有方向关系，但拥有自己的长度、起点与终点；不是给主形加等距描边。
- **局部转折：** 在翼根、肩部或尾根改变宽度或方向，不能突然为躲人物折出无来由的角。
- **节奏标记：** 短斜杠、轮廓箭头、框线或小段条带。它们在长留白中提供尺度，不沿整条机身无休止重复。

## 单发布局：F2A / F16 的中轴分支

F2A M4 的红色鼻部场在座舱后变窄，白色大尖束沿两侧收拢，深色间隔使嵌套白形仍各自可读。大形后方的红色短箭组与长细带不是一条线的等比例延长：它们在不同纵向位置退出。机侧保留长文字和低密度功能标记。

F16 惠惠保留类似的纵向导向，但底色反转为浅色，主形改成红色并嵌入黑色间隔；双翼暖红场中的人物不需要与机背一起变浅。应迁移「主形—间隔—伴形—休止」关系，而不是复制 F2A 的红黑白面积。

绘制时优先使用封闭多边形表达宽窄变化和尖端。纯 `stroke` 适合真正等宽的细带；不能用圆角端帽代替尖束。伴线在狭窄位置提前退场，可以比主线更短。是否对称由具体机背及 brief 决定，左右人物不因此镜像复制。

主形、负形、伴形和字标保留可编辑的确定性构造。配套有机纹饰可按[素材流程](generated-assets.md)调用生图，但应作为独立背景层，按人物／文字可读区控制强度和位置；不能让模型同时猜测主线、机械结构和原生UV。完成后在[编辑器与Blender](editor-blender-workflow.md)核对线框、实际表面、终点和叠层。

## 单发＋鸭翼：中轴、前鸭翼、后三角翼

J10C类目标使用独立的 `single-canard-delta` 分支：单一机背主导向与宽主翼的展开同时设计，前鸭翼以短尖形和伴形呼应，三者各有独立终点。不能把F16的机背—主翼—后平尾图形分配搬过来，也不能只压窄阵风整机设计。局部红白构形已有实做；本分支完整主线路径仍属待验证设计，详细步骤和边界见[机体分支](airframe-families.md)。

## 双发布局：宽翼身与双脊分别组织

**Su27 爱音：** 边界主要沿机身外肩向主翼展开，中央宽浅色面可以容纳跨翼根的画面和斜向标题。主人物动作的横向联系比一条强中轴更重要。不要给它强塞 F2A 的多重窄尖束。

**F15 黍：** 两个进气／机背台面提供分开的纵向通道，细框、长字与短标记保持可读；后机身分成两条收尾节奏，翼面复杂图形由较浅的机背和中央沟槽分开。不要把两条发动机脊压成一个大 V，也不要把两脊之间真实不可印或不可见的位置当成平面。

阵风属于双发加鸭翼：白色中央尖场与黑色两侧文字走廊共同承担主布局，鸭翼再用独立短形呼应。中央有尖形并不改变其双发分支。

双发内部按真实机体细分，Su27连续翼身、F15双脊和阵风双侧走廊各有组织方式。不能把「双发不必全部分成两条线」误读成「可以继续套单发窄中轴模板」。

## 线宽、间隔与接缝

- 线宽在实际表面／局部设计坐标中规定，再映射到 UV。记录单位；不同 UV 岛的相同像素宽度未必对应相同实体宽度。
- 暗缝与留白是构图对象。缩小到用户实际观看尺度后，它们仍应把相邻形状分开；近景成立而整机糊成一块时先减少并列数量或增加间隔。
- 一条连续线跨固定接缝时，先核对两侧表面位置、切向方向和宽度，再在各自 UV 岛绘制。不得按 atlas 中两岛看似相邻就连线。
- 活动面允许有意断开，用方向、色序或节奏呼应。鸭翼不能要求所有角度无缝相接。
- 从真实导出的颜色层检查边缘，不用 SVG 看起来笔直证明 DDS／mip 已通过。

## 反例

把所有尖端收在一个像素点会产生拥挤；伴形等长等宽会变成栅栏；近脸的高对比细线可能穿出假五官；用全翼高密度网点遮住人物会消掉动作；把整套 atlas 当统计分母会混入隐藏面和 UV 空白。分别回到起止关系、人物保护域与真实可见面诊断。


## 深化后的三项纠正

F2A主白形是包含内部负形的连通构形，不能把屏幕上看起来分开的每条白边都当独立stroke。F16主红形的中央内孔、侧内孔与黑白层分工不同，不能靠F2A换色完成。具体构造见[第二轮实物研究](deep-study.md)。

Su27的一组粉条用错位白底片形成单侧白边，不是四周等厚描边。F15则确实使用每排六个重复箭头：这里重复承担局部节奏，蓝到金的色阶跨单元变化；另一组扇形是单块形状内部渐变。这两种渐变和几何结构分别设计。

测量时必须记录轮廓是否被观察窗裁断、是否混入字标／机械件、颜色阈值是否漏掉中间低饱和色。高mask IoU只说明阈值轮廓重建接近，不能证明已选对视觉对象、读懂布局或能独立设计。
