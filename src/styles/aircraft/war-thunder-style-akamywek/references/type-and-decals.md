# 字与标识

## 字体

- 全大写的宽体或方形无衬线（类 Eurostile、Bank Gothic、Microgramma 的气质），粗、细两档。没有授权字体时，用系统里最接近的几何无衬线，加宽字距。
- 作者字体尚未完成准确识别。Windows 的 Bahnschrift（`C:/Windows/Fonts/bahnschrift.ttf`）只是可用的备用字体，不是已核实的作者字体，也不等于已复现作者字形。用它时在 `vector_paint.py` 写 `font` 和 `variation`（`Bold` 做主名、`Light` 做副名），`tracking` 0.05–0.12 给主名、0.2–0.3 给副名。用户要求精确字形时先对照原图核验，不用备用字体冒充已识别字体。
- J-16 同尺度对照中，Bahnschrift 主字显得过于常规且偏窄；本次采用 Orbitron Medium 的宽体方形字形作两肩主字、Bold 作机型标签，Michroma 作较细副字。它是经当前样张核对的替代选择，不是对作者字体身份的确认，也不把整个装饰改成其他科幻风格。字体及 OFL 许可一并放源码，其他机型仍按实际字组宽度和观看尺度核对。
- 中文、日文字要显式指定字体并渲染确认；这个风格的主字默认用拉丁字母拼写。
- Light 只给字高 8 cm 以上的副名；更小的技术字用 Regular 或 Bold，否则在游戏距离里消失。字体选择、字号层级和凑数字的通用纠偏见 [审美纠偏](core/taste-corrections.md#字体)。

## 字组

炭灰区域需要可读的主字与较小副字配对；把所有字都做成同一字重、细小低对比的签名色，会丢掉 F-2A 的第二阅读层。按[炭灰部位职责](mosaic-and-charcoal-detail.md#炭灰区按组补信息保持大面安静)检查其与图标、短下划线和短标记的组合；不要仅靠重复机型名凑密度。

每组字是固定的"锁组"，不要单独散放：

| 锁组 | 结构 | 位置 |
| --- | --- | --- |
| 机型名 | 大号粗体（如"F-2A"），左侧竖排小字制造商名，下方一条虚线下划线 | 垂尾外侧、侧面 |
| 角色名 | 小号细体副名在上（阵营或作品），大号粗体主名在下，中间一条与字同宽的细线 | 主翼对角线、机背负形里 |
| 双色词 | 两个词上下叠放，一个白、一个签名色（如"VIPER / ZERO"） | 垂尾、翼尖深色带 |
| 技术字 | "JET INTAKE →"、"ANTI-RAIN"、"CARRIER-BASED"、"GUARD"等，小号，配箭头或细框 | 侧面、进气道、口盖附近 |

- 字高：机型名约为所在面短边的 1/4–1/3；角色名主名约为主翼弦长的 1/8–1/6；技术字 4–8 cm。
- **安全净距与防逼挤（Clearance）**：任何文字、徽章或贴纸不得顶贴在相邻色带边缘、垂尾前缘方格列边、翼尖外缘拐角或方向舵/襟副翼铰链缝上：
  - 平尾文字居中于平尾内中段宽敞底色区，不向外推入翼尖窄弦区（如 F-15EX 实机反馈右平尾 `F-15EX` 靠外贴近翼尖斜边，内收至 `z≈2.72` 后恢复平衡）。
  - 垂尾外侧徽章须位于前缘序列框后缘与垂尾后缘的中间暗底，下沿高于 `rudder` 铰链缝，左右留出 **≥ 0.12–0.20 m**（或自身宽度的 20%–25%）纯底色边距，不紧贴前缘方格列（"太靠内"）。
  - 同处大号机型标（如垂尾根部 `F-15EX`）上方/下方若净空不足，直接删除附带小字副标，避免垂直方向硬塞逼近。
- 方向：沿机轴或沿所在面的长对角线；同一视图内的字方向一致或互为镜像。左右两侧的字都要从各自的外侧读正：设计稿里左侧通常要 `flip`，先用一张带方向标记的试写确认。
- 位置（J-16 v10 做法）：角色名主副名锁组沿主翼后缘斜放在立绘下方；机背角色名放进深色通道，字头朝外；垂尾外侧的机型名放在根部深色带、角色名缩写放在顶帽；机头侧面放机型名。字只放在 `surface_map.py` 的平整可见区，避开弯折和机械件。
- 不要在左右共用 UV 的部位放字：另一侧会显示同一块像素，字会反。
- 颜色：白为主，签名色只给双色词的一半、细线和小图标。

## 小件

- 飞机剪影的视角按角色区分：F-2A 后机背采用白色侧视剪影，平尾采用签名色俯视剪影；新机型使用自己的对应轮廓，见[后机背细节关系](mosaic-and-charcoal-detail.md#后机背的关系不能只靠元素齐全验收)。
- 徽记：角色阵营或作品标志，放在机背负形或垂尾，配四角折线框（"⌜ ⌟"）而不是完整外框。
- 圆形靶标、带圆点的胶囊框、条码：在侧面排成一行，等距。
- 所有小件聚成 1–2 簇，不撒满全机。

不照搬参考作品里的具体字样、徽记和数字，换成当前角色、作品和机型的内容。无人物涂装不用角色名、阵营或角色徽记填空；保留真实机型、制造商以及适用的技术标注即可。表内技术字是位置示例，必须符合该机型，不能把舰载标识套给陆基机。

## 窄机身的两肩字组

两侧主副字作为锁组放在中轴白组与主翼色场之间的炭灰通道内，按真实机身宽度定位。只看 UV 空白或直接沿用双发机横向坐标，会把单发机文字推到外围。先看整机正常观看尺度，再核对局部边界；主副字之间的间距与粗细层级一起保留。

用户只指出“太靠外围”时，先整体内移对应字组，不同时缩字号、改方向或重排白组。J-10C 两侧各内收 0.28 m 后获认可，数值仅适用于该模型；见 [具体位置及验证](current-approved-j10c.md#两肩文字内收)。


## 侧面如何验字

机鼻朝上的正俯视能验左右位置，不能单独决定字是否从观察者方向读正。对肩字、平尾大字和进气口标记，分别从左舷、右舷外侧看；若字在机顶或平尾，使用该侧的斜俯视，让基线与字头都可辨。逐件记录读到的内容，不能用垂尾和进气口读正代替肩字。若两组仅需旋转，固定锚点、字重、字号和所有非文字层，追踪最终游戏包，不在 atlas 上凭一个 flip 参数验收。F-16C 铜橙试作的首包有两组在俯视未发现的倒字；这是观察方法的例证，不把该机旋转角度用于其他机型。


可用[字向检查器](core/lettering-review.md)对同一图元在指定相机上的真实可见笔画测量基线方向，并记录烘焙覆盖损失。字朝向正确且一端被舱窗遮住时，仍需逐字核对或把受影响一侧移到可见蒙皮。另一侧按其外侧机位独立判断。
