# 各面布局

先按 [基本布局](base-layout.md) 做出不带立绘的涂装，用户认可后再按本篇放立绘。下表里写到人物的格子都是第二阶段的内容；基本布局的两大块、白色焦点和尺寸阶梯在第二阶段保持不变。

## 通用分工（第二阶段）

| 面 | 内容 |
| --- | --- |
| 主翼上表面 | 人物。整个岛几乎被人物填满：每翼 1–2 张不同的图（不同姿态或同角色不同版本），可再加一张放大、低不透明度的回声脸；人物之间用签名色细边、折线或小三角隔开；角色名大字沿翼的长对角线或翼根斜线排；人物身后可放空心大首字母。不用整条前缘宽色带或后缘名字栏把人物框起来 |
| 机背 | 一个主图形（见 [图形库](motifs.md)）＋深色中线通道＋签名色母形；两组字（角色名、阵营名）放在主图形和母形之间的深色负形里。中线有凸起背鳍条时，凸条就是深色通道 |
| 机头 | 饱和签名：签名色马赛克，暗端在机头；浅色签名：白或浅灰大面，边界是新月长弧 |
| 机身侧面 | 文字道：75% 以上是安静底，放机型名、"JET INTAKE →"等技术字、飞机剪影、虚线序列、伴线组和小箭头组 |
| 边条、鸭翼、平尾 | 签名色楔形或小号人物；鸭翼做沿实测前缘的白、签名色尖片箭头加机型名（见 [鸭翼](motifs.md#鸭翼)） |
| 垂尾外侧 | 立绘。每片外侧一张不同的人物图，干净抠图放在深底上：前缘一条签名色窄带、顶端一块深色帽、根部一条深色带（机型名、小字放在帽和根部带上），人物身体被根部带截断。不保留原图背景。第一阶段（基本布局）这里是前缘签名色平行四边形列加描边列（F-2A 式，见 [基本布局](base-layout.md)） |
| 垂尾内侧 | 沿前缘的签名色马赛克楔形（根宽尖窄），内侧签名色伴线，根部半调；不用等宽平行粗带，不用白色长针 |
| 机腹 | 只画在平整区（先看 `surface_map.py`）。不放人物。签名色暗一档大面，被深色 U 形或 V 形负形切入，加白色嵌套 V 腹饰；长细线用签名色 |

不放人物时就是 [基本布局](base-layout.md) 本身，它单独就成立（作者的 F-2A）。

## 按机型

- **双发侧卫类（Su-27/30/33、J-11/16）**：机背宽，用琴键序列或放射长针；两侧垂尾外侧各放一张不同的立绘；尾梁间的中线通道做深色楔形。
- **单发中单翼（F-16、F-2）**：机背窄，用嵌套 V；签名色从机头一直铺到座舱后，被白 V 刺穿；主翼翼根深色楔形、中间签名色、翼尖淡染条纹；平尾签名色包前缘加白带；垂尾前缘平行四边形序列（以上就是 F-2A 的基本布局）。第二阶段主翼或垂尾可换成人物。
- **三角翼（幻影、阵风、鹰狮、J-10）**：主翼面积最大，人物直接放在深底上填满三角翼，两张图沿翼的对角线分开；翼根斜线上放角色名，前缘一带只放 2–3 根尖片组成的箭头，不铺整条色带。机背窄，用签名色面里的白色尖片组（作者的幻影就是这样），伴线用签名色；鸭翼放尖片箭头和机型名。
- **双发双垂尾（F-15、F-14）**：主翼人物；机背两条平行签名色母形夹一条深色通道；垂尾外侧肖像。

## 不要这样做

用户明确否定过、或检查中确认看不见的做法：

| 做法 | 问题 | 改成 |
| --- | --- | --- |
| 垂尾外侧只放线条、色带或机型名（有人物的版本） | 审查记录：该处理需要修订 | 外侧放立绘，线条留给内侧 |
| 两处用同一张立绘，或拿另一侧主图做回声 | 审查记录：该处理需要修订 | 每个位置换一张原图，不够就找新素材 |
| 垂尾内侧三条等宽白-签名色-白粗平行带，其余全空 | 审查记录：该处理需要修订 | 沿前缘渐收的马赛克楔形加签名色伴线 |
| 机腹、机背、垂尾上的白色细长针、平行白条、前缘白细边 | 审查记录：该处理需要修订 | 白色只做有体量的形，集中在主白色图形；长细线用签名色（见 [白色怎么用](motifs.md#白色怎么用)） |
| 保留原机法线、颜色里叠面板线、光滑度 100–130 | 审查记录：该处理需要修订 | 整机一层亮漆（SKILL.md 的“漆面”） |
| 机腹线条压在格栅、舱门、天线上 | 审查记录：该处理需要修订 | 先看 `surface_map.py`，只画平整区 |
| 嵌套 V 的尖点放在凸起背鳍条上（J-10C 莱万汀 v2） | 审查记录：该处理需要修订；凸条侧壁不上色，每个 V 碎成一个小尖加两根斜杠 | 凸条做深色通道，V 拆成左右尖片组、尖端顶到凸条边；看 `surface_map.py` 的 `seam_items` |
| 嵌套 V 画成 18° 的等宽粗臂短 V | 钝，像路标箭头，没有作者的锐利感 | 细长渐尖尖片，6–13°，最宽处约为长度的 10%，最大的 V 里留深色 V，两侧配错开的菱形尖片 |
| 鸭翼整条前缘色带，坐标从别的任务抄 | 审查记录：该处理需要修订 | 按本机鸭翼实测前缘做白、签名色尖片箭头，加机型名 |
| 三角翼前缘宽色带加后缘名字栏，把人物框成卡片 | 和作者幻影比像贴纸卡片 | 人物直接放深底，名字沿翼根斜线，前缘只放尖片箭头 |
| 从原厂贴图描面板线画进颜色（莱万汀 v3） | 审查记录：该处理需要修订“线条粗糙”。描出的线断、斜线成台阶、脏迹被描成歪线、铆钉是散点 | 基本布局不画面板线（F-2A 没有）；用户点名要时，必须和作者阵风在 1:1 下并排看不出差别才交付 |
| 主翼立绘保留官方图的浅色背景，再按翼形渐隐（莱万汀 v3） | 深底上一片灰雾，显脏 | 人物干净抠图，背后直接是深底 |
| 先放立绘，再拿线条去配人物 | 审查记录：该处理需要修订 | 先做 [基本布局](base-layout.md)，认可后再放人物 |
| 机背色带延伸到机身弯折面 | 碎成毛刺 | 朝上图表只收真正朝上的面 |
| 把图形放在座舱玻璃、机身内部或别的面后面 | 看不见（J-16 第一片琴键、两个回声框曾经这样） | 以 `surface_map.py` 的 hidden 区为准，不以命中纹素数判断 |
| 在左右或上下共用 UV 的部位放不同内容 | 一边被另一边覆盖 | 共用区放对称相同的内容，或挪开；J-16 左垂尾内侧有一条和右垂尾外侧共用 |

## 人物处理

- **素材不重复**：主翼、垂尾、回声脸等每个人物位置各用一张不同的原图；左右镜像、同图换裁切、拿另一侧主图做回声都算重复。本地不够就上网找官方立绘、卡面、活动插画（先列出文件名、来源和大小，经用户同意再下载），并记录来源。
- **官方图不够或背景太乱时**：按 [素材与布局](core/assets-and-layout.md#官方图不够时抠图和-gpt-生图) 让 GPT 把背景换成纯灰，或参考官方图生成新姿态（纯灰底），再用 `art_cutout.py` 抠。模型抠图（`person`、`any`）在光效、半透明裙摆上会留下灰雾，不用。
- **三角翼**（J-10C v6）：人物铺满主翼上表面，只留翼尖带（含淡染条纹）。横图的长边顺弦向，约 5 m 宽，上方朝机身。同一张图同时放在主翼和两段升降副翼的图表上，参数相同，所以连续。主翼下表面维持基本布局的签名色马赛克。
- **单垂尾两面**：各放一张不同的图，从头往下取，被根部深色带截断，顶端深色帽，前缘一条签名色窄带，垂尾上不放字（审查记录：该处理需要修订）。
- 人物干净抠图放在深色底上：边缘锐利（8192 上 1–2 px 抗锯齿），不保留原图的浅色背景、光效碎片和远景，不做大片渐隐。身体被翼面边缘或深色带截断的地方直接截断。作者阵风、幻影的人物都是这样，莱万汀 v3 保留背景再渐隐，深底上成了一片灰雾。用 Composa 的 `select_subject` 或 `filter_remove_background` 抠图，在 1:1 下检查发丝边缘。
- 人物可以被翼面上的签名色折线、字和细边压过，但不能被它们穿过脸。
- 两张人物之间的分界做成一条与前缘平行的直线，线上放角色名或一条签名色细带。
- 背景空心大字母（角色名首字母，字高约翼面短边的 1/3，描边 0.03–0.05 m，灰色 30–50%）可以压在人物身后。
