# Akamywek 喷气机涂装

正式 1.3.1，2026-11-18 按 F-15EX 实机反馈、对照图漏项复查与内置字体/净距规则更新。先确认是新作、已有认可版的局部修订，还是复现历史案例。局部修订先冻结其余色场、白组和已选人物；新机按自己的几何与原皮建立分区。本风格归纳自作者公开作品，学习部位关系，不复制作者的字、徽记和作品。网页或海报配色规则不参与机身构形。

## 新作先看哪件作品

用户指名色块布局范本时，以那件具体作品为本次依据。对应机鼻、座舱后的色尖、两侧翼根暗楔、主翼母形和翼尖条带，分别标清相邻颜色之间在哪里接触、何处被炭灰分开。先画大色块及主白形，在近似的正俯与斜俯角度对照参考，再安排字标、小剪影与马赛克。按目标机原生翼面重定落点。用户未指名范本时，先按目标机的翼形和平尾、鸭翼、翼根的位置选择[已认可的具体作品](references/reviewed-works.md)。双发双垂尾（如 F-15C/E/EX 家族）无人物制作直接对照用户认可的 [F-15EX「终末地」定稿](references/f15ex-endfield.md)，核对双发后机背文字与剪影、内翼根炭灰细件、无缝白 V、双垂尾与独立平尾、保形油箱（CFT）及三段式深枪灰钛喷口。

有独立平尾的轻型单发可从 [F-16C Block 50 铜橙终稿](references/f16c-copper.md)看色场、白组与后段的主次。大三角翼无人物可从[歼-10C 青玉金黄无人物](references/current-approved-j10c.md)看宽翼面的分量及活动面接续，再按目标机自己的前缘、翼根和后缘画边界。目标机有作者原包时，从其 BLK 核实对应型号，放回本机观察正俯与斜俯。人物作可以借鉴翼根或肩部关系，无人物大翼仍需要独立构形。

用 `vector_paint.py --proof-width 1536` 从最终尺寸输入先烘一份原生布局。先在整机缩略图上指出最先读到的形、机头色场与左右主翼由哪几块颜色相隔或相接、后机背哪里留暗，再安排字标和剪影。按本机选择[机背主图形](references/motifs.md#机背主图形四选一)或在原生 UV 上画新的母形。用户明确否定整机布局并选定了范本时，先用实物把新版与范本对照。结构方向未定时才用同一实模、机位、光照和占比比较不同草案。比较哪种色场边界、白形和留白在正俯与斜俯缩小后仍成立，把判断落实到某一块可见机体上。选定后再从左右外侧读本侧字标，按[字向与实际可见笔画](references/core/lettering-review.md)查倒置、镜像、遮挡和零写入。技术通过只记录为技术结果。

## 选方案

2026-11-12 的目录标注指名认可七件**具体作品**：[先按作品查正例与适用范围](references/reviewed-works.md)。同名机体、角色或公开页面上的旧“已认可”标签都不能扩大范围。歼-10C 基础布局和 Su-30SM2 基础布局不列正例；“无人物”仍是完整分支，和被划掉的两件具体作品是两件事。

| 情况 | 从哪里开始 |
| --- | --- |
| **无人物** | [F-2A 基本布局](references/base-layout.md)提供一套完整无人物实例。跨机型先选相近翼形，再按本机轮廓重画。没有人物也不借角色图取色；使用指定签名色、真实机型与制造商文字。若新作未指定颜色而选型和配色已授权，自选并记录。 |
| **人物** | 用户明确需要人物，先从同机已认可或本次获认可的基本布局出发。再按[各面分工](references/surfaces.md)与[素材选择](references/core/assets-and-layout.md)安排姿态和裁切。上翼可放人物，下翼保留基本布局；共享 UV 必须在最终下视验证。官方图限定、素材可否重复、垂尾要不要人物均按本次选择。 |
| **已有认可版** | [F-15EX「终末地」](references/f15ex-endfield.md)：双发双垂尾无人物基线（含 CFT、内置字体、三段钛喷口与无缝实心白 V）；[J-16 青色无人物](references/current-approved-j16.md)：保留当前双发整体及后机背左中右；[J-10C 青黄无人物](references/current-approved-j10c.md)：整块双翼渐变、两肩字距认可，旧图的两枚剪影另有勘误；[J-10C 祀](references/current-approved-j10c-si.md)：淡翠绿与金黄的最终整机组合认可，早期失败与部分认可记录不能覆盖它。早期 [白组示例](references/centreline-approved.md)是中轴构造记录。 |

深底默认炭灰 **#333334**。饱和签名色用机头连前机背与左右主翼的整块色场；浅色签名用白／浅灰做第二大面，签名色退到细线与淡染；用户选择浅底则按[实模分支参考](references/modern-jet-examples.md)重新确定负形与材质，不套深底的白形比例。用户指定双色时让两色进入整个目标色场；人物多识别色用于周围渐变，人物保持源色。见[色表与统计口径](references/palette.md)。

## 从原皮到设计稿

1. 按[新机型上手](references/core/new-airframe.md)核对机型、原厂 BLK、颜色与材质贴图、真实场景与几何，确认模型轴、材质、节点、岛和贴图密度。把一张贴图与实际使用它的表面绑定。缺作者原图或目标机的某个输入就列出限制，不借用另一架的图、岛号或坐标冒充。
2. 在原 UV 上分别确定可涂外皮与机械区，核对喷口、座舱、轮舱、活动面及原 Alpha；白罩为保护。对共享／镜像岛先确定每个纹素由哪一面绘制，并检查另一面会显示什么。共享像素不能承载两份独立文字或人物；需要左右异字／上下不同而 UV 无法实现时改放独占表面。用同一套 geometry、设计、atlas 大小和保护罩做 [绘制与表面检查](references/core/native-checks.md)。
3. 先定大形。采用 F-16C／F-2A 已认可方案时，机头色场向后凸出收尖，炭灰间隔外是[主白形、闭合孔洞、独立小 V 与弱回声](references/centreline-approved.md)。**若从带机背圆包雷达罩的参考引导文件（如 `j16-guide.json`）迁移白组，目标机该处若平滑无障碍物，必须把绕开圆包的碎片 `idx 16 / 17 / 20` 合并重绘为完整连续、不镂空、无圆洞的实心锐角白 V**。新作若选其他机背构形，按该机色场与所选参考确定白形所在面、角度及分量。在 F-2A 分支，翼根深楔、中段色场和翼尖深带形成三级；平尾前缘带和垂尾序列分别落到相应外皮。换翼形时先画本机的翼根与签名色交界、翼尖或后缘的收口，再判断哪些次要条纹值得保留。鸭翼选对应实例：J-10C 的认可方案保留自己的前缘处理；阵风的尖片与字组只在选该原作分工时用。中轴不靠一个 V 等比复制或统一加粗。
4. 按[马赛克与炭灰第二层](references/mosaic-and-charcoal-detail.md)校准三角边长、母色留缝、明暗权重和左右翼实际方向；活动面接续同一物理渐变。采用双发 F-2A/F-15 后段布局时，**后机背（外长线、内箭头、机鼻朝前侧视剪影 + 剪影旁完整机型锁组/胶囊与中央低体量尖片细线）及内侧主翼后根/平尾前方炭灰技术细节簇（标识+条码/斜纹警示+刀形短机型标）均必须补齐**，不得因减少文字数量把后机背文字或翼根细节删成光板；平尾机型标用俯视轮廓。目标机的新侧视／俯视图标可用[原模剪影工具](references/core/resource-markings.md#从本机飞行几何取剪影)直接取形。复用 F-2A 的后机背成对排布时，在**机鼻朝上的正俯视**，两枚小飞机机鼻都朝前，左枚垂尾向右、右枚向左。[字与标识](references/type-and-decals.md)默认使用内置宽体 `assets/fonts/Orbitron-VF.ttf` + `Michroma-Regular.ttf`；文字与徽章须避开相邻色带、方格列、翼尖边缘和活动面铰链缝，四周保留清晰暗底呼吸间距，避免相互逼挤。
5. 用 `vector_paint.py` 输出可编辑设计、分层图和合成。按[原生检查](references/core/native-checks.md)运行 `design_lint.py`、`surface_map.py`：白组、人物关键框、接缝、同图幅防逼挤（`crowded-placement`）、以及几何边界/铰链缝净距（`surface_map.py` `edge_items` / `seam_items` `< 5 cm`）各查一次。零命中或净距过近需回查。对已有命中但实模难以辨认的装饰，指定其应读到的机位，按[图元可见性复核](references/core/item-visibility.md)比较保留和移除该图元的两张布局渲染，再查可见承载面与最终 DDS。例如下鼻的色环和后腹线应在仰视核对。

## 漆面

按[UV 与材质](references/core/materials-and-uv.md)分开颜色、Alpha 和打包的材质数据。F-2A 式基本布局不描原厂面板线、铆钉；机械件保留原皮或按材质分工单独分级。默认非金属深底用 R 173／B 0、浅底用 R 228／B 56；若用户要求缎面金属+清晰反光质感，使用实机验证的**缎面高金属预设** `coat_material.py --preset metallic-satin`（R 163／B 188／G 128／A 128、`--structure 0.0`），并同步以 `--flat-detail-out` 生成 512² 平坦中性细节法线（`RGBA=(198,128,255,128)`）在 BLK 中替换平铺细节法线槽位（如 `aircraft_normal_detail_lo_n*`），消除金属高光下的机翼“水波纹”。对保形油箱等独立挂件（注意 2:1 非正方形尺寸与对应 `_n` 槽位）同步涂装、去碎块并共用同套清漆；**发动机屁股及前方机腹/机背护罩禁止直接保留原皮黄褐或大块发亮银灰**——调用 `coat_material.apply_exhaust_finish` 保留原厂 `G/A` 铆钉法线并将 `shroud` 压成深枪灰钛金属、`noz_outer` 改深阳极钛、`noz_inner` 改哑光碳陶。J-10C 祀保留已选 R 128 与其法线方案。只在用户点名要时新增面板线。格式、通道与光照分别核验。

## 从模型检查到交付

- **布局与面积**：在本次受影响的俯、仰、侧视及局部看最终贴图，绑定机型、场景、材质和贴图。整机百分比用带模型遮罩的 `airframe_setup.py shares`，选角色标记／色板或历史 F-2A 定义；`atlas_palette.py` 测的是展开图，不能代替俯视面积。F-2A 饱和红分支的 48% 深底、38% 签名、6.3% 白仅供该视角对照，不作为其他分支或认可作品的硬闸。
- **边缘与可读性**：对最终包内实际解码的颜色图取 1:1，检查同类线宽、孔洞、字和人物边缘；另在真实模型上以两点标定约 100 px/m 的局部相机，核对主形、缝与细回声。两份视图回答不同问题，见[原尺寸和观看尺度](references/core/view-scale.md)。实机投诉优先复现投诉的角度和屏占比；本地相机不是游戏截图。没有作者原贴图时可核查本作品，但注明不能作作者同尺度比较。整套七视图仅在本次获明确授权时生成。
- **人物追加检查**：需要左右同向时，以机鼻朝上的同尺度正俯对齐眼线、下巴与露肩，再从最终 DDS 取原尺寸双眼和发丝检查有效细节。用[人物布局](references/surfaces.md)核对左右眼脸、发丝、翼根及活动翼面、最终下翼无意外人物、垂尾符合本次选择。若出现灰雾或紫边，沿原图 → 分层 → 合成 → DDS 解码逐段对照，再查材质与游戏滤波，不靠增加分辨率或统一改格式掩盖。
- **导出、封包、安装**：按[打包与验证](references/core/packaging-and-validation.md)保留可编辑源与实际来源。传统 BGRA8 单层是祀案例实机验证过的选项，不是所有机型要求。游戏 ZIP 只放一个涂装文件夹、BLK 与实际引用贴图；从最终 ZIP 安装到约定的 UserSkins，逐文件比 SHA-256。记录游戏可选名、实际验证过的离线／实机状态，技术通过与用户美术认可分开。

常用工具及可选依赖见[工具表](references/core/overview.md#可选工具)。原生流程需 Python 3.10+、NumPy、Pillow、SciPy、Numba；运行 `python -B`，Numba 缓存放系统 TEMP，输入、输出及收据放任务目录。图形构造、原包逐组研究另见[图形库](references/motifs.md)与[原 UV 逐组核对](references/core/uv-native-replica.md)，不要把历史示例作为独立新机的美术模板。
