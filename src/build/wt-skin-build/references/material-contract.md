# 材质目标、通道解释与工具限制

**材质目标来自当前风格／设计；通道解释来自本载具 profile。** 本工程包不指定亮面、哑光、单层涂层、金属度、面板线或法线压平。未授权修改的原值保持不变。

profile 对每张贴图记录资源标识、哈希、尺寸、颜色空间与 RGBA 每通道的含义、变换、证据和验证范围。某通道未知时明确写 `unknown` 与 `preserve`，不能从 `_n` 后缀推成普通 RGB 法线图，也不能默认所有载具具有相同打包方式。颜色图 alpha 单独记录，它可能承载与颜色不同的语义。

## 哪些现有工具带解释假设

| 工具 | 已实现假设 | 使用条件 |
|---|---|---|
| `build_skin.py` | 保持颜色 alpha 和未指定的数据，允许逐通道替换 | 精确资源身份与输入尺寸已核对；本次修改通道有证据 |
| `coat_material.py` | R 写常量、B 写常量；G/A 朝平值混合；默认 structure=0 | 仅在本 profile 确认这些通道意义、平值与目标后显式指定全部材质参数；默认值不可作为通用规范 |
| `structure_layer.py` | 默认从 G/A 提取高频结构并生成独立层 | 必须显式 `--channels` 与参数，确认对应通道确实承载待提取结构；目标要求这种结构时才用 |
| `scene_preview.py` 材质模式 | R 解释为 inverted roughness、B 为 metallicity；法线需明确 convention | profile 与实现相符时可做近似对比；不符时只用 layout，不借预览反推真实游戏含义 |
| `finish_preview.py` | 必须选 generic 或 dynamic_masked_chrome_public；后者限特定 source_shader | 检查 shader、通道映射、法线约定与 profile；工具是近似，不是编译后的游戏 shader |
| `dds_variant.py` | color/data 角色分别过滤；G/A 当前仍是数值 mip | 只声明过滤和编码范围，不能称为向量感知法线滤波或游戏 shader 验证 |

`coat_material.py` 的 protect mask 会最近邻缩放；调用者必须先检查尺寸与采样对保护区边缘的影响。若 profile 与此工具假设不同，选择保持原值或实现适配器，不通过更改字段名称强行运行。

## 受控定位

出现发白、过亮、凹凸异常或结构丢失时，依次固定相机、实际贴图、场景材质、光照，核对“设计源 → 导出 → 包内解码 → 实际安装”。一次改变一项。保持实际色值与曝光证据，不能仅凭截图把光照效果写入颜色图。

离线光照、原色 layout、normal-off 诊断各自只回答限定问题。normal-off 是诊断开关，不是应压平法线的美术结论。玻璃代理不透明、损伤或运动状态未知时单列范围，避免用代理问题驱动错误修图。

## 通道变更记录

每次变更记录 `resource_id`、通道、原值来源、预期作用、实际操作参数、保护域、前后哈希和规定光照证据。用户风格评价与技术值分开；局部看起来更好不建立跨载具通用映射。
