# 修订 17：第二阶段立绘（J-10C v6）

起因：用户：“这里不需要字，你开始上立绘吧，看看能不能调用 gpt 的生图模型”。位置定为主翼上表面加垂尾两面（4 张不同的图），图源“先找立绘，觉得要帮忙就找 gpt”。过程见 `assignments/j10c-laevatain-akamywek-20261018/verification/v6/workflow.md`。

## 改动（每条都有测试）

1. **`design_lint.py` 的 repeated-art 误报**：一张图跨几块 UV 岛（主翼和两段升降副翼），每个岛的图表都放了同一张图、同样的摆放，原来被报成“重复使用素材”，v6 的构建因此停住。现在按“来源 + 中心、宽度、角度、翻转、裁切”分组，同参数的算一次摆放；换位置、翻转、重新裁切仍然报。
2. **新脚本 `art_cutout.py`**（从任务 `tools/v6/cutout.py` 来）：纯色底人物图的干净抠图。
   - 被人物围住的背景也去掉（Composa `plain` 只擦和边缘相连的部分）；
   - 边缘按颜色距离抗锯齿；紧贴背景的一圈按邻域参照色算透明度，鲜艳颜色的边缘也不留灰圈；
   - 反混灰边，输出深底检查图。
