# 喷气式飞机的原 UV 正交制作

路径为“模型与原 UV → 正交参考 → 分方向设计 → 可见性投射 → 回烘原 atlas → 模型检查”。保留模型姿态、原 UV、部件变换和材质分组。仅有二维 atlas 无法恢复准确的三维投射关系。

## 几何与资源

使用实际可渲染的网格、原 UV 和材质关系。资源检索核对内容，按需要优先使用更新资源；容器解压不等于网格解码或 DDS 转换。将节点、骨架/部件变换、材质与 UV 清单留在工作区，控制互斥挂载和显示状态。

`scripts/surface_preview.py prepare` 通过配置的解码器筛选目标颜色资源对应的静态几何。解码器目录按显式 `--tools`、`WT_ASSET_TOOLS`、所属项目 `.skin-workshop.json` 的 `tools.asset_decoder` 解析；项目相对路径以项目根为准，不依赖调用者当前目录。目录需包含 `wt_assets.py` 与 `dae_backend.py`。解码器不是此 Skill 的内置模块；缺少它时使用已有、适用的 `geometry.npz` 或取得受支持的解码器。

几何 NPZ 使用 `triangles`、`uvs`、`node_ids` 和 `names`，数组数量、索引、形状及数值在投射前校验。模型坐标与导入姿态保持一致。prepare 支持节点 glob 排除，生成原 UV 静态布局数据，不模拟全部动画和游戏着色器。当前回烘只支持首个 0–1 UV tile；重复或跨 tile UV 会拒绝，不能靠裁入 atlas 当作已支持。

## 多材质整机场景与补充相机

需要保留座舱、喷口、附件等不同材质共同显示时，使用 `scripts/scene_preview.py`，不要把全部面随意套进一个颜色 atlas。公共 prepare 接受标准解码器导出目录：`parts.json`、`materials.json`、逐部件三角 OBJ 及已取得的纹理。用 selection JSON 明确静态状态，最小结构为 `{"schema_version":1,"description":"本次展示状态","include_nodes":["实际节点名"]}`；从真实节点清单选择精确名称，不靠命名猜飞行态或把互斥挂载全部叠入。

```powershell
python scripts/scene_preview.py prepare --asset output/decoded-aircraft --selection design/scene-selection.json --out output/scene
python scripts/scene_preview.py render --scene output/scene/scene.json --view reverse-iso --mode layout --out output/scene-views/reverse-iso.png
```

prepare 保留解码后的原装配坐标与 UV，输出逐三角形 `material_ids`、`material_names` 和资源槽关联的 `geometry.npz`、绑定输入哈希的 `scene.json` 及 `prepare-receipt.json`。scene 的 `schema_version=1`；几何及颜色／打包材质引用含 `path` 和 `sha256`，`materials` 的连续 `id`／`name` 与几何一致，`display_state` 记录展示状态。selection 可按现有材质名提供 `materials` 覆盖，设置颜色、打包材质引用或明确常量代理。缺少真实材质时查看收据中的 proxy 警告；常量及保留的 RGB 代理不能证明玻璃透明度或游戏材质正确。

预览支持标准七视图和 `reverse-iso`。局部近景可用 scene 的命名 `cameras`，或 `--camera` 指定 JSON：提供 `eye`／`up`，可加精确 `fit_nodes`、`target_world`、`zoom` 与画布尺寸；也可提供已确认的 `basis`／`center`／`scale`／`width`／`height`。相机只改变观察，完整场景继续参与遮挡。调整输入贴图或几何后显式更新引用哈希并重新生成所需引导，不用旧引导绕过内容校验。

scene 可登记重复 UV 供显示，但这不增加回烘支持。场景的深度与 owners 属于完整场景几何，不能配给另取的投射子集。实际回烘使用与投射几何完全配对的引导；必要时先去除不支持的材质／表面并重新生成，而不是只改哈希。

## 正交参考与绘制

```powershell
python scripts/surface_preview.py render --geometry output/geometry/geometry.npz --texture textures/body.tga --view top --view bottom --view left --view right --view front --view rear --view iso --width 2048 --height 2048 --out output/guides
```

参考图、相机 JSON 和深度数据作为同一组使用。当前引导 `schema_version=2` 绑定完整几何内容 SHA256、相机的 basis／center／scale／画布指纹与深度文件 SHA256，深度 NPZ 同时保存逐像素三角形 `owners` 及几何、相机身份。路径相同不代表内容相同；几何或相机改变后重新生成整组引导。旧无绑定引导需重建，不改写历史文件。各方向使用同一模型姿态；检查相机旋向、画布与缩放，文字在侧视及斜视保持一致。

在编辑器保持每张参考的尺寸、位置和方向。参考底图单独隐藏，导出透明设计层；裁切或重新缩放画布会使投射失配。直接 UV 局部编辑可跳过正交投射。

上述尺寸一致约束针对同一组参考与投射数据，不要求沿用旧稿的像素尺寸。提高分辨率时，重新生成相互配对的参考、相机、深度与 owners，并从原素材和可编辑源层按相同模型空间布局重建覆盖图；不能仅放大旧覆盖图或 atlas。先核对所用工具的画布与内存边界，超出单张能力时选择经过验证的分块或其他渲染入口。

多方向稿进入合成前，为每个连续绘制表面确定主导来源和明确承载域，并以同一组模型空间锚点核对色场边界、路径和裁切。顶、侧、底图若覆盖同一物理区域，应表达一致的设计；不同设计必须通过真实表面或明确遮罩取得互斥归属，不能让几张独立画面自行争夺同一曲面。检查重叠区的同一位置，不只比较各张正交稿单独是否好看。

圆周或其他展开图表不一定具有相同的横纵物理尺度。横轴为角度、纵轴为机身站位时，直接旋转文字或等比例导入图形可能在模型上压扁字高、拉长笔画；先用实际曲面长度补偿局部比例，再在整机显示尺度检查完整字形。图表上的连续区域也可能对应被独立凸起遮挡的表面，文字与主线须避开真实遮挡或换承载位置；源 SVG 完整和分辨率足够都不能关闭这一项。

几何承载遮罩用于限制可绘面，其轮廓不自动成为图形设计。源稿出现原矢量没有的重复三角齿、台阶或孔纹时，先在未回烘的角色层与色场层对照实际 carrier alpha，再追查平面映射或图表如何把该轮廓带到曲面；增加分辨率不会去掉已经进入源稿的齿边。区分真实机体外轮廓与落在连续涂层内部的遮罩边界，按明确表面职责重建承载和接续，不用全局模糊、膨胀或直接填满真实间隙掩盖。最终以对应模型位置的实际映射复核，不能仅凭同类形状便认定截图每个缺陷的来源。

承载范围是设计选择。先确定要保留的完整头型、头饰、颈肩、肩臂与关键手势，再按真实轮廓、间隙和当前部件状态选面；不能先把整个人物机械限制在 fixed-wing 遮罩，再裁头或肩去凑命中。关键连接避开真实空隙和会分开的边界；衣料、远端长发可在明确的静态闭合控制面上有意延续，但需记录该状态，不能宣称活动或游戏状态已验证。翼面与尾面独立构图，机腹按当前无人物要求处理。

节点、深度归属与 UV 参考用于防误投，须复核实际可见承载区。粗坐标或三角中心选面可能整片排除跨界三角，局部保守遮罩不等于最大可用面；网格连通也不证明画面连贯。自动适配检查关键头部与动作，alpha 全命中不代替构图。外围裁切后以同尺度整机和局部复看，头或肩被硬切时先改素材、位置、角度、尺度或承载域，不能用技术剪切掩盖。

人物承载遮罩的形态学内缩应保护内部连续、真实可见的表面。先区分外轮廓、真实间隙和有限分辨率下的一像素无归属裂隙；直接对带有内部裂隙的遮罩做侵蚀或 MinFilter，会把裂隙扩成切穿头发、脸或颈肩的假孔。提高分辨率、恢复载体或配对左右遮罩后，用原几何的实际可见面复核内部小孔；表面确实存在且人物应连续的位置，从原素材恢复覆盖，真实空隙仍按原几何保留。逐点核对人物关键区的源 alpha、回烘 UV 及实际模型，检查内缩和配对没有重新引入假孔；总覆盖面积接近、对称或脸仍可认不能代替这项检查。

## 投射与共享纹素

```powershell
python scripts/surface_preview.py bake --geometry output/geometry/geometry.npz --base textures/body.tga --overlay output/guides/top.json=design/top-overlay.png --out output/body-painted.png
```

覆盖图与相机 JSON 精确配对，画布尺寸、几何、相机及深度／归属必须一致。投射结合逐像素可见三角形归属、深度与有符号面朝向，不能只靠深度容差接受后方近面或薄翼背面。提高 `--min-facing` 可减少近乎侧视表面的拉伸，随后检查相关表面覆盖。

朝向阈值是采样保护，不是设计路径的边界。源稿连续而实际 UV 在机背曲面、翼根或节点交界处缺色时，逐点核对相机朝向值、阈值、承载域和来源优先级；达到阈值要求的部分变清，不能关闭被剔除的线段。对需要跨曲面连续的图形，使用补充相机、明确的连续表面图表或直接 UV 编辑，并用同一模型空间锚点接续；只给某方向降低阈值或膨胀遮罩，仍须独立复核真实遮挡、侧面拉伸及禁区。沿实际路径检查接缝两侧颜色与局部对比，UV 坐标跳跃本身不等于接缝缺陷。

任一含有效 alpha 的覆盖图零命中即整批失败，不因其他方向已有命中就跳过；检查面朝向、遮挡、位置和承载面后再投射。整批均没有有效 alpha 时记录为 `no_op`，保留原基底并输出零遮罩，不称为完成绘制。主输出及其派生遮罩、JSON 同样不得覆盖基底、覆盖图、引导或其他已有资产。

回烘与渲染保持相同取样坐标：UV 的 `u×(W−1)`、`(1−v)×(H−1)` 对应整数 texel 中心；屏幕光栅仍在 `x+0.5`、`y+0.5` 取样，不能混用两种中心。主回烘后，当前工具只从实际可见 owner 的屏幕样本枚举最多四个权重大于 `1e-7` 的 bilinear 支撑 texel，补未被主回烘覆盖的部分；不膨胀 UV 邻域，不放宽遮挡或面朝向。查看收据 `sampling` 中的补齐量、颜色竞争和 UV 中心重叠。支撑齐全只说明该相机与取样条件下没有漏写贡献 texel，不保证颜色逐像素重建、美术质量或其他视角通过。

共享 UV 的多个方向可能竞争同一像素。辅助脚本按几何三角候选的 facing×alpha 离散选择来源，这是取样优先级，不能协调相互矛盾的构图。各方向在同一连续曲面布置不同色场时，选源可能沿三角面切换，产生宏观三角切色，即使单方向回烘与采样支撑均通过。先修来源一致性或承载域归属，不把软混合当自动修复，也不能将正交图按矩形拼到 atlas。非连续表面另行安排，保留文字与图形的有意边界。

UV 中心重叠统计是严格三角形内部覆盖的下界，bilinear footprint 还可能读取更多共享 texel；零重叠不证明可以独立绘制。重叠量或补齐时的颜色竞争用于定位复查，不能自动归为可见冲突或声称已修复共享 UV。回到实际材质、承载面和可见性判断；同一 texel 的共享读取仍不能保存两套独立图案。

顶底共享同一纹素时，清空底视人物图层并不能使底面独立于上面。先确认共享关系；将人物移动、缩小或裁切到可独立安排的 UV 区域，必要时换承载面。提高面朝向阈值只能改变投射候选，不能让共享像素保存两套独立颜色。

先用机体坐标、表面朝向和部件位置确认尾面结构。单尾按左右两面安排，默认两面均有人物；双尾按各片外侧人物、内侧图形安排，当前要求优先。左右视图标签或画面中的远近不能单独决定面别。共享 UV 不支持独立内容时通过图案一致性、裁切或换承载面解决，含字内容按最终模型判断方向。被另一片尾面遮住的面不能凭主侧视证明完成；使用补充相机、单独部件投射或直接 UV 编辑，保留原坐标与方向，分别核对每面的既定职责。

## 回烘后检查

先查看只有色场与路径的实际合成模型，必要时对照单方向回烘，检查连续曲面是否出现三角切色、跨方向边界错位或重复裁切；出现这些问题先回查同一物理位置的来源与承载域，不直接归咎于材质、人物或合成计算。再恢复人物、文字与材质看完整整机，确认修正没有破坏独立翼面、尾面和配件的职责。单方向正确或 atlas 合成可重现，都不能代替多方向最终模型验收。

重新渲染顶底、两侧、前后与斜视，并补看反向斜视或尾面局部，检查文字、人物轮廓、接缝、尾面、镜像和配件。重点确认脸与肩线没有被结构切开、主翼人物没有残片落到平尾或机腹、垂尾确实有人物，以及机背路径能在整体尺寸读出层级。跨部件的人物或字标受到遮挡时，优先裁切舍弃非关键部分、移动或换承载面，保留可读尺度后重新回烘。投射命中数量和遮罩完整不等于构图通过。

存在独立人物层时，可将人物单独回烘成 UV 遮罩：人物区域为亮色，背景 RGB 为黑色，再临时作为诊断色图渲染模型。不要只清透明度而保留白色 RGB；部分布局渲染器直接读取 RGB。底视与腹部斜视用于发现共享 UV、投射残片和边缘取样；垂尾与侧面的人物按其表面职责判断。没有可靠人物遮罩时，直接检查最终颜色贴图的实际模型视图，不用未经确认的自动分割结果证明无人物。

腹面或翼下禁人物区域不能只取所有朝下法线三角形的 UV 并集。隐藏辅助几何可能用很小的空间面积读取整张 atlas，法线朝向本身不证明它是实际可见的机腹。先审核目标承载面的真实形状与职责，再结合完整场景底视和两个相反腹斜视的可见 owners，定位需检查的真实表面；跨投射子集必须有明确三角对应，不能直接混用不同几何的 owner 索引。排除辅助面需保留几何与可见性依据，不按节点名一概删除，也不修改原 UV。

人物增加、移动或裁切后，以实际合并人物 footprint 和最终颜色图同时检查投射机体与完整场景的底视、两个相反腹斜视，结合可见画面与边缘取样诊断。单个主人物检查不能覆盖后来新增的尾面或副像。出现真实禁区重叠时，展示受影响位置并返回编辑器改布局、裁切或承载面；不能静默从人物 UV 中减去禁区来凑零交集，这可能切断脸或颈肩并掩盖冲突。主动统一共享像素或黑填也不得遮盖应保留的肩胸与动作；出现这类损失时改布局、素材或承载面，无串色不能代替图像完整。有限分辨率的静态可见性证据不覆盖未知视角、mip、活动或损伤状态。

```powershell
python scripts/surface_preview.py render --geometry output/geometry/geometry.npz --texture output/figure-uv-mask.png --view bottom --width 2048 --height 2048 --out output/figure-check
```

诊断时结合几何覆盖区排除背景和模型空隙，查看亮区的位置、面积与强度。极弱边缘样本与可辨认人物残片分别记录；继续检查最终颜色图、缩小显示与实际需要的 mip，不能把遮罩数字当作美术评分。诊断输入留在工作区，不替换交付贴图。

投射默认保留原颜色 alpha；打包材质使用已确认的原图或明确编辑过的通道。近似漫反射渲染用于布局观察，实际材质光照按项目要求另行验证。
