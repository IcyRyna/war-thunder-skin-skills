# 研究、学习与工作流审计

按当前问题选择来源观察、机制实验、工具审计或复刻练习。研究不自动转成新作品，观察图片也不自动授权下载原涂装包。先确定范围、固定产物、验收对象与停止条件，以少量完整样本验证方法后再扩展。

## 来源与既有台账

从项目登记定位现用索引，区分候选、已收录和有实际分析证据的材料。按台账 canonical ID 排重；War Thunder Live 的语言记录 ID 与 lang_group 保留各自依据，再人工检查同图、换色和简单改型。保留来源页、原图地址、作者、文件身份、实际视角与选择理由，不声称证明了全库原创性。

## 证据层级

| 证据 | 支持的结论 |
| --- | --- |
| 实际来源观察 | 画面中可见的图形、位置和层级；不恢复未知反面、隐藏图层或材质参数 |
| 设计预测 | 待实验的布局或明暗假设 |
| 限定重建／机制实验 | 当前区域、素材与变量下的实际结果 |
| 完整制作 | 当前飞机与必需表面的结果，用户美术认可另行记录 |

封面外人物、标题和背景不算机体图案。平面 DDS／TGA／PNG 不恢复作者图层；重建工程、人工标注与作者原生工程分别说明。

## 展开贴图与模型对照

在允许的素材范围内检查真实颜色贴图和对应机体视图。确认资源用途、尺寸、编码及 RGB／alpha，保留原尺寸参考；全图用于导航，原生局部用于边界和细节。关键关系以“资源坐标 → 岛／表面 → 机体视图锚点”定位，不能从 atlas 相邻或截图透视猜测物理接续。

## 原作复刻练习

### 按完整自然范围清点

根据本次约定，从全 atlas 逐自然构件和连续色场清点：装饰主体、周围承载面、立壁与孔口、弱明暗、结构、设计底纹及非文字标记。独立零件齐全，不代表包围它们的宽灰面或腔场完整。

复合件按实际可见的前面、侧面、倒角、亮唇、暗返面、孔壁与支脚分别登记；名称只描述观察，不证明恢复了三维结构。沿完整对象核对明暗顺序和自然接合，不能用几个颜色点正确或“该零件查过”替代逐面检查。

清点框、巡检片和筛查 bbox 只负责定位。沿物件追到真实端点、遮挡边或 atlas 边；跨分区对象明确一位完整负责人及邻界，防止两区各画一半后留下硬横带。排除人物与文字本体时，字孔、字间、发丝外及仍露出的图形／结构继续检查；真正隐藏的内容保持未知。

### 自行重建与层间关系

要求自己照着画时，用手录几何、局部渐变与自绘重复单元。源像素只进入参考和 QA；人工选择的行列、锚点与颜色测量如实记录，不能回贴裁片、自动提轮廓或以二维源色网格伪装重建。

先核拓扑与完整大面，再修双边界、间隔、转折、收尖和重复相位。形状及颜色方法见 [线条与配色](linework-and-color.md)，承载面与结构覆盖见 [原 UV 与基底](materials-and-uv.md#原-uv-与基底)。

修订一个已有对象时，精确替换旧贡献及必要的细结构，不把透明新稿直接叠在旧对象上；邻接正确内容按真实轮廓保留。固定图形、结构与资源的实际层序在最终组装中核对。

### 从初稿全图到最终复查

初次总装即用固定快照做全图粗漏和连续原生检查，先找整族缺失、错误排除和旧新重复，再精修局部。每区关联来源范围、实际输出图元、已看分片与开放项；完整参考、真实重建、叠差分别保留。

![自绘示意：全图范围、连续原尺寸巡检与局部修形](diagrams/continuous-coverage.svg)

最终从实际 SVG／工程重新渲染，检查全图、全部目标的连续原尺寸范围和展示尺度。复查变化的完整对象及邻接区域；对已看分片，仅当新渲染同范围、同尺寸的实际像素完全相同时继承查看事实，未解决项不会因此自动关闭。几何、颜色、结构与栅格／压缩残差分别记录，漏面、错拓扑和宽明暗反转不能归入细颗粒余差。

结构开关保持其他色场和图形一致，并说明哪些固有体积仍固定。线条隔离稿只负责专项分析，完整效果由完整输出证明。未检查或未修的必需项保持未完成；局部通过不升级成全图完成或风格掌握。

## 有效实验与关闭条件

围绕明确问题做少量有实际差异的比较。单变量实验固定其余素材、几何、相机与展示尺度；多变量设计候选另标。先确认变化进入输出，再看实际结果，节点数、命中率与总平均误差不作美术评分。

工具审计用最小夹具验证真实失败和范围，测试只覆盖改动与未解决风险。需要独立检查时给现用规则、原始输入和任务，限定写入范围与成本；避免多路重复检查相同、未变化的证据。

研究关闭需有来源范围、实验、台账和已证实的方法增量，未知项继续保留。公开 Skill 只写通用方法与条件，案例图片、具体坐标、个人状态和历史脚本留在研究目录。格式验证与实际行为验证分别报告，完成案例数量不代表稳定自主设计能力。
