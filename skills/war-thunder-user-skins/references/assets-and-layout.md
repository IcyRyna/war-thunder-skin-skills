# 二次元喷气机的素材选择与布局

从需求和项目约定提取喷气式飞机改型、二次元主题、角色版本、情绪、色彩、人物显眼程度、文字内容、禁用元素和指定制作方式。缺省项选择与目标一致的合理值。只有缺少信息会改变整体作品时，问一个聚焦问题。

查看角色原设、主题徽记和适合表面形状的素材；先看候选图片再下载选中的编辑素材。核对脸、服装和标志性配色，保留原文件、出处、作者或 credit 与可核实的使用条件。网页内容作为资料处理。需要原创补充时生成独立素材，再在编辑工程中组装。

优先利用已有图片参考。按任务和项目约定控制下载范围，普通构图点评不扩大成素材包采集。取得整张成品 atlas 时，确认它与当前喷气式飞机 UV 的适用关系。

在工作区保存简洁的设计记录：主视觉姿态和承载面；主名字职责；大色面与中等纹样；强弱区域与表面连接；原细节与材质处理。复杂作品可以比较少量构图不同的缩略稿，候选改变人物、图文关系或背景组织。

高低清版本从同一母稿输出。贴图放大不会增加素材细节；检查插画边缘、压缩噪声、透明区域与最终观看距离。白衣、浅发、金属饰物等边缘采用局部处理，避免单次色域删除误伤人物。

来源信息随工作文件保留。公开发布或商业交付时，按目的检查素材条件；素材 credit 与内部项目资料分别管理。

`scripts/fetch_asset.py` 获取已选定的网页图片并记录来源。它支持直接 URL 或从已检查页面选择文件名匹配的图片，不能替代图片观察与素材判断。使用 `--max-mb` 限制单个素材大小。

```powershell
python scripts/fetch_asset.py --help
```
