# 喷气机痛涂的线条与配色

## 先建立整机路径

在真实机体上确定主导方向如何进入、展开、转折、停顿与收束，以及由人物、文字还是图形承接。色场边界、宽带和人物轮廓都能承担路径，不要求所有区域物理连成一条线。真实间隙与活动面分别安排。

## 先辨别看到的是哪一种线

分开观察色场边界、独立主题笔画、字与人物轮廓、机械接缝及光照反射。宽带按两侧轮廓重建，不能用一根等粗描边代替；发丝动势和字标外缘也不自动需要装饰描边。被遮挡路径保持未知，重复图形可通过方向与间隔形成视觉接续。

## 按主题选择线条家族

用户指定作者、作品或局部时，先从真实颜色贴图及对应机体视图读取关系；自主设计才另从角色服装、装备或主题图形选形。整体美术、线条和配色参考可不同，职责在设计记录中说明。

把**色场、宽带、负形和伴线作为相邻的一组形状**：观察带的两条边、共同折点或切线、间隔如何变化，在哪里收尖、齐平或错层端切。先恢复相连、分离和叠压关系，再修细线。凌厉感来自这些轮廓关系；直线、局部圆弧和圆角依实物选择，不按角色自由改掉指定线型。

示意不提供固定线族或像素配方。换机型时迁移主次、方向和疏密，具体形状回到新 UV、纹素密度与可见面；需要改变指定关系时单列为改编方案。

## 线条的尺度与形状

| 职责 | 组织重点 |
| --- | --- |
| 主带、大切面或主边界 | 远看方向和视觉重量，按位置展开、收窄或转折 |
| 中等边线、框与字轨 | 分开色场、承托主字，保留可读负形 |
| 细线、短条与重复标记 | 服务已有方向或节点，控制节奏与局部强弱 |

这是职责分工，不要求每面画齐。用户明确的密度另行验收。同组先维持共同方向与可读间隔，再依据参考改变宽窄、长短和端点；避免每条线各自折返。重复单元逐区核对节距、相位、行偏移、朝向、裁切与淡出，不把总长均分后拉伸成另一个节奏。

测量记录原分辨率、坐标与方向，斜线横纵截宽不等于法向宽度。模型截图中的曲率可能来自曲面和透视，先对照展开图。移动或镜像图元后，核对渐变坐标与色向是否仍随正确区域变化，再看实际渲染。

## 按表面安排职责

机首／座舱后引入方向，翼根和机背中段展开或分流，后机背与尾根收束；具体连接可以由色场、宽带、文字或人物共同完成。主翼与尾面按人物和轮廓组织，侧身利用连续长面，配件以同套颜色和局部标记呼应。

安静区以有效色面、边界或弱细节承担停顿。某处被指出单调时，在整机尺寸先调整浅深边界、中尺度形状和承托关系，再补近看细节。深区完整线组不能代替浅区检查。各面人物默认与裁切标准见 [美术设计](art-direction.md#垂尾与机腹)。

## 机腹单独构图

以中央通道、进气道、发动机腹部和翼下的大形定路线，在翼根展开、尾根收束，再配较弱边线和局部节奏。服从当前无人物要求；参考只有中央腹部无人物时，不把带翼下人物的整张图当合规范本。不同方案应改变可见的大形或色场分配，而非只微调几根细线。

## 颜色按职责选择

指定配色先保留底色、主色和点缀的职责及相邻对比。自主配色从角色识别色选主色，再确定承托与点缀；不固定数量和比例。

- 底色承托人物与文字，主色延续主题和大图形。
- 点缀强调边界、节点或局部转折，强度与分布有主次。
- 同色相的浅深、饱和度与局部密度共同建立层级，副线不必都变白。

截图用于看颜色关系，原色优先从可靠原图或颜色贴图取得；高光和环境倒影不直接当调色板。灰度辅助看竞争，最终回原色判断。RGB 银灰渐变与实际金属反射分开，见 [UV 与材质](materials-and-uv.md)。

## 编辑与验收

色场、主带、伴线、文字、人物与结构按职责保留制作源。先确认预期图元和遮罩实际进入渲染，再检查画面，尤其关注 SVG clip／mask 丢失、错误填充规则和重复叠层。

多方向稿先分配真实承载域与主导来源，再看最终合图的重复主轨、反向走向、三角切色和端点。局部修改诊断用新生成稿替换旧贡献，不能把透明新图叠在旧同对象上当作修订证据。

整机尺度看方向、主次和负形是否可读；原生局部查两侧边、间隔、折点、端点与弱纹理；斜视查拉伸和遮挡。隐藏细节看大形、隐藏人物看背景，恢复全部贡献层后查竞争。提高分辨率从矢量和原素材重建，线宽、人物面积与展示尺寸仍须合理；实际 mip／过滤另按 [打包与验证](packaging-and-validation.md#dds-与实际-mip) 检查。
