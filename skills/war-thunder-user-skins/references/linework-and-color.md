# 喷气机痛涂的线条与配色

## 先建立整机路径

把装饰线条作为构图的一部分。先在实际机体轮廓上确定起点、转折、分流、收束和它连接的角色或文字，再选择宽带、细线、边框或断续图形。主路径通常沿机身纵向延伸，在翼根分流或转向翼缘，并在尾面用同类形状呼应。路径可以连贯，但不要求跨越所有凸起、缝隙和非连续表面。

装饰线与机械刻线分别管理。原机的铆钉和面板细节提供表面结构，不能代替主题线条；保留刻线也不等于已经处理机身的大面积空白。较安静的区域仍应有属于主题的色面、边界或低对比细节。

## 线条的尺度与形状

| 层级 | 作用 | 组织方法 |
| --- | --- | --- |
| 主色带或大切面 | 远看识别、连接机体、承托角色 | 宽窄随位置变化，在需要的位置展开、收尖或转折 |
| 中等边线与轮廓框 | 分开色场、连接主字、强化翼根与翼缘 | 实线、空心线、双线或局部框按表面选择，留出间隔 |
| 细线与断续标记 | 近看节奏、补充较空区域 | 分段、渐短、错位或局部成组，减少等距重复与无意义密铺 |

层级通过宽度、明度、饱和度和密度共同区分。多条线平行时改变长度、间隔、起止点或强度；部分线终止、部分线继续，才能形成方向与节奏。尖端、斜切、菱形、折线、弧线可以组合，但选择须关联机体和角色，不能成为每套作品固定复用的装饰配方。

轮廓线与相邻色面之间保留可读的间隔，避免细线紧贴边界后在缩图中消失。主线需要在整体预览中成立，细线可以只服务近看。面向最终展示尺寸检查线宽；提升贴图分辨率不能替代合理线宽与 mip 后的可读性。

## 按表面安排职责

| 表面 | 优先解决的关系 |
| --- | --- |
| 机首与座舱附近 | 方向性细线、收尖色带或轮廓呼应；避免强框把座舱切成孤立块 |
| 座舱后的机背前段 | 主路径从窄处起笔或收尖，中等轮廓伴随；细节间隔随表面宽度变化 |
| 翼根与机背中段 | 主路径展开、转向或分流，中等框线组织两侧色场；保留中央与人物的呼吸空间 |
| 后机背与发动机上部 | 延续前段的方向，利用长短和线重变化收束到尾根；热区保留机械质感 |
| 翼根与进气道附近 | 色带转折、分流、局部框线；用斜视检查凸起遮挡和断裂 |
| 主翼 | 人物、主字和翼缘边界共同组织；线条绕开脸和关键手势 |
| 垂尾 | 紧凑头像或半身立绘承担角色识别，边线与色带承托人物；号码与徽记降低竞争，分别检查内外面 |
| 平尾 | 用同套角度、边线与色带呼应主体，按面积减少图形数量，避开割裂主翼人物的残片 |
| 机腹与翼下 | 只用色面、主辅路径、节奏图形和材质延续主题，不放立绘；随中央通道、进气道和发动机腹部转折 |
| 侧面 | 长路径连接主字、辅助识别与尾根，人物只安排在能保持轮廓的连续区域 |
| 外挂与配件 | 用适量色环、边条、编号和局部图形延续整套，检查独立资源 |

每个主要可见表面在设计记录中有明确角色：主视觉、连接、辅助识别、低对比细节或保留机械材质。若隐藏人物后只剩空底，先补充色面连接和线条组织；不要直接用密网格填满。图文重叠处优先保证人物识别和主名字阅读。

机背要有在整机缩图中可见的主路径和中等图形，细线负责补充。先隐藏人物与细小标识，分别看座舱后、翼根和后机身：只有大底色加两条细线时，继续组织中等空心轮廓、宽窄变化的带组、偏移副线或有间隔的斜切段。细节分布随主路径变化，不需要在每段铺同样数量的图案。恢复人物后，降低与脸、手势和主字竞争的局部强度。

机腹的主线可沿两侧发动机腹部成组延伸，在翼根展开，再由较细边线和渐短段落补充中央与翼下。局部方向、间隔、留白和线重应有变化；不能把背面图案整张翻转到机腹，也不能因为没有人物就只保留原灰色底。

## 颜色按职责选择

先从角色服装、头发、装备或作品识别中选主色，再选择承托底色与少量点缀色。颜色数量和比例按主题与密度决定，不固定套用百分比。

- 底色控制人物与文字的明度关系。浅色衣服需要有对比的承托，暗色人物可由较亮底色、轮廓或局部色面分开。
- 主色承担宽带、主要图形或大区域，使人物色彩延续到机身和尾面。
- 点缀色承担边线、少量节点、细标识或局部转折。强点缀色沿整机分布，但密度和强度不同。
- 相同色相可用较淡、较深或低饱和版本区分宽带与细线。高饱和色大面积使用时，其他区域降低竞争。
- 主字与重要标识用足够明度差建立识别。辅助文字随观看距离降低强度，不让每处都成为主标题。

白底、深底和彩色底都可以成立。参考配色只是关系依据，新角色需要重新匹配肤色、服装和情绪。颜色贴图中的灰、银或金并不能单独决定金属质感，表面效果另按 [材质处理](materials-and-uv.md) 规划。

## 编辑与验收

大色面、主路径、边线、细节线、文字和人物独立分层，用当前接口实际支持的形状、笔画或导入图形实现。复杂曲线或字标保留制作源，不虚构编辑器 API。局部 UV 接缝回到对应图层修订，避免水平翻转包含文字的整张图。

按顶、底、两侧和斜视逐面检查：机背前中后三段是否有主辅路径；线条是否被曲面拉坏；空白是否有明确职责；粗细和密度是否有节奏；垂尾人物是否清楚；机腹与翼下是否混入人物残片；近看细节是否能在最终贴图与 mip 中成立。隐藏细节线后检查大形，隐藏人物后检查背景组织，恢复全部图层再检查竞争关系。
