# 喷气机痛涂的线条与配色

## 先建立整机路径

把装饰线条作为构图的一部分。先在实际机体轮廓上确定起点、转折、分流、收束和它连接的角色或文字，再选择宽带、细线、边框或断续图形。主路径通常沿机身纵向延伸，在翼根分流或转向翼缘，并在尾面用同类形状呼应。路径可以连贯，但不要求跨越所有凸起、缝隙和非连续表面。

装饰线与机械刻线分别管理。可见的铆钉和面板细节提供表面结构，不能代替主题线条；保留刻线也不等于已经处理机身的大面积空白。较安静的区域仍应有属于主题的色面、边界或低对比细节。

## 先辨别看到的是哪一种线

观察参考时分开标记大色场边界、独立主题笔画、字与人物轮廓、可见机械刻线及光照反射。宽花瓣、扇带和长白色文字通道的外缘可能承担主要方向，但其宽度是色块的范围，不能按一根等粗细线去重画。人物的长发、举臂或衣料本身也可以提供弧线动势，不一定再叠一圈装饰描边。

选少量关键路线，记录实际可见的起点、转折、分叉、停顿与终点，以及它接近的是脸、手、字还是翼缘。截图估计只属于该视角；阴影、遮挡和部件间隙之后的路线保持未知。重复三角、短条、花点可以用方向、间隔和色彩建立视觉接续，彼此不必物理相连；不要为了让路线图连通而凭空加连接线。

圆环或主题印记在人物头肩后作低对比背景时，先保留其局部、较弱的职责。把它改得粗亮会改变人物与图形的竞争，不因它属于主题就自动提升成全机主路径。另一翼的人物、名字、场景或花瓣可以提供重量，不能只用两侧线条数量相等判断平衡。

## 按主题选择线条家族

先确定本轮如何选择形状。用户指定作者、作品或局部线型时，从该参考的实际颜色贴图与对应机体视图读取关系；自主设计时，再从角色服装、装备和作品图形中选择形状。整体美术参考、专项线条参考和配色参考可以各有来源，在设计记录中分别说明。

沿指定参考选一条完整的主导关系，连同它承托的色场一起观察：哪一侧是宽带、哪一侧是负形，伴线从哪里进入，转折时两侧边界和间隔怎样变化，最后在哪里收尖或切断。先重建这些相邻形状，再调整局部细线。干脆感由实际折点、切口、尖端、边界连续性和间隔共同形成；直线、局部圆弧或齐平端点都按参考中承担的职责处理。宽填充带按两侧轮廓重建，文字通道按其承托文字与组织色场的作用保留。

![自绘示意：色场、宽带、负形与伴线](diagrams/coupled-shapes.svg)

示意只说明如何读取相邻形状，不提供固定线族、像素配方或优劣模板。观察实际参考时，同时看带宽与带间负形；同组表达共同转向时，核对共享转折位置或共同切线及其间隔，再决定条数。齐平或错层端点、实心带与空心框均按实际职责判断。

换机型时，在目标 UV、纹素密度和可见面上实现同样的主次、方向和疏密；换角色时，调整与人物相接的裁切、位置和局部配色。需要改变已指定的主线逻辑或配色关系时，单列为改编方案比较。将参考和实际模型的对应区域并排看整体与局部，记录已落实关系和残差；对称、线数与零穿插分别说明相应问题，形态是否达到要求仍由实物对照判断。

无固定参考或本次要求自主设计时，可从披风、衣褶、装甲、徽记、植物、字标等提取主导形状，再沿真实机体组织。主路径可以由大色场边界、宽带、局部框或连续装饰承担。辅线与端点延续该套形状的方向和强弱；数量、对称与曲直由本次主题、素材和机体共同决定。

| 可用的形状来源 | 转化方式 |
| --- | --- |
| 披风、衣褶、带状饰物 | 顺着机背或翼缘展开、弯曲、叠出宽窄变化，在尾根收束 |
| 装甲、装备边界、几何徽记 | 用少量切面、折线与较硬端点形成方向，细节降低强度 |
| 火焰、植物、毛发或装饰纹样 | 提取轮廓与流向，组成可辨的中等图形；减少细碎内部描边 |
| 大字与标志的外轮廓 | 与色场边界呼应，让图文共同形成路径，保护字标完整性 |

这些是自主选形的例子，不是按角色类别套用的模板；不能替代用户已经选定的形色关系。增加层级时，先看宽窄、边界和强弱是否有效，再决定要补多少细线。

## 线条的尺度与形状

| 层级 | 作用 | 组织方法 |
| --- | --- | --- |
| 主色带或大切面 | 远看识别、连接机体、承托角色 | 宽窄随位置变化，在需要的位置展开、收尖或转折 |
| 中等边线与轮廓框 | 分开色场、连接主字、强化翼根与翼缘 | 实线、空心线、双线或局部框按表面选择，留出间隔 |
| 细线与断续标记 | 近看节奏、强调已有方向或节点 | 按明确职责跟随、分段或局部成组，保持可读间隔，避免为填空而增线 |

层级通过宽度、明度、饱和度和密度共同区分。同组线先维持可读的共同方向、间隔与主从关系；稳定间距和齐平终止也可以形成秩序。需要转向、节奏或收束调整时，再按该组职责改变宽度、长度、间隔、起止点或强度，不为增加变化而让每条线各自折返。尖端、斜切、菱形、折线、弧线可以组合，但选择须关联机体和角色，不能成为每套作品固定复用的装饰配方。

三档是职责参考，不要求每个表面都画齐。大色场与人物已经形成主次时，稀疏主题笔画也可以成立。项目或当前任务明确要求的密度、机背三档或覆盖范围另行验收，不将这种局部要求推广到所有主题。采用长短退场方案时，成组曲线各段按人物动作和承载空间选择终点，不把同一条曲线等距复制到所有区域；开口环、断开的弧段和被人物遮住的完整底图也要分开判断，单张图不能证明被挡部分原本怎样画。

终点本身参与构图：在头发或手势前收住，沿衣料转折接到色面，或在字旁留出出口，都可能比把人物完整包一圈更合适。先看眼睛、近脸手、颈肩和主名字周围是否拥挤，再决定辅线在哪段继续、哪段结束。需要明确边框或有意穿插时仍按主题处理，不把“避让”固定成每个角色周围同样大的空洞。

轮廓线与相邻色面之间保留可读的间隔，避免细线紧贴边界后在缩图中消失。主线需要在整体预览中成立，细线可以只服务近看。提升贴图分辨率不能替代合理线宽、人物大小与最终展示尺寸下的可读性。

分开检查贴图取样与展示尺度：比较纹素细节时，固定机型、相机和机体显示尺寸，再降低颜色贴图分辨率；判断构图时，另看预计展示尺寸下的整机与尾面。离线缩小可发现细线、脸部和小字变弱的位置，但不等同于游戏的 mip、过滤、压缩或 LOD；有需要且条件允许时另行验证实际目标效果。

从展开贴图测量线宽、组间距或负形时，记录分辨率、局部坐标与测量方向；斜线的横纵截宽不等于其法向宽度。跨 UV 岛或机型比较须核对纹素密度、拉伸与曲面尺度，没有可靠物理尺度时只报告局部纹素比例，不发布通用像素配方。模型中看似弯曲的线不证明源贴图也画成曲线；先核对实际笔画与机身对应，再决定在新 UV 上怎样实现同样的视觉关系，不能照截图曲率直接描进展开图。

## 按表面安排职责

| 表面 | 优先解决的关系 |
| --- | --- |
| 机首与座舱附近 | 方向性细线、收尖色带或轮廓呼应；避免强框把座舱切成孤立块 |
| 座舱后的机背前段 | 用色场边界、路径或字轨从窄处引入主题，按需要安排轮廓与细节 |
| 翼根与机背中段 | 让主导形状展开、转向或分流，按需要用中等图形组织色场；保留中央与人物的呼吸空间 |
| 后机背与发动机上部 | 延续前段的方向，利用长短和线重变化收束到尾根；热区保留机械质感 |
| 翼根与进气道附近 | 色带转折、分流、局部框线；用斜视检查凸起遮挡和断裂 |
| 主翼 | 人物、主字和翼缘边界共同组织；线条绕开脸和关键手势 |
| 垂尾 | 紧凑头像或半身立绘承担角色识别，边线与色带承托；单尾查左右面，双尾查各片内外面，按当前分工验收 |
| 平尾 | 用同套角度、边线与色带呼应主体，按面积减少图形数量，避开割裂主翼人物的残片 |
| 机腹与翼下 | 只用色面、主辅路径、节奏图形和材质延续主题，不放立绘；随中央通道、进气道和发动机腹部转折 |
| 侧面 | 长路径连接主字、辅助识别与尾根，人物只安排在能保持轮廓的连续区域 |
| 外挂与配件 | 用适量色环、边条、编号和局部图形延续整套，检查独立资源 |

在预计整机显示尺寸下，为每个主要可见面指出实际承担主视觉、连接、承托或停顿的内容。大色场边界、宽带、字轨和人物轮廓都可以建立连接；明确有效的安静区可以保留。用户指出某处单调或空缺时，先在该尺度调整浅深色场、中尺度图形或承托关系，再考虑细化。深色区的完整线组不代替浅色区的检查。

近看时，再安排有位置的结构、弱纹样和细笔画，让其支持已经成立的大形。隐藏人物检验背景时，核对所有人物贡献层；恢复人物、文字和全部贡献层后，检查脸、手势、主字与装饰之间的竞争。机背前中后段分别指出连接由谁承担，停顿如何与相邻区域相接。同一组线先核对共同方向、可读间隔和转折关系，再按职责选择稳定间距、长短退场、齐平或错层端点。已经获肯定的局部关系保留，未获肯定的区域继续单独检查；换角色是否重选形状由本轮参考要求决定。

机腹的主线可沿两侧发动机腹部成组延伸，在翼根展开，再由较细边线和渐短段落补充中央与翼下。方向、间隔、留白和线重由各组主次及真实机体转折决定，不为增加变化而拆散同组秩序；不能把背面图案整张翻转到机腹，也不能因为没有人物就只保留原灰色底。

## 机腹单独构图

在能看清腹部的模型视角上，先安排中央通道、发动机腹部和翼下的大形关系，再补副线。参考图只有中央腹部没有人物、翼下仍有立绘时，只采纳中央路径关系；不能把整张图当作符合无人物机腹要求的范本。侧视、机背照片和被外挂遮住的角度只支持实际看见的局部。

| 区域 | 图形职责 |
| --- | --- |
| 前机腹与中央通道 | 较窄的方向性路径引入主题，利用收尖、间隔或轮廓变化避免一根等粗长条贯穿 |
| 进气道与发动机腹部 | 按真实宽度组织主带或成组路径，在部件转折处展开、终止或接续；保留机械面分工 |
| 翼下 | 用较大的色场、宽带或对角方向形成远看层级，再由较弱边线和局部节奏补充 |
| 后机腹、平尾下方与尾根 | 沿同套方向收束，减少同时争强的装饰；不要留下主翼人物的残片 |

需要比较机腹方案时，让候选改变主路径、宽带展开位置或色场分配；只改变几根细线的曲直，在整机缩图里可能不足以比较构图。固定展示尺寸看主次，再看腹部斜视中的曲面拉伸和部件遮挡。无人物检查、线条构图判断和材质检查分别记录。

## 颜色按职责选择

有指定配色参考时，先保留参考中底色、主色与点缀色的职责和相邻对比，再按当前角色素材验证。自主配色时，从角色服装、头发、装备或作品识别中选主色，再选择承托底色与点缀色。颜色数量和比例按主题与密度决定，不固定套用百分比。

- 底色控制人物与文字的明度关系。浅色衣服需要有对比的承托，暗色人物可由较亮底色、轮廓或局部色面分开。
- 主色承担宽带、主要图形或大区域，使人物色彩延续到机身和尾面。
- 点缀色承担边线、少量节点、细标识或局部转折。强点缀色沿整机分布，但密度和强度不同。
- 相同色相可用较淡、较深或低饱和版本区分宽带与细线。高饱和色大面积使用时，其他区域降低竞争。
- 主字与重要标识用足够明度差建立识别。辅助文字随观看距离降低强度，不让每处都成为主标题。

白底、深底和彩色底都可以成立。指定配色按本轮目标落实；自主配色再匹配新角色的肤色、服装和情绪。颜色贴图中的灰、银或金并不能单独决定金属质感，表面效果另按 [材质处理](materials-and-uv.md) 规划。

从角色原图、可靠设计稿或确认过的颜色贴图取得主题色。飞机截图主要用于观察颜色的职责与相邻对比；高光、环境反射和色调处理会改变可见颜色。只给截图时，比较同一区域在不同角度的表现，把不能确认的原色记为候选，不直接把亮斑、蓝色或金色倒影当成调色板。

在实际整机尺寸同时检查明度、色相和饱和度的分工。局部人物与承托色需要可辨，但主色、副线和细纹不必全部同样明亮。灰度可帮助发现大形和明暗竞争，原色仍决定角色配色与色相关系；不要为了让灰度中每条线都强，把次级线一律改成白色或让所有点缀色争强。

## 编辑与验收

大色面、主路径、边线、细节线、文字和人物独立分层，用当前接口实际支持的形状、笔画或导入图形实现。复杂曲线或字标保留制作源，不虚构编辑器 API。局部 UV 接缝回到对应图层修订，避免水平翻转包含文字的整张图。

多视角投射与侧图包覆并用时，为实际机背、侧面和翼根明确主路径由哪个来源承担，其余来源在边界接续或降低竞争。侧面色场和侧面线条分别决定是否跨到机背，不能凭 `fields-only` 等文件名推断只含底色。复看合并后的真实模型；来源竞争不清楚时，用同相机比较各来源单独存在和合并的结果。分面线稿各自流畅，不能证明合并后仍有主次；重复主轨、反向曲线和密集收尖须在最终承载面解决，不能只删细节层后继续放行。

按顶、底、两侧和斜视逐面检查：机背前中后三段的连接由什么承担；线条是否被曲面拉坏；安静区是否有明确职责；粗细和密度是否有节奏；各个要求的人物尾面是否清楚；机腹与翼下是否混入人物残片；近看细节是否能在最终贴图与实际所检查的 mip 中成立。隐藏细节线后检查大形，隐藏人物后检查背景组织，恢复全部图层再检查竞争关系。明确要求的三档密度逐档另查。

比较层级时保留相同机体、人物、相机与显示尺寸，只改变有明确问题的一项，例如描边线宽、局部对比或某组路径的可见性。描边等宽不会改变填充色带的宽度；隐藏主副线后仍保留的色场与粗字也会继续承担大形。按实际可见内容描述差异，不用图层名称推断画面已经只剩细线，也不预先判定某个对照一定更美。

先确认预计绘制的图层和遮罩实际非空，并检查条件变化确实进入了导出与模型。零越界、零脸部交集可能只是整层没有渲染出来，不能单独作为通过证据。第三方 SVG 栅格化的裁剪或遮罩支持按实际输出核对；修正后重看真实编辑器导出和模型，不能仅修诊断数字。
