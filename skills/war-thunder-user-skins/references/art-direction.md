# 二次元喷气机痛涂的美术判断

## 主视觉与机体

以喷气式飞机的主翼、翼根、机背、进气道、发动机舱和垂尾组织二次元主视觉，承载面按实际机型选择。

选人物素材时同时看脸、肩线、手势、袖子、头发和装备的方向。先圈出真实连续的承载面，再把素材放到该轮廓上判断。主图优先保护脸、头发与颈肩关系；与人设有关的手势或道具进入主视觉时也要保留可读的连接。人物显眼程度取决于模型上能看清的识别特征，不能只用整张图占了多少面积衡量。

狭长表面适合紧凑头像、半身或倾斜姿态；宽翼面可以容纳更多动作。默认保住完整头型、主要发型与头饰，以及让姿态成立的颈肩、肩臂、手或道具连接，再确定远端长发、衣摆和肢体的裁切。关键头饰、头顶或肩臂被裁掉不能仅凭脸大而接受；确有用户指定的局部裁切时按其范围处理。脸与动作连接避开进气道、空隙和会分开的部件，自动可见性遮罩不能替代构图。

人物太小时，比较紧凑素材、位置、旋转、尺度与承载面；放大须同时复核完整头部轮廓与肩臂动态，不能一路裁到只剩五官和零散手。固定整机展示尺寸，再看原生局部与原图：哪里被有意舍弃、哪里被机体硬切必须分清。范围命中、脸没越界和零碎片只用于诊断，不能判定整体识别或美术通过。

需要醒目主视觉，或用户指出人物仍小时，实际并排当前版与明显更大的可行版，固定同一机体、相机和飞机显示尺寸；改变素材裁切、姿态、角度或承载面以取得有意义的尺度差别。先让主人物的脸、头肩与所选动作取得阅读重量，再为它分配图形余量。完整头型是放大的边界，不能成为不断缩小直到轻松命中的理由。主近景与副动作的分工必须在整机上看得出，不把两张近似小胸像或局部放大的展示图当成已满足。

完整场景插画可以使用，但先判断角色、道具、灯光和原背景谁最强。根据目标轮廓裁切、分离或重建场景，让主题仍然清楚。多张人物素材保持有意安排的画风、光感和清晰度关系；Q 版等明显不同的画风作为辅助视觉时明确分工，避免无目的地混贴。

## 用人物动作选择布局

先读人物的动作结构，再决定贴图变换。用简线标出脸、颈肩、手或道具、胸腰、骨盆和膝的关系，区分“用于认角色的部位”和“让这个姿态成立的连接”。靠脸的手、折膝、抱臂或环绕身体的长发可能是动作的原因；只保住脸的范围却删掉这些连接，会把选中的姿态退化为无关头像。没有叙事作用的远端肢体和衣摆可成为可裁的大形。

按人体外轮廓随高度或长度怎样展开，比较它与真实表面的宽窄变化。以下是选图方向，不是必须套用的模板：

| 人物结构 | 可以利用的表面关系 | 先保留的关系与常见代价 |
| --- | --- | --- |
| 头窄、肩袖向下展开的胸像 | 前窄后宽的翼面，脸靠前部安全区，肩胸利用较宽后段 | 脸—颈肩与近脸手势；后缘可裁腰腹，袖端不必全留 |
| 折膝坐姿、回身与环绕轮廓 | 宽翼面中的三角或弧形空间，人体长轴可折回画面 | 肩—腰—膝或手—脸—肩的转折；脚尖、尾巴或远端衣料可出画 |
| 斜卧、抬腿或横向动作 | 具有相应宽度的翼展与后机身，形成两段方向 | 脸胸与主要折点；跨面的腿、衣料可受局部遮挡，但先用斜视确认动作还能读出 |
| 抱臂或收拢上肢的半身 | 翼根与宽后段可承接紧凑体块 | 脸—胸部识别区与抱臂关系；不强求外套和下躯干形成完整封闭轮廓 |
| 举臂、竖向收拢的胸腰或轻斜半身 | 尾面或较窄竖面，身体落向较宽根部 | 头饰—颈肩—胸腰或围头手臂；前缘楔形可留给图形与字，不必把人体硬转成平行后掠边 |

先在预期整机观看方向判断人物的头、身体折线与表面是否协调，再看其他模型视角。atlas 的岛旋转、相机透视、图层刚性旋转分别记录；不能从截图估计角度当作原图层参数，也不要求人物在每个相机画面里都正立。

两翼先服从当前 brief 的表面分工。明确要求双翼人物时，两侧都安排真实立绘，名字不能替代缺少的一侧；未指定时，可比较双翼不同姿态、人物配文字翼、环境或低对比副像。共享明暗、方向与图形语言，并明确对话、补形或叙事关系。低对比副脸可补外角，不用同强度重复大脸填空；五官、完整头型与关键动作保持清楚的阅读顺序。

人物与线条一起定路线：宽肩、举臂、拳或长发可以成为路径的目的地、转折或停顿。顺着动作保留一段安静区，再决定主题线从哪边靠近、在哪一侧退出；不要求所有线都绕成完整人物外框。暗衣可以部分并入深色翼面，亮脸、手、领口或胸饰保持可辨，详细线条关系见 [线条与配色](linework-and-color.md#先辨别看到的是哪一种线)。

人物坐靠、倚卧等动作依赖场景时，先判断局部背景、家具或道具是否提供支撑语境。可保留有用的暖浅场、座面或轮廓，再与机体色场衔接；不要自动把所有背景抠掉，也不要因保留场景而缩小到看不清脸。人物外轮廓可在衣料与底色相近处有意消隐，脸、动作转折和主要服装识别处则要能读出。

评估选图时做一个有实际差别的反事实：保全全身会让脸多小、只保留大头会失去哪段动作、改变角度会把哪部分推到窄面或活动部件。必要时用同一机体、相机和展示尺寸做少量对照。保持脸点和尺度的刚性旋转也会改变脸倾角，须说明这个耦合。几何命中率只用于定位损失，骨架练习只用于验证方向与占位，两者都不能代替真实立绘和整机美术检查。

跨连续表面的主图需在模型上保持人物连接；二维投影中相邻的主翼、平尾、进气道和机身不能当作同一块画布。普通 UV 接缝可通过对齐修复；真实空隙、错层遮挡和会分开的活动面应重新分配构图。别让头部、颈肩、关键手势或主名字横跨这些位置。辅助人物通过尺度、色调与对比分工，不能用技术剪切代替有意裁切。

## 垂尾与机腹

本节给出缺省分工，当前用户与项目约定优先。研究其他作品时记录其实际安排，不用这些缺省反推作者的各个表面。

先按机体确认尾面结构。单垂尾按左、右两面分工，默认两面均安排适配的角色肖像，不把其中一面当作双尾“内侧”省略人物；双垂尾默认各片外侧人物、内侧图形。当前要求可改变这些默认。确认共享 UV 与镜像后，分别规划人物、文字和图形，不能假设每面能保存独立内容。

需要人物的尾面专门选紧凑头像或半身。根据实际梯形或后掠轮廓，在完整头型、主要头饰和颈肩可读的前提下安排尺度与位置，再决定远端长发、衣摆或道具出画。尺寸不合适时比较素材、角度与承载面，不能靠裁掉头顶或头饰放大脸。探针、灯具和凸起按实际模型避让；徽记、号码和边条辅助人物，不替代指定立绘。不要把主翼大图直接缩成整幅缩略图。

先处理人物与尾面底纹的衔接，再做最终裁切。兜帽、发束、披风与肩线可以成为色面边界；相邻主线顺着这些外轮廓绕开五官，在衣摆或尾根处接入整机路径。原图矩形裁边仍清楚时，按服装与发丝轮廓分离人物、用局部色面嵌合或调整遮挡，避免把一张小胸像放进硬框就结束。外围可以延伸后再有目的地舍弃，不把整张透明图完整命中尾面作为缩放目标。编辑器抠图、裁切与图形组合可以完成这些操作；可用的图像模型也可辅助延展，但衍生五官与服装变化需复核，不能声称原画逐像素保留。

尾面按一张完整构图验收。隐藏人物，在实际尾面与整机尺度下检查浅深色场、中段、斜前缘与尾根如何接续；恢复人物后看这些关系怎样承托头肩、发束或衣料。大浅色楔区只有机械板缝、装饰全部挤到深色边缘时，先改浅场边界、可读的中尺度主题形或线组，再加细节。完整肖像加边缘几根线不能单独关闭尾面设计；不强迫每块区域画齐三档，也不为填空给五官附近增加竞争。

比较尾面素材时固定机体、相机和整机展示尺寸，并放回当前整机的配色与线条上下文，先看脸、发型与关键头饰能否辨认，再放大尾面检查边缘和裁切。大幅放大的尾面局部不能证明整机观看时的人物足够显眼。完整动作图覆盖的像素可能更多，但脸部仍小于紧凑头像；选择依据是实际识别与构图，不是素材总尺寸或遮罩命中量。

将主动裁切、原图已有缺失、抠图损伤与机体结构遮挡分别判断。用户允许舍弃局部时，可以有目的地留下头像或半身；先确定本角色要保留的完整脸部识别、发型、耳角/头饰、颈肩关系或关键道具。保住局部眼睛的范围检查不代表裁切后的整张脸与身体关系成立。原图已被裁掉的部分不能称为已保全或已恢复；保留哪些特征按任务和实际角色识别决定，不把所有局部裁切一律视为失败。

尾面左右、双尾各片的内外均以机体方向确认。斜视里看见的双尾远侧面常是内侧，不能凭它朝向镜头决定面别。反向斜视或单独部件预览用于核对各面的既定职责；主侧视不能证明所有尾面已经完成。人物与活动舵面发生可见割裂时移动到固定面或采用更紧凑的裁切。

机腹与主翼下表面默认不放角色立绘，用主色场、长路径、中等边线、分段节奏与局部材质组织。机腹配色来自整机主题，按进气道、发动机腹部、中央通道和翼下的形状转折；机械刻线作为原细节保留。用户有明确的其他布局要求时按当前要求调整。

## 大形、中等图形与细节

先安排大色面、宽带、曲面或切面，明确机首、翼根、机背和尾面的连接。隐藏小字和细纹后，主视觉与机体走向应仍然成立。再增加中等纹样，最后补近看细节。

整机痛涂需要给各个可见表面安排职责。较安静的前部、机腹或连接面，用颜色、边界、路径和局部标识延续主题。机背单独检查座舱后段、翼根展开区和后机身，不把两条很细的边线算作整个机背已经有了组织。图案密度可以不同，覆盖范围按需求决定。机械面、刻线和材质等级单独处理，避免把结构噪声一律叠到人物脸和主字上。

整机连接可由色场、人物、文字与路径承担，但用户明确要求的三尺度线条须实际出现：主路径组织方向，中等轮廓处理分流与边界，细线用长短、间隔和渐细退场形成节奏。按座舱后、翼根、后机身及指定面检查，不能以宽色带或“无需每面画齐”为由免除要求。未指定密度的任务才按实际主次选择稀疏程度。见 [线条与配色](linework-and-color.md)。

层级可以由大色面边界、宽带、图案明度和局部密度共同形成。不要把“补机背线条”执行成所有区域添加同样的空心框、三角和短划线。先选与主题相关的主导形状，让各段有展开、停顿与收束，再保留人物和主字附近的安静区。隐藏细节后仍能读出连接关系，才继续添加近看纹样。

人物、文字、背景看起来像彼此孤立的贴纸时，先重排它们的方向、距离、形状嵌合和遮挡。增加小标、磨边或输出更大贴图，不能修复这些关系。

## 文字参与构图

文字量和语言先服从当前要求；主名字、标识与小字均为可选。减少文字时直接删去重复信息，不用许多小字补满空白。选择字形时看外轮廓、字重、宽窄、间距和角度，让它与人物、翼缘或色面呼应；默认正文或系统字体的直接放大不能自动成为合适的字标。需要时比较少量实际字样，按整机观看效果选入。分别安排主名字、身份字、编号和细注释的观看距离与强度。中文书法、装饰字、衬线、手写和无衬线按主题选择，避免所有主题使用同一类标签。

文字保留可编辑文字层。复杂字标可以使用独立图形素材，保留来源和制作源；栅格化字标的可编辑范围要如实说明。检查实际模型上的方向、遮挡和可读性，不能只按 atlas 的朝向翻字。

## 纹样与主题

从服装、装备、徽记、身份或场景中选择相关纹样，再组织方向、粗细、间隔、大小和局部强弱。需要中等图形时确定主要一组，其余装饰降低强度；人物、色场或字轨已经承担其职责时不为凑档次新增纹样。语义准确只是起点，图形仍需要服务构图。

柔色角色主题用实边人物承接柔纹、色洗或渐变，保持脸与主字的识别。装备或机械元素较强的二次元主题，用大切面、字形和设备图组织，网格、三角和技术字放到次级。二次元赛车、演唱会等信息较多的主题，先用大色场组织，再分配号码、标识和点阵密度。

配件以同套颜色、宽带、编号、徽记和材质等级接续主体。是否增加人物、文字或更多装饰，由配件面积和观看距离决定。

## 审稿与修订

先用低成本模型预览看顶底、两侧和能显示遮挡的斜视，再投入完整细节。整机展示尺寸检查人物识别、垂尾角色、主字与机背路径；原生局部检查轮廓、接缝和图层边缘。机腹及翼下按最终贴图检查无人物要求，未显示或被遮住的部位保留未检查状态。

有用户指定的质量基线时，以相同观看尺度对照人物完整、双翼或其他指定覆盖、粗中细节奏、图文嵌合与表面质感。消除裂缝、增大色块或调整R/B不代表已达到该基线。独立审查需指出实物位置与不足；被用户和实物否定的结论按漏检复盘，不能用多数肯定替代修订。

在同一整机视图里同时看人物、色场、文字和线条，按可见问题修对应层：

| 可见问题 | 优先调整 |
| --- | --- |
| 人物太小或放大后头发、头饰、肩臂被硬切 | 比较更适合的原图、尺度和位置，同时保住完整头型与动态；脸部放大不能抵消整体损坏 |
| 脸、颈肩或关键动作被结构切开 | 先改姿态、裁切、尺度或承载面；明暗调整不能修复人物连接 |
| 人物与相邻色场难以区分 | 检查局部承托、边界与附近纹样强度，保留角色配色；不要直接把整机调成高饱和或统一加粗描边 |
| 大浅色板与人物、深色线组各自孤立，内部只有刻线 | 回到浅深边界、主题中形与路径连接；先在整机缩图中组织承托和方向，再补细线，不能只凭“留白有职责”的文字说明放行 |
| 大字、边线和细标都争强 | 明确主视觉，调整竞争图层的尺度、线重、对比或密度，保留有目的的安静区 |
| 隐藏人物或细节后没有主路径 | 返回大色面与中等图形的连接，先组织方向再补细纹 |
| 高光下脸或文字被冲淡 | 在同一光照下比较色图与材质作用，再按区域处理表面反射；不要用整体加深 RGB 掩盖材质问题 |

灰度或近似明度视图可辅助检查明暗主次，不能单独决定配色优劣。回到原色看色相分离、角色识别色和主题情绪；灰度中弱一些的副线可能正符合原色里的次级职责。诊断图的转换方式、截图光照与色调处理均可能影响结果，不把数值或滤镜结果作为自动评分。

记录“视角与位置 → 可见问题 → 对应图层或素材 → 修改后复看”。按反馈调整相关层，保留已经接受的部分。技术检查、设计自评和用户验收分别记录。
