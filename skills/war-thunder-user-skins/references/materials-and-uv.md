# 喷气式飞机的资源、UV 与材质

## 从配置确定资源

读取目标 BLK，列出 `from → to → 用途 → 尺寸与通道`。用途由游戏资源、配置和实际模板确定，作者文件名不能代替判定。保留 `name:t="user"` 和资源名所需的 wildcard。改型兼容性核对部件、材质分组和 UV。

自制本地贴图必须有真实包内文件。现有配置缺少字面目标时，核对引擎默认资源、损伤状态、可选配置和扩展部件，记录受影响的范围。重复或冲突映射按待验证问题处理。

沿用目标喷气式飞机模板的颜色与打包材质资源映射，按对应 `replace_tex` 替换真实贴图。改变映射方式时一起检查颜色 alpha。以当前飞机模板为准，并按需查阅 [Gaijin 技术说明](https://wiki.warthunder.com/cdk/creation_camo)。

## 原 UV 与基底

保留原 UV、画布比例、部件变换和材质分组。标明接缝、镜像、复用纹素和跨部件区域。两个共享同一纹素的表面不能通过 BLK 获得独立像素；通过统一图案、调整位置或投射优先级解决冲突。

原 UV 约束归一化坐标、岛关系与画布比例，不要求终稿沿用原贴图的像素尺寸。按预期近景中人脸、文字和最细线实际分到的 UV 纹素选择 4K／8K 等尺寸，分别检查原素材、正交源稿和最终 atlas 的有效细节；整机七视图的显示尺寸不能代替近景清晰度验收。提高分辨率时，从原 PNG、矢量与文字源重建对应源层及 atlas，并同比更新相机、位置和遮罩，保持布局与原 UV 不变。用同一模型位置和源图坐标读取新旧实际输出，确认眼线、字形或线端确有细节增加；旧成图插值放大、锐化或文件头写为 8K 均不能作为重建证据。

模板可能包含纯色或常量材质占位图。看通道 min/max、方差和局部结构，确认是否有真实细节。常量模板可提供资源名和尺寸，结构及材质基底从实际资产或 CDK 输出核对。

先区分保留原皮、局部改绘和重新喷涂的目标。需要干净新底色或完整换主题时，在实际重涂区域去除不需要的原迷彩、标记、脏污、磨损及烘焙明暗；保留原 UV、法线和必要机械区，不等于保留原 diffuse 图案。需要的面板、铆钉或结构细节单独选取、限制强度与区域，不能让旧涂层纹理透过新底色，也避免将整张原皮用 Multiply 覆盖人物和主字。比较误差时使用真实 UV 覆盖区，并看通道分布和局部图案。

编辑图层透明度与颜色贴图 A、材质 A 分别处理。主体重涂层按覆盖目标决定不透明度，抗锯齿边缘与有意的透明效果可以使用连续 alpha；不将固定半透明涂层作为通用方法。添加人物和装饰前，在实际模型上先检查仅有底色的版本，再恢复图文。清洁底色仍有旧图案时先修基底，不能用装饰遮住。

干净度按来源隔离：平光布局中仍有旧色纹先查 RGB；只在受光中出现的纹理，再固定其他条件分别查 R/B、法线与真实几何。法线可能同时含机械结构和旧漆剥落、裂纹或旧图案压痕，不能因位于 G/A 就全部保留；强幅或边缘检测命中也不能单独证明是面板、铆钉；宽浅色涂层出现块状反射时，实际复看该部位的中性 G/A／关闭法线对照，把不规则旧涂层凹凸与已确认的窄结构分别处理。违反新漆目标的旧涂层凹凸按明确遮罩移除或重建，核验域外数据。压平法线后仍存在的真实几何结构，不能作为旧皮污染一并抹掉。主动设计的新主题纹样可保留，但需说明来源、区域、尺度与对比职责；不以全域零方差否决有意纹样。

关闭法线后斑纹消失，只证明法线参与了成像，不能单独证明源 G/A 存在应删除的旧漆。回读实际受影响位置的 UV、通道与遮罩；已中性重建的区域仍有块带，或极小法线扰动引起突跳时，先检查近似预览的环境连续性、采样与数值稳定性。同版本环境中比较原材质、候选和关闭法线结果，排除预览伪影后再决定是否修改真实 N。不能反调法线或抹掉结构来抵消离线积分误差；发现误诊时撤回由其支撑的材料失败结论，保留正确原数据。纹理数值有变化、候选改动像素更多都不能代替可见缺陷及其来源证据。

## 通道与格式

| 数据 | 处理原则 |
| --- | --- |
| 颜色 RGB | 保存图案、配色、文字及需要的表面细节 |
| 颜色 A | 按映射与着色器核对覆盖语义，默认保留 |
| 打包材质 R | 核对当前 inverted roughness，按需编辑 |
| 打包材质 G/A | 以已确认法线为基底，分别处理；区分机械结构与不应保留的旧涂层凹凸 |
| 打包材质 B | 按表面分区处理金属度 |

通道布局以目标着色器和当前技术规范为准。旧材质转换只在确认源语义后执行，不因文件年代不明重复转换。以已确认的打包材质为基底。图案没有改变对应表面分区时可沿用；人物或装饰移动、缩放、裁切后，若材质包含旧图案的印刷或金属遮罩，同步修正受影响区域，避免新脸落到旧银边材质、旧人物位置仍保留印刷质感。改变光泽或金属效果时，按区域编辑相应数据通道。

沿用材质不关闭既有外观失败。“材质已验证”须说明是文件身份、通道语义、数据保持，还是当前目标下的外观；N 字节未变、G/A 保持或导出往返一致，只能关闭对应数据检查。光泽、发白或图案冲淡尚未解决时，继续单列该项失败，不能由颜色分辨率提高继承通过。

RGB 预览先去除 alpha 再缩图；alpha 单独看，黑 alpha 中仍可能有颜色数据。数据贴图按独立通道缩放，避免预乘 alpha 和普通摄影调色污染数据。灰度通道显示图用于诊断，生产组装使用经过确认的数据。

DDS 核对真实编码。需要连续 alpha 或四通道打包材质时选择能保存对应通道的格式。实际转换格式后再改配置扩展名。保留原比例，检查 mip 和局部细节；高低清输出各自完整包。颜色 RGB、颜色 alpha 和材质数据使用各自的过滤语义，按 [DDS 与实际 mip](packaging-and-validation.md#dds-与实际-mip) 另建版本并回读实际文件，不用普通缩图冒充 mip 检查。

`scripts/compare_skin.py` 按 BLK 选择实际使用贴图，比较独立通道；可传真实颜色、材质与 UV 遮罩。数值诊断不代替着色器效果，也不用于自动美观排名。

## 先区分表面类型

颜色相近的两个区域可以有不同质感；有明显高光的表面也可能是亮漆。先确定表面属于涂层、印刷、装饰金属还是机械裸金属，再决定数据通道。几何不连通、节点名或未命中主体选区，不能单独判为保留原漆的机械面；用实际可见表面与部件职责确认，外露可重涂罩壳进入对应新涂层域。截图中的灯光、环境反射和色调处理不能反推出作者原参数。

| 目标表面 | 颜色与材质的分工 |
| --- | --- |
| 亚光或较柔和的主题涂层 | 颜色承担主题；控制较宽柔的反射并检查是否冲淡人物与文字，金属度按实际涂层处理 |
| 亮漆 | 通过粗糙度相关通道取得较清楚的高光，通常仍按非金属涂层处理；不能因为发亮就提高全部金属度 |
| 抛光或缎面金属 | 金属度与粗糙度配合，颜色作为金属表面的颜色依据，原有凹凸继续参与光照 |
| 金属边条、字标或局部装饰 | 用对应 UV 遮罩限制效果，与相邻涂层形成局部反射差；保留文字和人物的阅读优先级 |
| 喷口、热区及其他机械面 | 保留经确认的原材质差异，按具体需求局部调整，避免跟随装饰底色一起统一填值 |

人物和关键字标需要在预期光照下清楚。表面高光冲掉脸、眼睛或主字时，缩小强反射区域或调整该区域的粗糙度，不能靠加深整张颜色图掩盖。需要特殊金属人物效果时单独制定方案并检查可读性。

## 分区编辑与数据保持

在设计记录中列出“部位 → 目标质感 → 遮罩 → 修改通道 → 验证方式”。遮罩覆盖真实 UV 岛，注意共享纹素、接缝、两面和不同资源；不要让未使用的 atlas 像素影响材质面积判断。

材质分区优先来自人物、涂层、金属边条和机械区域的语义图层或明确的区域遮罩。相近 RGB 可能同时出现在灰色头发、白色衣服、普通印刷和银色装饰中，不能只凭颜色接近就把它们自动归为同一金属度。颜色阈值用于辅助建立遮罩时，再检查真实区域与边缘混色，尤其保护脸、眼睛、文字和服装的材质职责。通道保护域与图案可放置域分别声明；保留结构法线的保护遮罩可能含可涂装外壳，不能仅据其名称当成 R/B 禁印或人物裁切域。

以当前目标飞机的已确认材质为基底。人物位置、尺寸或裁切变化后，从实际新图层导出语义遮罩，检查新印刷区、被腾出的旧印刷区和底下的装饰区域；只修正受影响范围及对应 R/B，不把整张材质直接套回去。改变光泽时处理 R，改变金属度时处理 B；没有明确凹凸设计且未发现不应保留的旧涂层凹凸时保持 G/A。参考数据只能用于判断关系，不把别人的全图主值当成新作的统一配方。输入如果是普通 roughness 或旧 smoothness，先核对目标编码，不能直接照贴或重复转换。

确认目标 R 使用 inverted roughness 后，较高值趋向更光滑、较集中的高光，较低值趋向更粗糙、较宽的反射。数值与肉眼亮度不是简单线性关系；较粗糙的宽高光也可能冲淡脸，较光滑的表面在另一个角度又可能出现强反射，不能把“更亚光”当作必然更清楚。从正确基底在相同条件下对照，再换受光方向复看，不把截图亮度直接换算成 R/B 的 0–255 数值。

用局部试片比较反射强弱，再确定目标范围。保真组装阶段检查已声明保持的 G/A 及修改遮罩外区域保持原数据；输出 DDS 发生重编码时，再检查通道变化和细节损失。镜面、柔亮或拉丝等视觉目标均受现有着色器能力限制，普通四通道贴图不能自行添加新的着色模型。

颜色 RGB 的面板／涂层细节、R 的空间变化、G/A 的法线数据与渲染器实际使用法线分开验。保留机械或旧涂层质感时，统一填值可能抹掉需要的差异；设计干净新漆时，则应替换不需要的旧涂层噪声和磨损，不强制混入原 R。按新涂层、印刷、边条和机械区分别比较反射，决定哪些变化保留、弱化或重建，参数只适用于当前表面和条件。保留 G/A 字节不证明预览已显示铆钉和面板凹凸，也不要求原 diffuse／R 纹理全部保留。同尺度局部与整机分别复看，不能把反射更强或原数据保留更多当作质感高级。

编辑器输出独立 8-bit 灰度通道，使用 `build_skin.py --channel` 对精确 `from` 资源进行组装。颜色 alpha 与材质 A 的职责不同；材质 A 是法线数据，不能作为编辑图层透明度清除。

## 装饰凹凸与表面细节

金属压纹、刻字、镶边或较明显的装饰纹样，需要单独规划凹凸效果。先将装饰的高度或法线素材与原机结构分开，使用实际可用的法线生成与合成工具，并核对目标方向和通道编码。G/A 保存法线分量，不能把普通灰度高度图直接当作两个法线通道，也不能用普通颜色相加代替法线合成。

控制装饰凹凸的幅度、区域和尺度，避免所有细线都变成粗重沟槽。保留原刻线、铆钉和机械面的作用；脸、衣服和主字是否需要压纹由具体设计决定。对原法线做明确修改时，校验修改范围、遮罩外数据及不同受光方向的表现，记录哪些变化是设计意图。

## 质感检查

用相同视角、光照和环境对照调整前后，再改变观察方向，检查反射是否随曲面与环境变化。主涂层、金属边条、机械面应有明确分工，避免整机被统一处理成塑料亮面或镜面。

需要区分粗糙度与金属度的作用时，固定 RGB、几何、相机和光照，选择明确的 UV 区域做对照：先在金属度不变时比较粗糙度相关通道，再保持该设置比较金属度。人物印刷、机械面和法线数据可作为保持一致的对照区。普通图案修改不必展开这组试验；只有材质需要或效果不明确时使用。

相同 RGB 不保证受光后看起来是同一种色彩。先按目标表面类型判断反射，再检查它是否压过人物、主字或线条层级。需要特殊金属人物效果时，单独选择相应印刷区域，不因整机试片更闪亮而把所有角色、文字和机械区一起改值。试片参数只用于当前基底与渲染条件下的比较，不能当作其他机型或角色的统一配方。

颜色图里画出的高光和银灰渐变可能是图案；它们不证明实际表面反射。近似漫反射布局预览可检查线条和覆盖，不能验收金属度或粗糙度效果。使用近似材质预览时注明近似范围；未用目标着色器验证的实际光泽保持未验证状态，并遵守项目的游戏启动约定。

近似材质预览中已观察到的发白、高光吞图或表面分工丢失，按该环境记录失败，并区分可能来自数据、光照环境和着色器假设的原因；“与游戏不同”本身不能将观察到的失败改为通过，也不能据此盲调真实材质去匹配代理渲染器。局部单变量实验须实际覆盖投诉的印刷或涂层区域；只改饰条 R/B 不验证人物印刷的响应。核对目标着色器的解码、数值重映射、法线轴序和颜色空间，通道名称相同不证明参数响应相同；仅翻转直接光而保持环境反射与色调映射不变，不算不同完整环境的验证。

公共多材质场景按 [整机场景](orthographic-workflow.md#多材质整机场景与补充相机) 准备，以 `scene_preview.py render --scene scene.json --view iso --mode material --out material-view.png` 输出近似 GGX 对照。比较时固定 `lighting`、RGB、几何和相机；复看再明确换光照。R 解释 inverted roughness，B 解释金属度。

需要比较两个完整受光环境时，使用 `finish_preview.py --scene scene.json --profile generic --environment outdoor --view iso --out outdoor.png`，再保持场景、相机和尺寸，改为 `--environment studio --out studio.png`。它同时改变环境辐射场及直接光，保存实际配置与输入指纹，不依赖任务私有的源码替换。`--size` 指定长边并保留相机比例，`--normal-off` 仅用于同条件隔离诊断；沿用场景显式法线约定，不自动改轴序。

`--profile` 必须明确选择。`generic` 按 R 反粗糙度、B 金属度解释；已确认与固定公开 `dynamic_masked_chrome_bump` 路径相符时，可选择 `dynamic_masked_chrome_public`，仅对精确匹配且绑定 packed 的材质应用相应 B 重映射与来源 BRDF。其他材质继续用通用近似；该选项不证明当前游戏编译 shader 的身份。旧 `scene_preview` 固定工作室近似与这些环境不等价，不能用两者的亮度差直接修改真实 N，或把一份工具的观察冒充另一份工具的验收。

法线仅在 material 模式显式启用。材质记录与 prepare 覆盖支持 `normal_convention: none`（默认）或 `ag_xy`／`ga_xy`／`rg_xy`，`normal_strength` 为 0–4、默认 1，`normal_y_sign` 为 ±1、默认 +1。可给含 `path`／`sha256` 的 `normal_texture`，否则读取已绑定的 packed。轴序、符号按目标资源与具体 shader 证据确认，不从文件名猜测；更具体的源 shader 只能提供参考，当前游戏编译版本未核对时仍记未验证。

查看输出 `normal_mapping` 的配置及退化 UV 回退数量；启用标志不证明目标面可见或已呈现细节，仍需固定 RGB/R/B、相机与光照做 normal-off/on 实物对照。当前 TBN 从原 UV／几何派生，处理镜像手性，退化处使用几何法线；不宣称匹配游戏导出的切线。layout 和省略／`none` 的材质模式保持原行为。额外 tiled/detail normal、游戏环境、阴影、AO、透明度及运行时 mip／各向异性仍未模拟，代理材质也不代替真实资源验证。
