# 喷气式飞机的资源、UV 与材质

## 从配置确定资源

读取目标 BLK，列出 `from → to → 用途 → 尺寸与通道`。用途由游戏资源、配置和实际模板确定，作者文件名不能代替判定。保留 `name:t="user"` 和资源名所需的 wildcard。改型兼容性核对部件、材质分组和 UV。

自制本地贴图必须有真实包内文件。现有配置缺少字面目标时，核对引擎默认资源、损伤状态、可选配置和扩展部件，记录受影响的范围。重复或冲突映射按待验证问题处理。

沿用目标喷气式飞机模板的颜色与打包材质资源映射，按对应 `replace_tex` 替换真实贴图。改变映射方式时一起检查颜色 alpha。以当前飞机模板为准，并按需查阅 [Gaijin 技术说明](https://wiki.warthunder.com/cdk/creation_camo)。

## 原 UV 与基底

保留原 UV、画布比例、部件变换和材质分组。标明接缝、镜像、复用纹素和跨部件区域。两个共享同一纹素的表面不能通过 BLK 获得独立像素；通过统一图案、调整位置或投射优先级解决冲突。

模板可能包含纯色或常量材质占位图。看通道 min/max、方差和局部结构，确认是否有真实细节。常量模板可提供资源名和尺寸，结构及材质基底从实际资产或 CDK 输出核对。

颜色、材质分区和凹凸独立保留。结构线只在需要的区域参与画面，避免将整张原皮用 Multiply 覆盖人物和主字。比较误差时使用真实 UV 覆盖区，并看通道分布和局部图案。

## 通道与格式

| 数据 | 处理原则 |
| --- | --- |
| 颜色 RGB | 保存图案、配色、文字及需要的表面细节 |
| 颜色 A | 按映射与着色器核对覆盖语义，默认保留 |
| 打包材质 R | 核对当前 inverted roughness，按需编辑 |
| 打包材质 G/A | 保留法线 X/Y 的细节，分别处理 |
| 打包材质 B | 按表面分区处理金属度 |

通道布局以目标着色器和当前技术规范为准。旧材质转换只在确认源语义后执行，不因文件年代不明重复转换。只改图案时保留原打包材质；改变光泽或金属效果时，按区域编辑相应数据通道。

RGB 预览先去除 alpha 再缩图；alpha 单独看，黑 alpha 中仍可能有颜色数据。数据贴图按独立通道缩放，避免预乘 alpha 和普通摄影调色污染数据。灰度通道显示图用于诊断，生产组装使用经过确认的数据。

DDS 核对真实编码。需要连续 alpha 或四通道打包材质时选择能保存对应通道的格式。实际转换格式后再改配置扩展名。保留原比例，检查 mip 和局部细节；高低清输出各自完整包。

`scripts/compare_skin.py` 按 BLK 选择实际使用贴图，比较独立通道；可传真实颜色、材质与 UV 遮罩。数值诊断不代替着色器效果，也不用于自动美观排名。

## 先区分表面类型

颜色相近的两个区域可以有不同质感；有明显高光的表面也可能是亮漆。先确定表面属于涂层、印刷、装饰金属还是机械裸金属，再决定数据通道。截图中的灯光、环境反射和色调处理不能反推出作者原参数。

| 目标表面 | 颜色与材质的分工 |
| --- | --- |
| 亚光或较柔和的主题涂层 | 颜色承担主题；较宽柔的反射减少对人物与文字的干扰，金属度按实际涂层处理 |
| 亮漆 | 通过粗糙度相关通道取得较清楚的高光，通常仍按非金属涂层处理；不能因为发亮就提高全部金属度 |
| 抛光或缎面金属 | 金属度与粗糙度配合，颜色作为金属表面的颜色依据，原有凹凸继续参与光照 |
| 金属边条、字标或局部装饰 | 用对应 UV 遮罩限制效果，与相邻涂层形成局部反射差；保留文字和人物的阅读优先级 |
| 喷口、热区及其他机械面 | 保留经确认的原材质差异，按具体需求局部调整，避免跟随装饰底色一起统一填值 |

人物和关键字标需要在预期光照下清楚。表面高光冲掉脸、眼睛或主字时，缩小强反射区域或调整该区域的粗糙度，不能靠加深整张颜色图掩盖。需要特殊金属人物效果时单独制定方案并检查可读性。

## 分区编辑与数据保持

在设计记录中列出“部位 → 目标质感 → 遮罩 → 修改通道 → 验证方式”。遮罩覆盖真实 UV 岛，注意共享纹素、接缝、两面和不同资源；不要让未使用的 atlas 像素影响材质面积判断。

以当前目标飞机的已确认材质为基底。改变光泽时处理 R，改变金属度时处理 B；没有明确凹凸设计时保持 G/A。参考数据只能用于判断关系，不把别人的全图主值当成新作的统一配方。输入如果是普通 roughness 或旧 smoothness，先核对目标编码，不能直接照贴或重复转换。

确认目标 R 使用 inverted roughness 后，较高值趋向更光滑、较集中的高光，较低值趋向更粗糙、较宽的反射。数值与肉眼亮度不是简单线性关系；从正确基底逐步对照，不把截图亮度直接换算成 R/B 的 0–255 数值。

用局部试片比较反射强弱，再确定目标范围。保真组装阶段检查 G/A 及遮罩外区域保持原数据；输出 DDS 发生重编码时，再检查通道变化和细节损失。镜面、柔亮或拉丝等视觉目标均受现有着色器能力限制，普通四通道贴图不能自行添加新的着色模型。

编辑器输出独立 8-bit 灰度通道，使用 `build_skin.py --channel` 对精确 `from` 资源进行组装。颜色 alpha 与材质 A 的职责不同；材质 A 是法线数据，不能作为编辑图层透明度清除。

## 装饰凹凸与表面细节

金属压纹、刻字、镶边或较明显的装饰纹样，需要单独规划凹凸效果。先将装饰的高度或法线素材与原机结构分开，使用实际可用的法线生成与合成工具，并核对目标方向和通道编码。G/A 保存法线分量，不能把普通灰度高度图直接当作两个法线通道，也不能用普通颜色相加代替法线合成。

控制装饰凹凸的幅度、区域和尺度，避免所有细线都变成粗重沟槽。保留原刻线、铆钉和机械面的作用；脸、衣服和主字是否需要压纹由具体设计决定。对原法线做明确修改时，校验修改范围、遮罩外数据及不同受光方向的表现，记录哪些变化是设计意图。

## 质感检查

用相同视角、光照和环境对照调整前后，再改变观察方向，检查反射是否随曲面与环境变化。主涂层、金属边条、机械面应有明确分工，避免整机被统一处理成塑料亮面或镜面。

颜色图里画出的高光和银灰渐变可能是图案；它们不证明实际表面反射。近似漫反射布局预览可检查线条和覆盖，不能验收金属度或粗糙度效果。使用近似材质预览时注明近似范围；未用目标着色器验证的实际光泽保持未验证状态，并遵守项目的游戏启动约定。
