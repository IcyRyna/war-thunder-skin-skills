# 二次元喷气机的图像辅助编辑

仅在本次任务需要、且环境具有对应能力时使用图像模型。用户指定的工具、原图和修改路线优先；其他情况按素材与目标选择局部改色、抠图、修边、光影调整、独立装饰或布局草案。

## 能力与输入

检查实际工具 schema，区分纯文本生图、原图编辑、遮罩编辑、透明输出及模型选择。按当前接口传入已查看的图片，遵循其路径／附件引用、遮罩语义和输出参数；不固定供应商、模型名、本机脚本位置或历史参数列表。

精确版本要求通过真实模型参数落实；工具不提供该信息时记录未确认，提示词中的模型名不构成切换。缺少必要能力时，使用 [现有素材与编辑器](assets-and-layout.md#原图适配与边缘) 完成可行部分；确有会改变作品的能力缺口再说明。

## 修改范围

- 保留原文件，每次编辑另存。说明各输入是主体、色板还是效果参考。
- 写清允许改变的区域及保持项：角色身份、五官、姿态、身体比例、手指、服装剪裁、装备和原画风格。一次优先解决一个主要问题。
- 需要透明素材时检查真实 alpha，并在深浅底看边缘。输出尺寸、裁切和位置以实际文件为准。
- 提示词与遮罩不保证逐像素保留。需要严格保护的部位由编辑器从原图合成，只采用通过检查的生成区域。

局部改色可写成：“编辑输入立绘，仅将已指出的外套衣料改为本方案目标色，保留褶皱和明暗；其余角色特征与姿态保持。”区域、颜色及其他允许变化须依据已看原图填写，不附加无关重绘。

## 导入与验收

原图与结果同尺度并排看身份、动作、线稿、色彩角色及多余元素。失败回到对应局部修订，通过后导入独立栅格层，保留输入、实际工具／模型、参数和结果关系。

文字重建为文字层，线条与重复图形保留可修改的制作源，见 [编辑工作流](editor-workflow.md)。模型生成的飞机草案只作方案；实际 UV、遮挡和模型预览继续使用真实几何。画出的反光也不替代 [材质通道](materials-and-uv.md#通道与格式)。
