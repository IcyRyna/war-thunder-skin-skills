# Akamywek 风格配方

**先读 [基本布局](references/base-layout.md)。** 每架涂装分两个阶段：第一阶段照作者的 F-2A 做基本布局，不放立绘；用户认可后，第二阶段才放立绘。用户的原话是“先学会走路再学会跑，先把这个 F-2A 的基本布局学透，再提放立绘”。

本 skill 单独就能做完一架涂装。风格文件（配色、图形、各面布局、字与标识）决定"长成什么样"；素材、原 UV、材质、工具、打包和验收按 [通用制作流程](references/core/overview.md) 执行，它的 [审美基线](references/core/aesthetics.md) 是风格文件没写到时的底线，冲突时以风格文件为准。脚本都在 `scripts/`，先用 `--help` 看参数。配方提炼自该作者 17 个公开作品的整机预览、5 个原包的 8K 颜色贴图和材质贴图（双发侧卫、单发 F-16 系、三角翼），是方法归纳，不是作者授权或复制他的作品；不要照搬他的字、徽记和具体图形。

## 先选分支

| 分支 | 何时用 | 一句话 |
| --- | --- | --- |
| **深底·饱和签名**（默认） | 角色识别色饱和：红、品红、橙、金、紫、饱和蓝（如陈千语 #3f7fc0） | 炭底上，签名色做第二大面，白色做尖形序列 |
| **深底·浅色签名** | 角色识别色发白或很浅：白、银、冰蓝、浅青 | 炭底上，白或浅灰做第二大面，签名色只做细线和淡染 |
| **浅底**（证据不足） | 用户要明亮机身，或角色整体很暗 | 白/浅灰底，人物铺满翼尾，签名色细线沿边；不做白色尖形。只看过少数早期作品的截图，没有实测贴图，用前先研究参考 |

用户没指定时用深底。分支看签名色的饱和度，不看冷暖：饱和的蓝和红一样走第一种；判断不准时，用 `atlas_palette.py` 看签名色是否属于 vivid。

## 制作顺序

### 第一阶段：基本布局（不放立绘）

1. 读 [基本布局](references/base-layout.md)，把 F-2A 的部位职责对应到本机型：签名色两大块在哪里、白色焦点放哪里、翼尖条纹、平尾或鸭翼前缘带、垂尾序列、侧面文字道。
2. 读 [配色](references/palette.md)，从角色原图取签名色、色阶和底色，写出色表；面积按 [基本布局](references/base-layout.md#整机只有两大块) 的俯视比例定。
3. 落笔前先对设计稿的图表跑 `surface_map.py`，看每块表面哪里平整、哪里弯折、哪里被别的表面盖住或被前面的图表抢走 UV（见 [线条与配色](references/core/linework-and-color.md#落笔前先看表面分区)）。
4. 按顺序落笔：先两大块色场，再白色焦点（[线条与图形库](references/motifs.md) 的嵌套 V），再翼尖条纹、前缘带、垂尾序列，最后细线和字（[字与标识](references/type-and-decals.md)）。每个元素的宽度取 [尺寸阶梯](references/base-layout.md#尺寸阶梯) 的一档。用 `vector_paint.py` 在原 UV 上直接出图层；示例设计稿在 `examples/`。作者是在原 UV 展开图上画直线的：机背这类展开的蒙皮岛先用 `uv_frame.py` 建框架，图表写 `frame` 和 `island`，图形用 `arrangement.py` 的构造线切出来；学作者、复刻图形前先读 [原 UV 作画与逐组复刻](references/core/uv-native-replica.md)。
5. 质感只有签名色面内的三角马赛克。不画面板线和铆钉（F-2A 没有）。漆面用 `coat_material.py` 做整机一层亮漆（深底 R 173、B 0，白底 R 228、B 56，法线压平）；主体颜色图 8192²。见 [漆面](#漆面)。
6. 出图前跑 `design_lint.py`，按 [审美纠偏](references/core/taste-corrections.md) 和下文的[常见跑偏](#常见跑偏)修掉报出的问题。出图后再跑一次 `surface_map.py`，`risky_items` 和 `seam_items` 清空或逐条确认；再给每个区域开近景相机看模型。
7. **原尺寸检查**：在 Composa 里打开 8192 颜色图，用 `detail_sheet.py` 按 1:1 截取每个部位，和作者 F-2A 同样米制比例的截图并排看（方法见 [原尺寸检查](references/core/packaging-and-validation.md#原尺寸检查)）。边缘不干脆、粗细不一、有锯齿或断线，就回到设计稿改，不能只看缩小的预览图。
8. 按 [基本布局验收](references/base-layout.md#验收基本布局阶段) 逐条对，交给用户看。

### 第二阶段：放立绘（基本布局被认可后）

9. 读 [各面布局](references/surfaces.md) 的人物部分，决定立绘放在哪里、替换基本布局里的哪一块；基本布局的两大块、白色焦点和尺寸阶梯保持不变。
10. 人物干净抠图，边缘锐利，背后直接是深底；不保留原图浅色背景，不做大片渐隐（见 [人物处理](references/surfaces.md#人物处理)）。立绘边缘同样按第 7 步做原尺寸检查。

材质、打包、安装和验收按 [通用制作流程](references/core/overview.md) 的后半段：[UV 与材质](references/core/materials-and-uv.md)、[打包与验证](references/core/packaging-and-validation.md)。

## 自带的脚本

| 脚本 | 用途 |
| --- | --- |
| `scripts/surface_preview.py`、`scripts/scene_preview.py` | 准备机体几何（`geometry.npz`），渲染整机和近景相机 |
| `scripts/surface_map.py` | 每个图表的平整／弯折／拉伸／机械件／共用 UV／被遮挡分区图，列出压到这些区域的图元 |
| `scripts/design_lint.py` | 设计稿的字体、配色、线型偏向检查 |
| `scripts/vector_paint.py` | 机体米制设计稿直接在原 UV 上求值：色场、渐尖线、马赛克、半调、立绘和文字 |
| `scripts/uv_frame.py` | 给展开的 UV 岛拟合直线框架，让图形在展开图上保持笔直（作者的画法） |
| `scripts/arrangement.py` | 构造线切格：几条直线切出图形和描边形，可镜像 |
| `scripts/replica_measure.py`、`scripts/replica_check.py` | 学作者时在展开图上逐组测量（轮廓、渐变、马赛克、图标配准、跳过原厂部件），再逐组同相机核对、整机组装对照；只用于学习和核对，不用来搬作者的图形 |
| `scripts/coat_material.py` | 整机一层亮漆的材质贴图（作者的做法） |
| `scripts/detail_sheet.py` | 原尺寸检查：从 8192 颜色图按 1:1 截取各部位，和参考贴图同米制比例并排，另出 Composa 调用清单 |
| `scripts/panel_lines.py` | 面板发丝线；基本布局不用（F-2A 没有），只在用户点名要时用，而且必须过原尺寸检查 |
| `scripts/structure_layer.py` | 从原机法线提取模糊结构层；本风格不用，只在用户要旧化时用 |
| `scripts/atlas_palette.py`、`scripts/style_board.py` | 色族面积对照；整机与参考并排的原色、明暗、眯眼对照板 |
| `scripts/composa_mcp.py` | Composa 编辑器调用（打开、渲染、取色、存工程） |
| `scripts/fetch_asset.py` | 下载已选立绘并记录来源 |
| `scripts/inspect_skins.py`、`scripts/build_skin.py` | BLK 与贴图检查，TGA／BLK 组装 |

其余脚本（`compare_skin.py`、`dds_variant.py`、`finish_preview.py`）的用法见 [通用制作流程](references/core/overview.md#可选工具)。依赖：Python 3.10+、NumPy、Pillow、Numba；运行时加 `-B`，输出写到任务目录，不写进 skill 目录。

## 一眼识别的特征（自查）

基本布局（每架都要有）：

- 整机两大块：深炭底和签名色马赛克，俯视约一半对三分之一多；签名色只有一个色相族，是整块的大面（机头连机背前段、两翼）。
- 座舱后一个白色嵌套 V，左右镜像，外侧有细描边回声；全机白色只集中在这里和平尾（或鸭翼）。
- 主翼：翼根深色楔形，中间签名色，翼尖深色带里两条淡染条纹；上下两面一样。
- 平尾或鸭翼：签名色包前缘，后面白带，平行于前缘；垂尾前缘一列平行四边形加一列描边。
- 所有图形边缘笔直干脆，宽度只有四档，同组平行、间距相等；长弧只有顺机身的新月形。
- 漆面是一层亮漆，颜色里没有面板线、铆钉和原厂贴图碎片。
- 字是全大写的宽体/方形无衬线，粗细两档配对，配细线和虚线下划线；左右两侧字的内容不同。

放了立绘（第二阶段）还要满足：

- 人物干净抠图，背后直接是深底，没有原图背景和灰雾；
- 全机人物素材互不重复；
- 基本布局的两大块、白色焦点和尺寸阶梯没有被人物冲掉。

条目缺任何一条，就还没进入这个风格。

## 常见跑偏

模型做这个风格时最常滑向下面这些做法；通用的字体、配色、布局偏向见 [审美纠偏](references/core/taste-corrections.md)。

| 跑偏 | 改成 |
| --- | --- |
| 签名色配第二个饱和色做"撞色"（红配青、蓝配金） | 只一个签名色族；第二色 ≤1%，只做小三角或细线 |
| 底色用纯黑，或带色的深蓝紫 | 中性炭 #2b2b2c–#424347；签名色偏冷时只略偏蓝灰 |
| 签名色大面平涂、处处最饱和 | 面内三角马赛克，沿气流从主色渐到暗一档 |
| 白色铺成大面或当底色 | 白只做尖形序列和主字：3–6%，嵌套 V 主图形时最多约 20% |
| 白色画成细长线：贯穿机身的白针、平行白条、前缘白细边 | 用户：“莫名其妙的白线”。白色只做有体量的形或主图形里成组的渐尖尖片；粗细不变的长白线改签名色亮一档，贴色块边走 |
| 嵌套 V 画成短粗等宽臂、尖点压在凸起背鳍条上 | 用户：“中线的线条做不到复刻 akamy 那个味道”。细长渐尖尖片 6–13°；凸条做深色通道，V 拆成左右两组，见 [线条与图形库](references/motifs.md) |
| 鸭翼整条前缘色带、坐标从别的任务抄 | 用户：“鸭翼线条也没有契合”。按实测前缘做尖片箭头加机型名，见 [鸭翼](references/motifs.md#鸭翼) |
| 保留原机法线、颜色里叠面板线、光滑度取 100–130 | 用户：“自带原皮的纹路，黑不溜秋”。按 [漆面](#漆面) 做整机一层亮漆 |
| 每个面各放一组尖形，方向不一 | 机背只有一个主图形；全机尖端同向，角度取机轴、前缘、后缘 |
| 加曲线、波浪、圆、圆角 | 只用笔直锐利的边；长弧只有顺机身的新月形 |
| 发光边、霓虹描边、外发光 | 不做；靠深色通道和负形缝分开 |
| 字用 Impact、斜体、科幻装饰字，或不加字距 | 方形宽体（Bahnschrift）全大写，Bold 加 Light 两档，按 [字与标识](references/type-and-decals.md) 的字距 |
| 字散放，没有锁组和下划线 | 按 [字与标识](references/type-and-decals.md) 的锁组；机型名配虚线下划线 |
| 编造 "UNIT-07""TACTICAL""CYBER" 之类的字 | 只用角色、作品、阵营、机型和真实的技术标注 |
| 机身侧面填满 | 75% 以上留安静底，只放细线、字和小件 |
| 马赛克铺满全机 | 只在签名色面内 |
| 机腹放人物 | 机腹不放人物 |
| 一开始就放立绘，布局靠人物撑 | 用户：“先学会走路再学会跑”。先照 [基本布局](references/base-layout.md) 做出不带立绘也成立的涂装，认可后再放人物 |
| 签名色压到 15% 左右，撒成细条和碎块 | F-2A 俯视签名色约 38%，是机头机背一整块加两翼各一块 |
| 每个元素各取一个宽度 | 只用四档：大带 0.2–0.4 m、主形 0.12–0.18 m、细线 3–4 cm、描边约 1 cm |
| 从原厂贴图描面板线画进颜色 | 用户在游戏里看 v3：“线条这么脏”“线条粗糙”。描出来是断线、台阶锯齿和乱点；基本布局不画，见 [漆面](#漆面) |
| 只看缩小的预览图就交付 | 8192 图缩到 1600 px 看不出 2 px 线的好坏。按第 7 步在 Composa 里看 1:1 |
| 保留立绘原图的浅色背景，再大片渐隐 | 深底上成一片灰雾。人物干净抠图 |

## 漆面

作者 5 个原包（F-2A、Su-30、幻影 2000、阵风、Su-33）的 BLK 把机身和挂架的全部材质贴图换成同一张 2048² `n.tga`，每个通道是常量：深底四架 R 173、B 0，白底的 Su-33 R 228、B 56；G 是常量，A 里只有一层别的机型的结构残影，单一方向、对不上本机 UV。所以他的漆面任何光照下都干净，只在反光里看到细纹。颜色图主体都是 8192² DXT1。F-2A 颜色里不画舱线；Su-30 和幻影画了少量笔直深色细线和等距铆钉点，没有亮边和斑驳。

做法：`coat_material.py` 按上面的值出材质（基本布局用 `--structure 0`，和作者一样完全平；用户要近看有结构时才用 0.2–0.4），`build_skin.py --channel` 装进包。人物和字与涂层同一光滑度。参数和命令见 [整机一层涂层](references/core/materials-and-uv.md#完整重涂默认整机一层涂层)。

基本布局按 F-2A 做：颜色里**不画**面板线和铆钉，蒙皮上不留原厂贴图碎片（座舱、喷口、起落架舱这类机械件照旧保留），`coat_material.py` 用 `--structure 0`。

Su-30、幻影、阵风三个原包画了全机面板分块线：笔直、粗细一致、在拐角接上，铆钉是等距成排的小点或小十字。莱万汀 v3 用 `panel_lines.py` 从 2048 的原厂贴图逐像素描线再放大 4 倍，结果一半以上的线短于 120 px、斜线成台阶、阴影和脏迹被描成歪线、铆钉是散点，用户在游戏里说“线条这么脏”“线条粗糙”。所以面板线只在用户点名要时才画，画了必须过原尺寸检查，和作者阵风并排看不出差别才交付，见 [面板发丝线](references/core/materials-and-uv.md#面板发丝线)。
