# 字与标识

## 字体

- 全大写的宽体或方形无衬线（类 Eurostile、Bank Gothic、Microgramma 的气质），粗、细两档。没有授权字体时，用系统里最接近的几何无衬线，加宽字距。
- Windows 自带的 Bahnschrift（`C:/Windows/Fonts/bahnschrift.ttf`）可直接用：`vector_paint.py` 的文字图层写 `font` 和 `variation`（`Bold` 做主名、`Light` 做副名），`tracking` 0.05–0.12 给主名、0.2–0.3 给副名。
- 中文、日文字要显式指定字体并渲染确认；这个风格的主字默认用拉丁字母拼写。
- Light 只给字高 8 cm 以上的副名；更小的技术字用 Regular 或 Bold，否则在游戏距离里消失。字体选择、字号层级和凑数字的通用纠偏见主 skill 的 [审美纠偏](../../war-thunder-user-skins/references/taste-corrections.md#字体)。

## 字组

每组字是固定的"锁组"，不要单独散放：

| 锁组 | 结构 | 位置 |
| --- | --- | --- |
| 机型名 | 大号粗体（如"F-2A"），左侧竖排小字制造商名，下方一条虚线下划线 | 垂尾外侧、侧面 |
| 角色名 | 小号细体副名在上（阵营或作品），大号粗体主名在下，中间一条与字同宽的细线 | 主翼对角线、机背负形里 |
| 双色词 | 两个词上下叠放，一个白、一个签名色（如"VIPER / ZERO"） | 垂尾、翼尖深色带 |
| 技术字 | "JET INTAKE →"、"ANTI-RAIN"、"CARRIER-BASED"、"GUARD"等，小号，配箭头或细框 | 侧面、进气道、口盖附近 |

- 字高：机型名约为所在面短边的 1/4–1/3；角色名主名约为主翼弦长的 1/8–1/6；技术字 4–8 cm。
- 方向：沿机轴或沿所在面的长对角线；同一视图内的字方向一致或互为镜像。左右两侧的字都要从各自的外侧读正：设计稿里左侧通常要 `flip`，先用一张带方向标记的试写确认。
- 位置（J-16 v10 做法）：角色名主副名锁组沿主翼后缘斜放在立绘下方；机背角色名放进深色通道，字头朝外；垂尾外侧的机型名放在根部深色带、角色名缩写放在顶帽；机头侧面放机型名。字只放在 `surface_map.py` 的平整可见区，避开弯折和机械件。
- 不要在左右共用 UV 的部位放字：另一侧会显示同一块像素，字会反。
- 颜色：白为主，签名色只给双色词的一半、细线和小图标。

## 小件

- 飞机剪影（俯视或侧视）白色或签名色，放在机型名旁或侧面文字道。
- 徽记：角色阵营或作品标志，放在机背负形或垂尾，配四角折线框（"⌜ ⌟"）而不是完整外框。
- 圆形靶标、带圆点的胶囊框、条码：在侧面排成一行，等距。
- 所有小件聚成 1–2 簇，不撒满全机。

不照搬参考作品里的具体字样、徽记和数字，换成当前角色、作品和机型的内容。
