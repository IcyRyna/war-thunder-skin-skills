# 各面布局

## 通用分工

| 面 | 内容 |
| --- | --- |
| 主翼上表面 | 人物。整个岛几乎被人物填满：每翼 1–2 张不同的图（不同姿态或同角色不同版本），可再加一张放大、低不透明度的回声脸；人物之间用签名色细边、折线或小三角隔开；角色名大字沿翼的长对角线排 |
| 机背 | 一个主图形（见 [图形库](motifs.md)）＋深色中线通道＋签名色母形；两组字（角色名、阵营名）放在主图形和母形之间的深色负形里 |
| 机头 | 暖分支：签名色马赛克，暗端在机头；冷分支：白或浅灰大面，边界是新月长弧 |
| 机身侧面 | 文字道：75% 以上是安静底，放机型名、"JET INTAKE →"等技术字、飞机剪影、虚线序列、伴线组和小箭头组 |
| 边条、鸭翼、平尾 | 签名色楔形或小号人物；鸭翼可放机型名和红白小 V |
| 垂尾外侧 | 立绘。每片外侧一张不同的人物图，铺满整个垂尾作为画面：前缘一条签名色窄带、顶端一块深色帽、根部一条深色带（机型名、小字放在帽和根部带上），立绘底部渐隐进根部带。原图有浅色背景也可以整幅保留，垂尾的外框就是画框。白-签名色-白平行带只用在垂尾内侧，或用户明确不要人物时 |
| 垂尾内侧 | 色场与平行带 |
| 机腹 | 不放人物。签名色暗一档大面，被深色 U 形或 V 形负形切入，加白色细长针和嵌套 V 腹饰 |

无人物的主题涂装（只用角色配色和名字）也成立：主翼改为整面签名色马赛克加翼尖条纹，人物的位置让给大号机型名。

## 按机型

- **双发侧卫类（Su-27/30/33、J-11/16）**：机背宽，用琴键序列或放射长针；两侧垂尾外侧各放一张不同的立绘；尾梁间的中线通道做深色楔形。
- **单发中单翼（F-16、F-2）**：机背窄，用嵌套 V；签名色从机头一直铺到座舱后，被白 V 刺穿；主翼整面签名色或人物；单垂尾两面各放一张不同的立绘。
- **三角翼（幻影、阵风、鹰狮）**：主翼面积最大，人物填满三角翼，两张图沿翼的对角线分开；机背窄，用细长白针和伴线；鸭翼放机型名。
- **双发双垂尾（F-15、F-14）**：主翼人物；机背两条平行签名色母形夹一条深色通道；垂尾外侧肖像。

## 人物处理

- **素材不重复**：主翼、垂尾、回声脸等每个人物位置各用一张不同的原图；左右镜像、同图换裁切、拿另一侧主图做回声都算重复。本地不够就上网找官方立绘、卡面、活动插画（先列出文件名、来源和大小，经用户同意再下载），并记录来源。
- 人物图层放在深色底上，脸和浅色衣物提供反差；衣摆、背景用软渐变溶进深场，发丝可以出画到翼尖或后缘。
- 人物可以被翼面上的签名色折线、字和细边压过，但不能被它们穿过脸。
- 两张人物之间的分界做成一条与前缘平行的直线，线上放角色名或一条签名色细带。
- 背景空心大字母（角色名首字母，字高约翼面短边的 1/3，描边 0.03–0.05 m，灰色 30–50%）可以压在人物身后。
