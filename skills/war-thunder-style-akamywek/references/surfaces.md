# 各面布局

## 通用分工

| 面 | 内容 |
| --- | --- |
| 主翼上表面 | 人物。整个岛几乎被人物填满：每翼 1–2 张不同的图（不同姿态或同角色不同版本），可再加一张放大、低不透明度的回声脸；人物之间用签名色细边、折线或小三角隔开；角色名大字沿翼的长对角线或翼根斜线排；人物身后可放空心大首字母。不用整条前缘宽色带或后缘名字栏把人物框起来 |
| 机背 | 一个主图形（见 [图形库](motifs.md)）＋深色中线通道＋签名色母形；两组字（角色名、阵营名）放在主图形和母形之间的深色负形里。中线有凸起背鳍条时，凸条就是深色通道 |
| 机头 | 饱和签名：签名色马赛克，暗端在机头；浅色签名：白或浅灰大面，边界是新月长弧 |
| 机身侧面 | 文字道：75% 以上是安静底，放机型名、"JET INTAKE →"等技术字、飞机剪影、虚线序列、伴线组和小箭头组 |
| 边条、鸭翼、平尾 | 签名色楔形或小号人物；鸭翼做沿实测前缘的白、签名色尖片箭头加机型名（见 [鸭翼](motifs.md#鸭翼)） |
| 垂尾外侧 | 立绘。每片外侧一张不同的人物图，铺满整个垂尾作为画面：前缘一条签名色窄带、顶端一块深色帽、根部一条深色带（机型名、小字放在帽和根部带上），立绘底部渐隐进根部带。原图有浅色背景也可以整幅保留，垂尾的外框就是画框。用户明确不要人物时，才改放机型名大字和白-签名色-白平行带（F-2A 式） |
| 垂尾内侧 | 沿前缘的签名色马赛克楔形（根宽尖窄），内侧签名色伴线，根部半调；不用等宽平行粗带，不用白色长针 |
| 机腹 | 只画在平整区（先看 `surface_map.py`）。不放人物。签名色暗一档大面，被深色 U 形或 V 形负形切入，加白色嵌套 V 腹饰；长细线用签名色 |

无人物的主题涂装（只用角色配色和名字）也成立：主翼改为整面签名色马赛克加翼尖条纹，人物的位置让给大号机型名。

## 按机型

- **双发侧卫类（Su-27/30/33、J-11/16）**：机背宽，用琴键序列或放射长针；两侧垂尾外侧各放一张不同的立绘；尾梁间的中线通道做深色楔形。
- **单发中单翼（F-16、F-2）**：机背窄，用嵌套 V；签名色从机头一直铺到座舱后，被白 V 刺穿；主翼整面签名色或人物；单垂尾两面各放一张不同的立绘。
- **三角翼（幻影、阵风、鹰狮、J-10）**：主翼面积最大，人物直接放在深底上填满三角翼，两张图沿翼的对角线分开；翼根斜线上放角色名，前缘一带只放 2–3 根尖片组成的箭头，不铺整条色带。机背窄，用签名色面里的白色尖片组（作者的幻影就是这样），伴线用签名色；鸭翼放尖片箭头和机型名。
- **双发双垂尾（F-15、F-14）**：主翼人物；机背两条平行签名色母形夹一条深色通道；垂尾外侧肖像。

## 不要这样做

用户明确否定过、或检查中确认看不见的做法：

| 做法 | 问题 | 改成 |
| --- | --- | --- |
| 垂尾外侧只放线条、色带或机型名（有人物的版本） | 用户：“垂尾应该是立绘” | 外侧放立绘，线条留给内侧 |
| 两处用同一张立绘，或拿另一侧主图做回声 | 用户：“立绘最好不要重复素材” | 每个位置换一张原图，不够就找新素材 |
| 垂尾内侧三条等宽白-签名色-白粗平行带，其余全空 | 用户：“垂尾内的线条不好看” | 沿前缘渐收的马赛克楔形加签名色伴线 |
| 机腹、机背、垂尾上的白色细长针、平行白条、前缘白细边 | 用户：“很喜欢弄些莫名其妙的白线” | 白色只做有体量的形，集中在主白色图形；长细线用签名色（见 [白色怎么用](motifs.md#白色怎么用)） |
| 保留原机法线、颜色里叠面板线、光滑度 100–130 | 用户：“自带原皮的纹路，黑不溜秋，他只在反光的时候看得到纹路” | 整机一层亮漆（SKILL.md 的“漆面”） |
| 机腹线条压在格栅、舱门、天线上 | 用户：“机腹线条有点问题” | 先看 `surface_map.py`，只画平整区 |
| 嵌套 V 的尖点放在凸起背鳍条上（J-10C 莱万汀 v2） | 用户：“飞机中线的线条，还是做不到复刻 akamy 那个味道”；凸条侧壁不上色，每个 V 碎成一个小尖加两根斜杠 | 凸条做深色通道，V 拆成左右尖片组、尖端顶到凸条边；看 `surface_map.py` 的 `seam_items` |
| 嵌套 V 画成 18° 的等宽粗臂短 V | 钝，像路标箭头，没有作者的锐利感 | 细长渐尖尖片，6–13°，最宽处约为长度的 10%，最大的 V 里留深色 V，两侧配错开的菱形尖片 |
| 鸭翼整条前缘色带，坐标从别的任务抄 | 用户：“鸭翼线条也没有契合” | 按本机鸭翼实测前缘做白、签名色尖片箭头，加机型名 |
| 三角翼前缘宽色带加后缘名字栏，把人物框成卡片 | 和作者幻影比像贴纸卡片 | 人物直接放深底，名字沿翼根斜线，前缘只放尖片箭头 |
| 只有干净漆面，近看没有任何结构 | 用户：“作者有很多这种小灰线，我们没有” | `panel_lines.py` 描原厂分块线和铆钉，画成发丝线 |
| 机背色带延伸到机身弯折面 | 碎成毛刺 | 朝上图表只收真正朝上的面 |
| 把图形放在座舱玻璃、机身内部或别的面后面 | 看不见（J-16 第一片琴键、两个回声框曾经这样） | 以 `surface_map.py` 的 hidden 区为准，不以命中纹素数判断 |
| 在左右或上下共用 UV 的部位放不同内容 | 一边被另一边覆盖 | 共用区放对称相同的内容，或挪开；J-16 左垂尾内侧有一条和右垂尾外侧共用 |

## 人物处理

- **素材不重复**：主翼、垂尾、回声脸等每个人物位置各用一张不同的原图；左右镜像、同图换裁切、拿另一侧主图做回声都算重复。本地不够就上网找官方立绘、卡面、活动插画（先列出文件名、来源和大小，经用户同意再下载），并记录来源。
- 人物图层放在深色底上，脸和浅色衣物提供反差；衣摆、背景用软渐变溶进深场，发丝可以出画到翼尖或后缘。
- 人物可以被翼面上的签名色折线、字和细边压过，但不能被它们穿过脸。
- 两张人物之间的分界做成一条与前缘平行的直线，线上放角色名或一条签名色细带。
- 背景空心大字母（角色名首字母，字高约翼面短边的 1/3，描边 0.03–0.05 m，灰色 30–50%）可以压在人物身后。
