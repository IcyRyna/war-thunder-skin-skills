# 二次元喷气机痛涂的美术判断

默认风格、面积区间、人物尺度和常见失败先看 [审美基线](aesthetics.md)；本文件讲在具体机型上怎么取舍。

## 主视觉与机体

先圈定真实连续的主翼、机背、侧身或尾面，再判断人物的脸、肩线、手势、头发与装备如何落位。人物大小有两个独立条件：识别与动作完整，以及在预期整机尺寸下足够显眼。

保住完整头型、主要发型／头饰和使所选姿态成立的连接，再决定远端衣摆、发尾、肢体或道具出画。普通 UV 接缝可对齐，真实空隙、错层和活动边界则需调整布局；头、颈肩、关键手势和主名字避开这些间断。

主翼人物默认覆盖该翼面 60% 以上，脸高约为所在处弦长的 1/5–1/4（见 [审美基线](aesthetics.md#人物人物就是翼面)）。达不到时，在同机体、相机及显示尺寸下并排比较明显更大的可行方案：换紧凑素材、姿态、裁切、位置或角度，同时检查整体轮廓。既不能为保全全身一路缩小成角落里的矩形，也不能只剩大脸和零散手臂。放大局部预览不证明整机中的视觉重量。

## 用人物动作选择布局

先读脸—颈肩—手／道具—躯干的关系。近脸手、抱臂、折膝或回身可能是姿态的关键；远端无叙事作用的衣料和肢体可以裁切。比较人体宽窄与表面如何匹配：

| 人物结构 | 可利用的关系 |
| --- | --- |
| 肩袖向下展开的胸像 | 前窄后宽翼面承接头肩，后缘收束腰腹 |
| 折膝、回身、环绕轮廓 | 宽翼内折回人体长轴，保留动作转折 |
| 横向或斜卧动作 | 利用翼展与后机身，斜视确认跨面的动作可读 |
| 抱臂或紧凑半身 | 用翼根或窄尾面保持脸胸与手臂关系 |
| 举臂、收拢胸腰 | 在尾面根部展开，上方保护头饰和围头动作 |

这些是选图方向，不是固定模板。atlas 岛旋转、图层旋转和相机透视分开判断，人物不必在每个观察角度都正立。场景中的座面、道具或局部背景若承担动作支撑，可保留并融入色场。

人物与图形共同定方向：肩线、长发、拳或道具可以成为路径的目的地或停顿。人物所在的面默认用深场：暗衣部分融入深底，亮脸、手或领口建立识别；衣摆和背景用软渐变溶进深场，发丝可以出画。不给人物套完整外框，也不留原图矩形边。多图保持有意安排的画风、光感和主次。

## 垂尾与机腹

缺省分工如下，当前 brief 优先；研究其他作品时只记录其实际安排：

- 单垂尾：左右两面各安排适配立绘；双垂尾：各片外侧人物，内侧用沿前缘渐收的签名色楔形加签名色伴线，不用白色细针。外侧只有线条、色带或机型名不算完成；内侧不铺等宽平行粗带。
- 每个人物位置用不同的原图，回声层也一样；不足时按 [素材与布局](assets-and-layout.md) 找新素材。
- 机腹与主翼下：不放角色，使用主题色场、路径、图形与局部材质。
- 双翼：用户指定双人物时两侧都落实；未指定时可比较不同姿态、人物配字或其他有意分工。

尾面单独选择紧凑头像或半身，按真实梯形／后掠轮廓构图，并在整机中看识别强度。发束、肩线与衣摆可接到色场边界；原图矩形边需经分离、嵌合或有意遮挡处理。尾面浅深场、中段、前缘和根部共同组成完整画面，不能只完成深色外缘而留下未组织的大浅区。

面别以机体方向、UV 与部件确认，反向斜视或单部件视图补查被遮面。共享 UV 不支持独立内容时调整位置、裁切或统一图案；文字方向以最终模型为准。具体投射与遮挡诊断见 [正交制作](orthographic-workflow.md)。

## 大形、中等图形与细节

先让人物、色场、文字和主路径建立机首—翼根—机背—尾面的连接，再安排中等图形和近看细节（三层的定义见 [审美基线](aesthetics.md#一眼看懂的结构)）。隐藏细纹后应仍读出主次。用户明确要求的尺度和覆盖逐项落实；未指定时按职责选择密度，不要求每面凑齐三档。

安静区域可以由有效色场、边界或弱细节承担停顿。用户指出空、素或断开时，先调整浅深场、中尺度形状与相邻关系，再补细线。重复小标、磨边和更大贴图不能修复孤立贴纸式构图。线组与配色方法见 [线条与配色](linework-and-color.md)。

## 文字参与构图

按当前文案选择字形外轮廓、字重、宽窄、间距与倾角，区分主名字、标识和细注释的观看距离。默认主名字每侧一次，放在最大的连续深色道上，沿机轴或前缘角度排列，字高为深色道宽度的 25–40%；次级字 1–2 组；HUD 小件只聚成 1–2 簇。文字量及语言服从要求；需要比较时使用实际内容，避免把系统默认字直接放大当作完成字标。编辑器默认字体可能没有中文字形，中文必须显式指定字体并看渲染结果。

保留文字层或独立字标源，并说明栅格化范围。检查机体方向、曲面比例与遮挡；默认 atlas 朝向不决定最终字向。

## 纹样与主题

有指定参考时先保持其图形关系；自主设计时再从服装、装备、徽记或场景选主导纹样。组织方向、尺度、间隔与局部强弱，语义相关只是起点。配件以同套颜色、边条和局部标记接续主体，数量由面积和观看距离决定。

## 审稿与修订

初稿即看完整模型，先查漏面、割裂和大形关系，再投入精修。整机尺寸看主视觉、路径和图文竞争，原生局部看轮廓与细节，受光图看材质。

| 问题 | 优先修订 |
| --- | --- |
| 人物小、被结构硬切或动作断开 | 素材、尺度、姿态、位置和承载面 |
| 大浅区单调、图文彼此孤立 | 浅深边界、中尺度图形、方向与嵌合 |
| 主字、副线和细标争强 | 视觉职责、线重、对比和密度 |
| 高光冲淡人物或文字 | 固定条件区分颜色与材质，再按区域调整 |

对照指定基线时固定观看尺度，按实际不足修对应层，保留已接受部分。灰度只辅助看明暗，配色仍回原色判断。记录位置、问题、修改和复看，最终状态按 [验收状态](packaging-and-validation.md#验收状态) 区分，不以自评分或审查人数代替实物。
