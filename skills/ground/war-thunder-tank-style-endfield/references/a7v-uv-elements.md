# A7V 原作 UV 与图形布局研究

这是 HK416の午夜福音 的 [Leopard 2A7V ENDFIELD 原作](https://live.warthunder.com/post/1162771/en/) 的案例研究。四张原尺寸 RGB 图集及 22 组裁片都在本包 `assets/reference-a7v/`，不需要原制作电脑的目录。快速图板在 `assets/study/`。

## 先看图形层级

侧裙把最大英文工业徽记放在横向长阅读面，用灰白装甲、黑色楔面和黄色方向面组成长轴构图。青绿与品红只沿少量大斜边点睛。两侧 UV 紧邻、阅读方向相反，图集上的倒置不是模型显示错误，也不是一个要整体提取的双重徽记。

炮塔让黑顶收住机械细节，灰白斜装甲承担黄带。粗黄折带、平行细线、黑色圆头条及圆点构成同一套语汇；它们存在宽度差、长度差和留白。顶盖的工业中文字和彩条是小标，VISUALIZE 模块和侧面分行字标是中层识别，不能把每块板都铺成同等强度的海报。

炮管按长轴铺渐宽黄带与黑色分隔线，两个相反朝向的字标服务绕管后的可见面。暗面另置低对比工程文字。机枪座保持暗底与低对比纹样，没有直接复制侧裙主徽记的尺寸和密度。

原图中的磨损、焊缝、螺钉、拉手投影和格栅属于机械基底。尤其 T08 那排像字的形状，放大后是装甲边缘结构，不能收入品牌字标库。新车的新增武器站应按其实际盒面、立边和孔壁重新安排图形。

## 官方标志核对的边界

[官网](https://endfield.gryphline.com/en-us) 引用了 [终末地工业透明原图](https://web-static.hg-cdn.com/endfield/official-v4/_next/static/media/endfield.bcc6fe39.png)，其倒三角、塔形、等高线与原涂装 B01 / B07 / T07 对应；官方中文工业字形也可与 T05 对照。原作使用英文工业字样和具体的车辆编排，这不证明作者直接使用了当前这个中文 PNG 文件。

官方英文游戏标题从官网页头的 SVG 路径提取，保留到 `assets/official/endfield-title-en.svg`；SVG 和 Composa 渲染 PNG 均入包。原作 T04 / T06 / G01 中品牌文字的具体字形和锁定排版，未找到完全同版官方母版，按原作实物核对，不以任意无衬线字体代替。

VISUALIZE ENDFIELD 的嵌套三角、CAUTION 的部门标签、EF10 等技术模块和 05 ENDFIELD CONSTRUCTIONS 已在原 DDS 看到，但本次尚未核对到相同官方资产。它们记录为原作素材，不能仅凭名字属于终末地就声明整个模块是官方贴花。LEOPARD2A7 则明确承担这辆车的设备身份，应在新车上改成对应载具信息。

## 换到另一辆坦克

先为新车选定主识别面和信息层级，再从包内找对应元素。主徽记需要连续、足够大的承载板；次级字标可放附件外板；微型标签跟随实际设备与操作位置。黄带先保持同一套方向与端点语言，再检查跨板连续；正文与编号不跟随 UV 镜像。

原作裁片里的 AO、孔口和压纹不随品牌图形一起搬。官方标志用清晰母版；复杂裁片需要抠图时按 [编辑器与素材提取](editor-and-extraction.md) 选择颜色选区或生图辅助，并在实际贴图尺寸检查。原始有效图案只有 122 像素的 T07 不应以生图放大结果冒充高清母版。
