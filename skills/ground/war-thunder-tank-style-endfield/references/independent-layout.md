# 混合载具与独立布局

## 按资源判断迁移范围

一辆车可能同时使用其他车型的车体、另一套炮塔与炮管，以及本车专属附加件。EMBT 的实际模板就是此类情况。逐个列出 BLK、材质 shader 和纹理槽，分别选择直接保留、局部适配或重新设计，不能给整车只贴一个“同车系”或“跨车系”标签。

同一纹理资源名是较强的复用线索，仍需在目标模型上验证阅读方向、结构与遮挡。装配原点、节点拆分、三角形顺序或数量可以不同；三维顶点不相等不能单独证明 UV 不同，车名相近也不能证明 UV 相同。把几何对应检查与实际图集采样检查分开记录。

共用原作颜色图时重新排当前车名与设备身份，检查两侧铭牌、国别小字和其他型号文字。保留来源标记；不能把原作者的机械底图与新画图形一起说成重新绘制。

## 从目标承载面开始画

结构不同的炮塔不需要寻找另一辆车的“最近图案”。以目标原生颜色、法线和 AO 为机械基底，再定义黑白装甲分区、黄带走向、主徽记、设备铭牌与技术小字各自的位置。

先做整车大块，比较侧面、俯视和前后。低平炮塔往往适合较长的侧向路线；高耸附加件需要独立收束。具体比例取实际车形与参考，不固定成所有坦克的横线或箭头。

使用已验证的 UV 栅格化工具时，可让来源与目标都是本车原生几何，以它提供真实表面坐标并写入独立涂层。这里的复用对象是栅格化能力，设计本身仍由目标承载面决定。保留原生法线与 AO；本车的原始颜色也可能含污斑，清洁涂层需分别重建。

## 图形与字体的承载范围

用实际尺寸建立图形母版。透明官方标志保留原轮廓，设备字标在分层编辑器中排字；记录文字实际像素包围盒，投射时按它的有效区域与宽高比安排，而不是按整张透明画布拉伸。

平面标志同时限制构件、平面范围与法向，避免投到邻接立杆和把手。不要让一个法向阈值在文字中间切断笔画；调整承载面或缩小标志。屋顶设备和主装甲可以分开定色，再检查它们之间的细墙与共享 UV。

圆筒上的文字按圆周角与轴向安排，分别验证两侧阅读方向。普通侧向平面投射可能在圆筒上下部拉伸或截断字形。若曲折装甲无法容纳完整编号，换承载面或采用路线、圆端和节点等参考图形，不用碎字填空。

主徽记、字标与编号保持层级。编号不应无意中压过品牌与整车色块；微小标签要在近景清晰，远看仍服务于整体构图。

## 每种 Alpha 分别交付

固定装甲的 C、裁切储物网的 C、打包材质 N 的 A 可以在同一辆车上承担三种不同职责。将 Alpha 契约登记到每个资源，构建时分别处理；保留裁切轮廓，N 的 G/A 按数据通道原样重采样，不能全车统一清零或不透明。

EMBT 的储物网件使用独立裁切材质。重新配色可改变 RGB，保持原 C Alpha 与原生法线/AO，再在颜色与阴影中核对孔洞。材质归属来自当前模型，不把这个特定资源名写成其他车的固定配置。

## 对照与收敛

参考车用于核对色块比重、图形职责、路线粗细、标志层级和漆面响应；目标车用来核对图案承载、结构与字体。相机、光照和背景相同时再比较。保留本轮布局分支及选择理由，随后从最终 DDS 重看七视图与容易出错的近景。

通用方法进入 Skill；车辆坐标、节点标签、掩码、所选布局与用户评价仍随任务保存。技术检查通过后交付可评价的版本，游戏内效果与用户认可单独确认。
