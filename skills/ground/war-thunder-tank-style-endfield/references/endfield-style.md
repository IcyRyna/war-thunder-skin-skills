# 终末地坦克风格配方

## 参考与适用范围

面向坦克涂装的终末地工业视觉。以用户指定的展示图和原包为风格依据；这一轮 A7V 到 A7HU 的参考原作为 HK416の午夜福音的 [Leopard 2A7V ENDFIELD](https://live.warthunder.com/post/1162771/en/)。来源位图复用、按参考重建、新增构件设计分别记录。

先确认参考是否就是本轮验证的黑白黄配方。其他终末地参考有不同的配色和图形时，沿新的参考分析，不凭主题名强制套同一组颜色。

## 原作元素库

先看包内 `assets/study/element-vocabulary.png`，再用 [原作 UV 研究](a7v-uv-elements.md) 对照具体承载构件、阅读方向和信息层级。徽记、标题字、警告块、载具铭牌、路线节点与低对比等高线承担不同职责，不能只提取黑白黄三色。素材路径、尺寸和适用限制见 [素材索引](assets.md)。

## 大块与线条

- 深炭黑承担顶盖、机械区及视觉收束；灰白装甲面提供主要阅读面。黑色保留细线和机械层次，白色保留面板结构及材质起伏。
- 荧光黄按参考形成跨构件的色带或路径，先安排它在车体、炮塔和新增武器站之间的走向，再处理碎小补色。
- 平行细带、圆点或圆环节点作为重复图形语言。让线条服从承载装甲的转折，检查左右侧、顶部和连接处的连续性。
- 微小序列、刻度和技术标注服务于主要构图；不要用随机碎线和噪点补满空白。

## 字标与新增部件

ENDFIELD 等字标使用正确字形与清晰层级。先在正向视图核对镜像和阅读方向，再限制到真实、连续的承载面；拉手、盒体接缝、孔洞和邻接零件会截断文字，需要重新安排位置和尺寸。

目标坦克新增的武器站、观瞄和附加装甲沿用参考的色块比例与图形语言，同时按新部件的实际 UV 设计。车名相近和零件外形相似不能证明贴图可以直接套用。

## 修订时的判断

三角形错贴、幽灵孔口和被拉长的圆环，先核对来源 UV 接缝与表面对应。必要时只对已确认的共同构件逐纹素重投影，保护其他构件的真实 UV 及采样邻域。

压纹附近的黑色脏边，分别替换颜色、法线和 AO 做诊断。旧漆磨损从颜色或 Alpha 混合中透出时，只整理所选涂层区域；小螺钉、光学孔和裸露金属保留各自的结构与材料。不要用整体模糊把压纹一起抹掉。

材质细节按 N 图的分量处理，保留目标结构法线和 AO。顶盖修订包含立边、凹槽和零面积 UV 的采样足迹，避免出现白缝。

## 展示与验收

优先把已有作者展示图用于漆面反光、金属高光、光照和背景的对照。基础排错预览出现履带、机枪、玻璃或网格材质缺失时，补齐实际材质后再制作展示图；单独提高亮度不能替代材质核对。

用户要求七视图时，用最终 DDS 生成两个斜视、俯视、左右侧与前后视图，保持各图比例、对齐边距与标注，按视角长宽比安排版面。离线材质展示与游戏内截图分别注明；只改展示图片的请求保持游戏涂装内容不变。
