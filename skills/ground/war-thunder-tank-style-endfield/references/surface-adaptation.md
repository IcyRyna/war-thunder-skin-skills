# 跨车型适配与出厂检查

## 迁移什么

同风格首先迁移的是图形职责：主徽记、黑白装甲分区、黄带的走向、粗细路线和圆端、少量彩色点睛、设备铭牌与近看才读取的技术标注。它们要落到目标车实际存在的连续承载面上。

相近机型可先把参考颜色图直接绑定目标模型，记录哪些表面确实对应。UV 不同但几何对应时才进行逐纹素三维转移。跨到勒克莱尔等其他车系时，重新识别装甲面与图集，按这些图形职责安排新构图；不能因为都属于现代坦克，就让最近表面搜索决定设计。

像素复用只保留经模型检查合理的部分。新增装甲、炮盾、观瞄、机枪座和储物组件可以按同一套图形语汇重画。以承载面范围、方向与尺寸约束图形，避免涂到孔壁、提手或旁边设备上。

## 先确认实际图集

使用模型 `materials.json` 的纹理槽、目标 BLK 和可见表面互相核对。视觉上属于“炮塔前部”的炮盾，实际可能采样炮管图集；资源名与外观部位不一定一致。

难以定位时，临时给候选资源绑定不同的纯色，保持相机不变。先确认投诉区域落在哪个资源，再改那份贴图。诊断图保存在任务中，不当作展示图。

## UV 采样与图集写入归属

一个组件可能使用平铺 UV，坐标跨出 0–1，或很小的三维面占据很大的 UV 面积。它可以采样现有图集，但在回绘时不一定拥有这些纹素。若给这种小件统一高优先级，会把主装甲的大面积颜色覆盖掉。

对同材质比较三维面积、UV 面积、坐标范围和重叠位置。`三维面积 / UV 面积` 可帮助发现异常，但阈值取决于模型单位与该资源的分布，不固定成所有坦克的常数。以真实承载面选择写入者；普通岛、平铺小件与零面积 UV 的处理应分开。

最近表面查询通过率与最终图集正确率是两个指标。查询大量成功而成图仍大面积错误时，检查 UV 重叠、深度优先级、平铺小件和实际采样方向。共享纹素只能保存一种颜色；确定可见表面与图形优先级，必要时让几个共用表面采用兼容的同色设计。

零面积 UV 的孔壁或盖板立边仍会取色。普通三角形栅格化不会覆盖一条线或一个点，需要明确处理它的双线性采样邻域，并让 R/B 材质与承载涂层一致。扩色只进入未占用纹素，不覆盖旁边已确认的图形。

## 颜色、结构与材料分开

旧车颜色图可能已经画入孔口、螺钉阴影、焊缝、掉漆与污渍。把它投到新车上，即使换了目标法线和 AO，仍会留下颜色层的机械残影。新结构与旧结构不一致的范围，应提取品牌与设计元素，重新铺漆，而不是继续锐化错误的孔和边。

清洁涂层可以按较大的连通面组织，独立螺钉、铰链和裸露金属保留目标细节。连通判断与面积阈值也需要用实际模型验证，不能把连通面大就等同于应该涂漆。

N 图按分量处理。结构不同或用户要求清洁新漆时，优先保留目标 G/A 结构法线和目标 AO。只有明确需要迁移来源新增的压纹等细节时，才将“作者法线减来源原生法线”的差值变换到目标切线空间。来源 R/B 的污渍和磨损响应也不能自动照搬。

## 出厂状态的细节检查

| 检查项 | 需要看到的证据 |
|---|---|
| 颜色层 | 白色漆面没有旧车孔位、随机脏斑或不属于目标的黑边；品牌细线和小字仍清晰 |
| 结构 | 螺钉、缝隙、孔口与实际目标模型一致；关闭颜色细节或切换材质诊断后能定位它们 |
| 粗糙度与金属度 | 漆面响应稳定；裸露金属、橡胶和软质附件保留各自材料关系 |
| 法线 | 目标结构未被整体模糊；没有旧结构的重复凹凸或被错误拉长的压纹 |
| AO | 使用目标数据；阴影属于真实缝隙和遮挡，没有把脏污颜色误当 AO |
| 图形 | 检查字形、阅读方向、负形、圆端、细带间距、接缝与近距离锯齿 |
| 实际输出 | 最终 DDS 再读回，与打包前像素核对，并从这些 DDS 生成模型图 |

用户指出的区域保留同相机前后对照，既看原尺寸贴图，也看近景与全车。原尺寸放大不等于增加了细节。清洁漆面应通过分层、明确底色和正确材质获得，不能用全图模糊掩盖错误。

漆面的具体 R/B 数值以当前参考和用户要求校准。深色附件也可能包含布质储物袋与金属支架，不能仅按颜色给它们统一粗糙度。原车材质能够区分这些结构时，保留这种区分。

## 可视化与反馈

分层编辑器保留原车参考、直接试套、表面适配和已确认修订的独立图层；三维预览也按阶段保留。给用户看当前正在修改的版本，最终展示明确标记为离线模型或游戏画面。

Composa 操作时使用实时返回的文档编号、图层名称或 ID。大图保存可能在客户端超时后已完成，先读取当前文档和实际保存文件，再决定后续操作，不重放整批图层编辑。对于大工程可在已知能力范围内提高客户端超时；方法见 [编辑器与提取](editor-and-extraction.md)。

用户否定的局部转化为可复现检查项。把跨车型仍成立的判断写进 Skill，把具体车型的坐标、掩码与用户评价留在任务。技术检查通过不自动代表用户认可。

预览中的透明网格或已隐藏的可选伪装网也要在阴影 pass 中正确裁切，否则不可见部件仍会投下假阴影，误导漆面和脏污判断。背景、地面和相机保持一致，排除有限地面边界对检查图的干扰。
