# 战雷涂装工作台 · Windows 本地版

## 三步启动

1. 下载 `wt-paint-workbench-windows-x64.zip`，完整解压到自己的可写文件夹，例如桌面。不要在压缩包窗口内直接运行。
2. 双击 **启动工作台.cmd**。无需预装 Python、Git 或 Blender，无需管理员权限。首次联网自动准备固定版本依赖，下载约 70 MB；请保持启动窗口打开。
3. 浏览器自动打开本机工作台。优先识别 Steam 和常见战雷安装目录，找不到时会弹出文件夹选择框。取消后仍可打开 GLB 和已有工程。以后换游戏目录，先停止工作台，再双击 **选择战雷目录.cmd**。

启动完成后可离线使用，游戏资源从本机安装文件夹读取。包内不附游戏模型或涂装。首次下载失败会显示原因；检查网络后重新双击即可。**检查运行环境.cmd** 会重新验证依赖；错误日志位于 `%LOCALAPPDATA%\WT-Paint-Workbench\startup-error.log`。

## 制作前先告诉 AI

请先把这句话和本工具的完整解压路径交给 AI，避免它不知道可以使用预览：

> 我已安装本地涂装工作台，路径是「填写完整解压路径」。你可以使用这里的工具，从我本机战雷安装文件夹提取模型，打开 3D 预览，检查颜色、装饰位置、部件和反射效果。请阅读包内「给AI的说明.md」，每轮修改后用真实模型与原生 UV 复查，再保存工程与导出文件。

完整命令见 **给AI的说明.md**。AI 是否能够自动操作浏览器取决于所用助手的本机工具权限；本包不包含付费 AI 服务。

## 使用与保存

- “打开涂装 ZIP”支持压缩包；“打开涂装文件夹”支持已解压目录。读取 BLK 配置与实际游戏模型索引识别车型，多型号时需要确认候选。
- 可手动校准新装饰、文字、色块，框选或圈选改色、画笔修补，修改部件中文名称和分类，保存可编辑工程。
- 反射、金属质感与接缝凹凸可以预览；模型清晰度和贴图画布均有 512–4K 档位。模型清晰度不改变面数，也不会为低分辨率原图凭空增加细节。
- 合并进旧底图的装饰不能可靠自动拆成独立层。当前颜色导出为 PNG / ZIP，尚未直接回写完整 DDS/BLK 游戏包，也不编辑 N/AO。
- 导入产生的工作文件位于 `%LOCALAPPDATA%\WT-Paint-Workbench\imports`；浏览器导出的工程和图片按浏览器下载设置保存。关闭前先保存可编辑工程。
- 保持启动窗口打开；完成后在窗口按 **Ctrl+C** 停止本次服务。重复双击会打开正在运行的工作台。

在线作品介绍页仍只保留展示、反射、清晰度、视角与预览截图。本地操作不会改动 GitHub 的展示文件或原始游戏文件。
